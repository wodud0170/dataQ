# 행정안전부 공공데이터 공통표준

## 원본 파일 (행안부 배포)
- `행정안전부_공공데이터 공통표준단어.xlsx` - 표준단어 원본
- `행정안전부_공공데이터 공통표준도메인.xlsx` - 표준도메인 원본
- `행정안전부_공공데이터 공통표준용어.xlsx` - 표준용어 원본

## 일괄등록 파일 (시스템 업로드용)
- `단어사전_일괄등록.xlsx` - 단어 일괄등록 (도메인 등록 전 선행)
- `도메인사전_일괄등록.xlsx` - 도메인 일괄등록
- `용어사전_일괄등록_1.xlsx` - 용어 일괄등록 1/2
- `용어사전_일괄등록_2.xlsx` - 용어 일괄등록 2/2

## 등록 순서
1. 단어사전 일괄등록
2. 도메인사전 일괄등록
3. 용어사전 일괄등록 (1 → 2 순서)
