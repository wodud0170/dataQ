## 1. 정책 (확정)

| 정책                 | 내용                                              |
| ------------------ | ----------------------------------------------- |
| **R1 행안부 표준사전 불변** | 단어/용어/도메인 Y 영역은 읽기 전용. **예외: B-3 3건 (Phase 1)** |
| **R2 행안부 우선**      | 행안부 표준 1순위, 없으면 기관표준(`comm_stnd_yn='N'`) 신규 등록  |
| **D1 도메인 통일**      | 최장 우선. 행안부 충돌 시 기관표준 추가 (D6 정책)                 |
| **D6 기관표준 도메인 추가** | 행안부에 없는 (분류·타입·길이) 조합은 자유롭게 N 등록 가능             |
| **Oracle 정책**      | VARCHAR2 사용. CHAR 미사용. STRING > 4000 → CLOB     |
| **마이그레이션**         | Cubrid → Oracle 재생성. ALTER 없음. BEFORE/AFTER만 추적 |
| **영문약어**           | 모두 대문자 (Oracle)                                 |

## 6. 회의 결정 대기 — D4 순번 계열

### 6-1. 현재 상태
- "순번" 한글 컬럼 = 242건 / **15 도메인 사용**
- 같은 한글에 도메인 8종 (NUMERIC 6/10/38, INTEGER 10, STRING 2/3 등)
- 일부는 PK 다수, 일부는 그룹 내 순번, 일부는 합성 ID

### 6-2. 옵션
| 옵션 | 처리 | 영향 |
|---|---|---|
| A. 의미별 용어 분리 | 일반순번/그룹순번/합성ID순번 3등급 | 의미 명확. 용어 3개 등록 |
| B. 최장 일괄 통일 | 모두 NUMERIC(38) | 길이 과도 |
| **C. 현재대로 유지 (사용자 잠정 결정)** | 다중 도메인 허용 | 회의 후 분기 필요 |

### 6-3. C 선택 사유
- 사용자 단독 분기 결정 불가 (의미 분류 컨텍스트 필요)
- RAMP 모델은 다중 도메인 그대로 적재 (현재 상태)
- 회의에서 의미별 분리 후 BEFORE/AFTER 보완
