# 05. CAMS 표준화 — 결정 필요 항목 (회의용)

> 부장님 회의 자료. CAMS Legacy DB 표준화를 진행하며 **사람이 결정해야 하는 항목** 정리.
> 각 항목: 배경 / 선택지 / 영향 범위 / 권장안. 규칙 전문은 `00_CAMS_표준화_개요.md` §2 참조.

## 현황 요약
- 대상: 773 테이블 / 12,818 컬럼 (국가기록원 CAMS Legacy DB)
- 자동 표준화 가능 9,195건(71.7%) / 미처리 3,219건(25.1%) / 보류(코멘트없음) 404건
- 산출물: 기관표준 신규 단어 B 149종, 컬럼명 통일 결정 464그룹
- **이 표준은 국가기록원 정식 기관표준이 되며 후속 사업이 준수**

---

## D1. 컬럼 물리 변경 여부 ★최상위 결정
- **배경**: 표준화 결과(AFTER 컬럼명, 예: `MMID`→`MEDIA_ID`)를 신규 DB에 **실제로 적용**할지.
- **선택지**:
  - (a) 신규 DB에 표준 컬럼명으로 물리 변경 (rename) + 데이터 마이그레이션
  - (b) 물리 컬럼명은 유지하고 표준은 메타(매핑)로만 관리
- **영향**: 전체 12,818컬럼 / 애플리케이션 영향 범위 / 마이그레이션 비용
- **권장**: 회의 결정 사항. 과제 범위·일정을 좌우하는 최상위 의사결정.

## D2. 영문약어 명명 규칙
- **배경**: 국가기록원 자체 약어 규칙 유무 불명. 현재 행안부 스타일(대문자, 자음 골격, 3~6자) 차용.
- **선택지**: (a) 행안부 방식 준용 / (b) 국가기록원 별도 약어 규칙 수립
- **영향**: 기관표준 단어 149종 + 향후 모든 기관표준 단어
- **권장**: (a) 행안부 준용 — 행안부 표준단어와 한 사전에서 혼용되므로 일관성 필요.

## D3. 단어 표준 — 의미 확인필요 6종
- **배경**: 의미가 모호하거나 약어 재검토가 필요한 기관표준 신규 단어.
- **대상**: `육안`·`자기`·`소화`·`상정`·`기구`·`현직` (`단어_일괄등록_CAMS.xlsx` 비고 "확인필요")
- **영향**: 단어 표준 + 해당 단어가 들어간 컬럼 표준화 결과
- **권장**: 회의에서 기록원 업무 맥락으로 의미 확정 → 약어·영문명 결정.

## D4. 컬럼명 통일 — 통일 vs 분리 (464그룹)
- **배경**: `(영문컬럼명+타입+길이)` 일치 그룹 중 코멘트 불일치 464종. 대부분은 표기 변형(통일 대상)이나, 일부는 같은 컬럼명을 **다른 의미로 재사용**.
- **의미 충돌 의심 예**:
  - `REMARK` → 비고 / 표지
  - `ORGTYPE` → 기록물유형 / 원본매체
  - `PAPER_DIV` → 복제구분 / 복원처리서구분
  - `READ_RANGE` → 열람범위 / 접근권한
  - `DHOUSECODE` → 자료관코드 / 접수기관
  - (`JUMINNO1`은 주민번호1=생년월일, 충돌 아님 — 통일)
- **선택지**: 그룹별 (a) 통일 / (b) 분리(코멘트별 개별 표준화)
- **영향**: 464그룹 (수천 컬럼)
- **권장**: `컬럼명_통일_결정.xlsx`에서 1건씩 판단. 의미 충돌 그룹은 `분리`.

## D5. 코멘트 품질 — 오타·공백·부가설명 정정
- **배경**: 오타(`마이그레션`→`마이그레이션`), 앞뒤 공백 217건, 괄호 부가설명(코드값 나열) 혼재.
- **선택지**: 표준화 과정에서 정정 범위 (오타만 / 공백까지 / 부가설명 분리)
- **권장**: 오타·공백 정정, 괄호 부가설명은 본문/설명 분리. 정정 내역은 `02_BEFORE_AFTER`에 기록.

## D6. 코멘트 없는 컬럼 약 404건
- **배경**: 컬럼 코멘트가 비어 표준화 보류 중.
- **선택지**: (a) 보류 유지 / (b) 컬럼 영문명으로 역추정 / (c) 기록원이 의미 제공
- **권장**: 보류 유지, 기록원 측 의미 제공 시 처리.

## D7. 미처리 컬럼 3,219건 (25%) 해소
- **배경**: 미존재(미등록) 단어가 포함돼 자동 표준화 불가. 장기꼬리 단어 추가 큐레이션 필요.
- **선택지**: 추가 단어 큐레이션 깊이·반복 횟수
- **권장**: 반복 큐레이션으로 분해율 90%+ 목표.

## D8. 용어 단계 (R8) — 코드 형식단어·용어 구성
- **배경**: 공통코드 참조 코멘트(`(RG052)` 등) 146건 → 코드 컬럼. 형식단어 `코드`로 끝나야 함. 용어는 `업무단어+형식단어` 구성 충족 필요.
- **권장**: 단어 결정 완료 후 **용어 단계**에서 일괄 처리.

## 이미 확정된 규칙 (참고, 재론 불요)
- R1 행안부 표준사전 불변 (이음동의어 추가 금지)
- R2 행안부 표준 우선, 없으면 기관표준(`COMM_STND_YN='N'`) 신규 등록
- R3 변형어는 행안부 표준어로 변경 (이음동의어 사용 배제)
- R4 `(영문명+타입+길이)` 일치 = 같은 컬럼 → 통일 (D4에서 그룹별 판단)
- R5 약어 = 대문자+숫자, 부적절 표현 금지, 과도한 길이 금지
- R6 단어/통일은 사람이 결정, 근거를 `04_단어검토이력.md`에 기록
- R7 `02_BEFORE_AFTER_컬럼.xlsx` 정합성 최우선, 변경 즉시 반영
- R8 공통코드 참조 컬럼 = 코드 (용어 단계 적용)
