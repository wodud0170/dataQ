# CAMS Legacy DB 표준화 — 진행 절차 (전체 흐름)

> 국가기록원 CAMS(기록물관리시스템) Legacy DB 표준화 과제의 **전체 절차와 진행 상황**.
> 이해관계자 설명용 문서. 규칙 전문은 `00_CAMS_표준화_개요.md`, 사람 결정 항목은 `05_결정필요항목.md` 참조.

> ⚠️ **2026-05-19 방향 변경**: CAMS↔RAMP **DB 통합** — CAMS가 **RAMP 스키마로 흡수**되는 형태로 결정됨.
> 통합 분석·매핑은 **별도 폴더** `CAMS_RAMP_통합/` 에서 진행. **원시 컬럼 기준 매칭 우선**(표준화 결과 대기 안 함, 구 DB 사용자와 소통 보존).
> 본 폴더(CAMS표준화/)는 **CAMS 단어·용어·도메인 표준화 본업**만 담당. 단어 145건 적재는 그대로 유효.

---

## 1. 과제 한 줄 요약

국가기록원 CAMS Legacy DB(**테이블 773 / 컬럼 12,818**)의 컬럼을 표준화하여,
**국가기록원 정식 기관표준 단어·용어**를 수립한다.
이 표준은 앞으로 수행되는 모든 국가기록원 사업이 준수한다.

- 테이블·테이블명은 변경하지 않음. **표준화 대상 = 컬럼**.
- 기존 영문컬럼명 + 한글 코멘트 쌍이 표준화의 원천 데이터.

---

## 2. 표준 체계 — 단어 → 용어 → 도메인

표준은 3개 층으로 구성된다.

| 층 | 정의 | 예 |
|---|---|---|
| **단어** | 최소 의미 단위 | `기록물`, `등록`, `일자` |
| **용어** | 업무단어 + 형식단어 조합 = 컬럼 표준명 | `기록물등록일자` |
| **도메인** | 형식단어가 가리키는 데이터타입·길이 | `일자` → DATE |

**적용 우선순위**: ① 행안부 공통표준(3,281단어) 우선 → ② 없을 때만 기관표준 신규 등록(`COMM_STND_YN='N'`).
행안부 표준사전은 읽기 전용 — 수정·이음동의어 추가 금지.

---

## 3. 전체 절차 (5단계)

```
Phase 0 ──▶ 1단계 ──▶ 2단계 ──▶ 3단계 ──▶ 4단계
분해분석    단어표준   용어·도메인  컬럼명통일  최종산출·적용
 [완료]    [진행중]    [예정]      [예정]     [예정]
```

### Phase 0. 분해 분석 — ✅ 완료
컬럼 코멘트 12,818건을 행안부 표준단어로 분해해 표준화 가능성을 측정.
→ 행안부 표준단어로 100% 분해 65.3%, 미존재 단어 포함 32.9%.

### 1단계. 단어 표준 — 🔄 **진행 중 (현재 위치)**
1. 미존재 단어 큐레이션 → 기관표준 신규 후보 도출
2. 후보를 **1건씩 검토** — 의미 확정, 영문명·약어 적합성, 행안부 중복 확인 (근거는 `04_단어검토이력.md`)
3. 행안부 표준단어와 **중복 전수검사**
4. DB 적재 (`TB_WORD`, `COMM_STND_YN='N'`)

### 2단계. 용어 + 도메인 — ⏳ 예정
1. 컬럼 표준명을 **용어로 구성** — 반드시 형식단어로 끝나게(R8)
2. 용어 ↔ **도메인 매칭** — 형식단어로 도메인 결정
3. **도메인 정합성 검증** — 도메인 표준 타입/길이 ↔ 컬럼 실제 타입/길이 비교, 불일치 검출
4. DB 적재 (`TB_TERMS`) — 용어는 도메인 없이는 등록 불가(`domain_nm` 필수)

### 3단계. 컬럼명 통일 — ⏳ 예정 (결정항목 D4)
`(영문컬럼명 + 타입 + 길이)`가 같은데 코멘트가 다른 **464그룹**을
그룹별로 **통일**(표기 변형) / **분리**(의미 재사용) 결정.

### 4단계. 최종 산출·적용
1. `02_BEFORE_AFTER_컬럼.xlsx` 최종 확정 (12,818 컬럼 전/후)
2. 표준 컬럼명을 신규 DB에 **물리 적용할지 결정** (결정항목 D1 — 최상위)

## 4. 현재 진행 상황 (2026-05-19)

| 항목 | 상태 |
|---|---|
| Phase 0 분해 분석 | ✅ 완료 |
| 단어 후보 큐레이션 | ✅ 완료 — 기관표준 신규 **145단어** / 코멘트정정 규칙 다수 |
| 단어 1건씩 검토 | 🔄 진행 중 — 오역·약어·예시 재검토, 주요 오류 수정 완료 |
| 단어 DB 적재 | ⏳ 임박 (적재 전 단어설명 보완 검토) |
| 컬럼 표준화(`02_BEFORE_AFTER`) | 71.7% (9,195/12,818) — 단어 확정 후 재생성 |
| 컬럼명 통일 464그룹 | 1차 자동판정 완료, 사람 결정 대기 |
| 용어·도메인 단계 | 미착수 |

**단어 검토에서 잡아낸 대표 오류** (재검토로 교정):
`연동→Interlock`(기계 잠금 오역) → 행안부 `연계` 흡수 / `광→Light`(光=optical 오역) → `Optical` / `주변→Surroundings`(주변장치=peripheral) → `Peripheral` 등.

## 5. 향후 할 일 (순서)

1. **단어 마무리** — 외래어 21건·약어 정책·예시 보완 검토 → 단어설명 채움 → DB 적재
2. **컬럼명 통일(D4)** — 464그룹 통일/분리 결정 (`컬럼명_통일_1차판정.tsv` 출발점)
3. **용어·도메인 단계** — 용어 구성 → 도메인 매칭 → 정합성 검증 → 적재
4. **재분해·정합성** — 단어/규칙 확정분으로 `02_BEFORE_AFTER` 재생성, 미처리 25% 추가 큐레이션
5. **최종 결정(D1)** — 표준 컬럼명 물리 적용 여부
