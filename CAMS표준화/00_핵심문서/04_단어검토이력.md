# CAMS 단어 검토이력

> 국가기록원 기관표준 — B 신규 단어를 1건씩 검토한 결정 기록.
> 각 항목: 출현 맥락 / 행안부 표준 대조 / 결정 / 사유.

## 유지 — 검토완료 (2026-05-18)
- **출현**: 코멘트 내 `유지` 53건
  - `보존환경유지기준-...` 50건 (온·습도·공기질·조명 min/max 기준)
  - `유지일` 2건 (컬럼 PRSV_DT)
  - `유지보수요율` 1건 → 행안부 표준 `유지보수(MNTN)`가 최장일치로 처리, B 대상 아님
- **행안부 표준 대조**: 단독 `유지` 없음. 유사어 — 유지보수(MNTN), 유지비(MNTFE), 세션유지(SSPRS), 관리(MNG), 보존(PRSV), 존속(CNTNC).
- **결정**: 기관표준 신규 등록 — 한글 `유지` / 영문명 `Maintenance` / 약어 `MNT`
- **사유**:
  - `보존환경유지`는 온·습도를 목표 범위 내로 **유지(상태 유지)** — 장비 정비인 `유지보수`와 의미가 다름. `관리(MNG)`로 흡수 시 의미가 넓어져 부정확.
  - 영문명 후보 검토 — `Retention`: 기록관리 도메인에서 보존기간으로 오독되어 배제. `Upkeep`: 정비·수선 뉘앙스로 미세한 위화감. `Maintenance`: 사전적으로 가장 정확.
  - 영문명이 `유지보수(Maintenance)`와 중복되나, 단어 표준에서 영문명 중복은 허용 (한글·약어 `MNT`/`MNTN`로 구분). → 의미 정확성 우선.
  - 약어는 `MNTNC`(5자)에서 `MNT`(3자)로 단축. `MTN`은 `산`이 선점, `MNT`는 미사용 확인.

## 시청각 — 검토완료 (2026-05-18)
- **출현**: 코멘트 내 `시청각` 56건 — `시청각기록물`, `시청각류 합계/아날로그/디지털`, `시청각-자기매체`, `시청각-필름매체`, 기록물 유형 분류값. 전부 **시청각 기록물**(오디오·비디오·필름·사진)을 가리킴.
- **행안부 표준 대조**: `시청각`·`영상`·`음향` 모두 없음 → 신규 등록.
- **결정**: 기관표준 신규 등록 — 한글 `시청각` / 영문명 `Audio Visual` / 약어 `AUDVS`
- **사유**:
  - 최초 제안 `AV`는 어감이 부적절하여 배제.
  - `AUDVI`(AUDio+VIdeo)는 `Audio Video`로 읽혀 영문명(`Audio Visual`)과 불일치하고, 오디오·비디오는 시청각의 하위 분류라 의미가 좁아져 배제.
  - `AUDVIS`(6자) → `AUDVS`(5자)로 단축. `AUD`(Audio)를 살려 가독성 유지.
  - 영문 표준 용어는 `audio-visual`(audio 선행 고정 합성어). 한글 글자순서(視聽)와 무관하게 `Audio Visual`이 맞음.

## 암호 — 검토완료 (2026-05-18)
- **출현**: 코멘트 내 `암호` 25건 — `사용자암호`, `이전암호`, `암호파일명`, `암호해제...`, `암호입력건수`, `API접근권한암호`. 컬럼명이 전부 `PASSWD`/`PSWD` (테이블 `RG_PSWD_RLSE_FILE` 등).
- **행안부 표준 대조**: `비밀번호`=PSWD(동의어 패스워드), `암호화`=ENCPT 존재. 단독 `암호` 없음.
- **결정**: B 신규 등록 **취소** → 코멘트정정 규칙 `암호 → 비밀번호`(PSWD)
- **사유**:
  - CAMS의 `암호`는 25건 전부 **비밀번호(password)** — 컬럼명 `PASSWD/PSWD`가 확증. `암호화(encryption)` 용례는 0건.
  - `암호파일`은 암호화 파일이 아니라 **비밀번호로 보호된 파일**(`RG_PSWD_RLSE_FILE` = 암호 해제). 
  - 따라서 행안부 표준 `비밀번호(PSWD)`로 흡수. 신규 단어 불필요.
  - `암호화`는 이미 행안부 표준(ENCPT)이라 CAMS 암호화 컬럼은 자동 표준화됨 — 별도 조치 없음.

## 회로 — 검토완료 (2026-05-18)
- **출현**: `패쇄회로감시장치유무` 2건 (실제 1개 컬럼, `패쇄`는 `폐쇄` 오타).
- **행안부 표준 대조**: `CCTV`(Closed-Circuit Television)·`폐쇄`(CLSG) 존재. 단독 `회로` 없음.
- **결정**: 기관표준 신규 등록 — 한글 `회로` / 영문명 `Circuit` / 약어 `CIRC`
- **사유**:
  - `폐쇄회로 → CCTV` 치환은 부정확(폐쇄회로=closed circuit, CCTV=closed-circuit television) — 철회.
  - `폐쇄회로감시장치`는 단어 단위로 `폐쇄+회로+감시+장치`. `회로`는 정당한 단어 → 출현 2건이지만 등록.
  - 약어 `CIRCUIT`(7자) → `CIRC`(4자). `CRCT`(보정)·`CRC`(시정) 선점되어 `CIRC` 채택.

## 총독 → 총독부 — 검토완료 (2026-05-18)
- **출현**: `총독` 27건 — `총독부기록·기관·간행물·지목·지번` 및 `총독문서` 7건. 전부 조선총독부 관련(사람 Governor 의미 없음). CAMS 컬럼 prefix `GGD`(Government-General Document).
- **결정**: 단어 `총독`→`총독부` 교체, 영문명 `Government-General`, 약어 `GOVGEN`

## 기록물건 / BSID·DSID 핵심키 — 검토완료 (2026-05-18)
- **배경**: 기록물 관리 핵심키 2종. `기록물철`=철(표지), `기록물건`=철 안의 상세 건. 기록원 내부에서 `기록물 건`이 공식 통용어.
- **행안부 표준 대조**: `기록물`(RCDS)·`기록물철`(RCDSF)·`전자기록물`(ERCDS) 존재. `기록물건`·단독 `건`은 없음.
- **결정**:
  - `기록물철` → 행안부 표준 `RCDSF` 사용
  - `기록물건` → 기관표준 신규 등록, 영문명 `Records Item` / 약어 `RCDSI` (행안부 `RCDSF` 패턴에 맞춤: RCDS+한글자)
- **컬럼명 표준규칙 신설** (`컬럼명_표준규칙.tsv`): 같은 영문컬럼명은 코멘트가 제각각이어도 코멘트를 무시하고 표준한글명으로 통일.
  - `BSID` (169컬럼, 코멘트 13종) → `기록물철ID`
  - `DSID` (93컬럼, 코멘트 9종) → `기록물건ID`

## 컬럼 동일성 규칙 + 코멘트 통일 (2026-05-18)
- **규칙**: `(영문컬럼명 + 데이터타입 + 데이터길이)` 완전 일치 = 같은 컬럼 (코멘트가 달라도).
- 해당 그룹 1,744종 중 **코멘트 불일치 475종**이 통일 대상 (예: `FST_REG_DT` 8종, `LST_UPD_DT` 8종, `BSID` 8종).
- **자동 결정 불가** → `컬럼명_통일_결정.xlsx` 생성 (475그룹, 컬럼수 내림차순). 각 그룹의 코멘트 변형을 빈도순으로 제시, `결정 표준한글명` 칸을 사용자가 채움.
- 결정된 내용은 `컬럼명_표준규칙.tsv`에 누적 → `_build.py`가 해당 영문컬럼명의 코멘트를 무시하고 표준한글명으로 표준화.
- 현재 결정 완료: `BSID`→기록물철ID, `DSID`→기록물건ID.

## D3 의미확인필요 — 재검토 (2026-05-19)
- 05 문서 D3는 6종이었으나 `현직`은 현재 149 후보에 없음 → **실제 5종**.
- `육안`(NKDEYE/Naked Eye) — **확정** (2026-05-19). 의미 = 사람 눈으로 하는 검사. 단어 등록 유지, "확인필요" 해제.
  - **영문명 검토**: 도메인 표준 활동어는 `Visual Inspection`이나, `Visual`은 시각·영상 계열 단어가 선점할 가능성이 높아 예약 → 육안은 직역 `Naked Eye`(NKDEYE) 유지로 확정.
  - **단어 vs 용어**: `검사`는 행안부 표준단어 → `육안검사`는 단어가 아니라 **용어**(육안+검사). 단어 신청엔 `육안`만 등록.
  - **표현 통일 결정**: 표준 표현은 `육안검사`. CAMS의 `육안검수`(3컬럼: `육안검수오류코드`, `육안검수수 시작일`, `육안검수수 종료일`) → 전부 `육안검사`로 변경. 사유: 기록물 관리 도메인에서 `육안검사`가 올바른 표현.
  - `육안검사` 4컬럼(`육안검사일자`×2·`육안검사자ID`×2)은 이미 일치.
  - 적용: `육안검수 → 육안검사` 구(句) 단위 코멘트 치환 — 재빌드 시 반영. 잔재 `육안검수수`의 둘째 `수`는 오타 의심 → 별도 확인 필요.
- `자기`(MAGNET/Magnetic) — 자기매체·자기온습도계. 명확 → 해제 가능.
- `소화`(FIRESP/Fire Suppression) — 자동소화시설. 명확(消火/소방) → 해제 가능.
- `상정`(SUBMIT/Submission) — 위원회상정. **SUBMIT은 제출과 영문명 충돌** → 별도 결정 필요.
- `기구`(MCHNRY/Machinery) — 🔴 **오등록**. 실제 컬럼 `기구명`은 `ORG_NM`(조직명)에 붙음 → 기구=機構(조직체)이지 器具/기계가 아님. 영문명·약어 교체 필요.

## 외래어 후보 15종 — CAMS 컬럼 맥락 검토 (2026-05-19)
- **원칙**: 외래어=금지가 아님(행안부 표준에도 디지털·데이터·파일·이미지 多). R3는 "의미가 정확히 같은 변형어"에만 적용 — 케이스별 판단.
- **외래어 유지 권고** (우리말 변환 시 의미 깨짐):
  - `워커` — `WORKERQUEUE.WORKER_NAME`, IT 워커프로세스. 근로자 ❌.
  - `마스터` — `오류신고_마스터_번호`, master record. 석사 ❌.
  - `클래스` — `클래스분류코드/체계`, classification class. 학급 ❌. (`CLASS` 약어 유지 — 위 2026-05-18 점검과 일치)
- **다른 우리말이 맞음**: `포지션` — `APPROVALUSER_POSITION`(승인유저포지션) = **직위/직책**이지 위치 ❌.
