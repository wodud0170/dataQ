# CAMS Legacy DB 표준화 — 개요·규칙·재현 가이드

> 국가기록원 CAMS(기록물관리시스템) Legacy DB 표준화 과제.
> **이 산출물(기관표준 단어·용어)은 대한민국 국가기록원의 정식 기관표준이 되며,
> 앞으로 수행되는 모든 국가기록원 사업이 이 표준을 준수한다.**
> 본 문서는 과제 전체의 단일 기준 — 다른 PC에서 이어받을 때 이 문서부터 읽을 것.

---

## 1. 과제 정의
- 대상: 국가기록원 CAMS Legacy DB — 테이블 773, 컬럼 12,818
- 입력: `CAMS_SCHEMA_원본.xlsx` (사용자 1차 정리본, 시트 `테이블`·`컬럼정의`)
- 목표: DataQ로 기관표준 단어/용어를 잡으며 **컬럼**을 표준화
- 범위:
  - **테이블은 그대로 유지** (구조·테이블명 변경 없음)
  - **표준화 대상 = 컬럼만**, 외래키(FK) 미대상
  - 컬럼 코멘트 없는 항목은 **보류**
- 배포: 실제 대상 DB는 **PC2의 PostgreSQL 컨테이너** (이 PC 로컬에도 테스트용으로 적용).
  과제 산출물·스크립트는 전부 `CAMS표준화/` 폴더에 둔다.

---

## 2. 표준화 규칙 (확정)

### R1. 행안부 표준사전 불변
행안부 표준단어/표준용어(`tb_word`/`tb_terms`의 `COMM_STND_YN='Y'`)는 **읽기 전용**.
추가·수정·삭제는 물론 **이음동의어(`alloph_synm_lst`) 추가도 절대 금지**.

### R2. 표준 적용 우선순위
1. 행안부 표준단어/표준용어를 1순위로 적용 (tb_word 승인분 3,281건).
2. 없을 때만 기관표준(`COMM_STND_YN='N'`)으로 신규 등록.

### R3. 이음동의어 배제 — 전부 행안부 표준어로 변경
변형 표기는 이음동의어로 두지 않고 **행안부 표준어(word_nm)로 변경**한다.
- CAMS 고유 변형어(`붙임`→`첨부`, `유저`→`사용자` 등)
- 행안부가 이미 가진 이음동의어(`ID`→`아이디`, `년도`→`연도` 등)도 동일하게 표준어로 변경
- 구현: 사전을 안 건드리고 코멘트를 표준어로 치환 (`코멘트정정_규칙.tsv`).

### R4. 컬럼 동일성 규칙
`(영문컬럼명 + 데이터타입 + 데이터길이)`가 완전 일치하면 **코멘트가 달라도 같은 컬럼**으로 취급,
표준화 결과(AFTER)를 동일하게 통일한다.
- 코멘트 불일치 그룹은 자동 결정하지 않고 `컬럼명_통일_결정.xlsx`로 사용자가 결정.
- 결정분은 `컬럼명_표준규칙.tsv`에 누적 → `_build.py`가 코멘트 무시하고 표준한글명 적용.
- 표준 감사컬럼(`FST_REG_DT`·`LST_UPD_DT`·`FST_REGR_ID`·`LST_UPDR_ID`)은 자명하므로 결정 불요.

### R5. 영문약어 규칙
- 대문자 영문(A–Z)+숫자(0–9)만 (시스템 검증). 소문자·기호 불가.
- **부적절·민망한 표현 금지** (예: `SPERM`·`AV` 폐기). 등록 전 블록리스트+육안 점검.
- 과도하게 길지 않게 — 행안부 스타일(3~6자, 자음 골격) 준수.
- 기존 tb_word 약어와 **중복 금지** (중복 시 일괄등록이 행 SKIP).

### R6. 단어 검토는 결정사항으로
모든 단어/컬럼 통일은 AI가 임의 확정하지 않는다. 1건씩 사용자가 검토·결정,
근거를 `04_단어검토이력.md`에 기록.

### R7. BEFORE/AFTER 최우선 — 변경 즉시 반영
`02_BEFORE_AFTER_컬럼.xlsx`의 정합성이 과제의 핵심.
규칙·단어·컬럼규칙 변경이 생기면 **즉시 `_build.py`로 재생성**한다 (파일 잠금 해제 상태에서).

## 4. 재현 / 이어받기 가이드 (다른 PC)

### 4-1. 환경
- Python + `openpyxl`, `psql` (PostgreSQL client)
- DataQ DB 접속 (행안부 표준단어 조회용): `127.0.0.1:25433` / DB `postgres` / 스키마 `quality` / `admin` / `admin!123`
  - (PC마다 DB 다름 — 해당 PC의 `q-center/.../application.properties` 확인)

### 4-2. 파이프라인 (작업 디렉터리 = `CAMS표준화/`)
```
# 1) 행안부 표준단어 추출 (스크립트 입력)
psql ... -c "select word_nm, coalesce(word_eng_abrv_nm,'') from quality.tb_word
             where use_yn='Y' and aprv_yn='Y';" > _w.tsv

# 2) 단어 등록안 / 코멘트정정 규칙 생성
python _curate.py        # 단어_등록안.tsv, 코멘트정정_규칙.tsv

# 3) BEFORE/AFTER 생성  (_w.tsv 필요)
python _build.py         # 02_BEFORE_AFTER_컬럼.xlsx

# 4) 단어 일괄등록 양식 / 컬럼통일 결정시트
python _xlsx.py          # 단어_일괄등록_CAMS.xlsx   (_w.tsv 필요)
python _decision.py      # 컬럼명_통일_결정.xlsx

# 끝나면 _w.tsv 삭제
```
- 큐레이션 수정은 `_curate.py`의 `ABSORB`/`NEW`/`ENG` dict 편집 → 위 순서 재실행.
- 컬럼명 통일 결정은 `컬럼명_표준규칙.tsv`에 행 추가 → `_build.py` 재실행.

## 7. 핵심 통찰 (참고)
- 컬럼은 `영문명 + 한글 코멘트` 쌍 — 한글-영문 매핑 정답지가 데이터 안에 있음 (외부사전 불필요).
- 단, 기존 영문약어는 기관 내 불일치(`COD/CD`, `DIV/GUBUN`) — 이형 정리 후 행안부 표준으로 통일.
- 표준화 도구: `한글컬럼 일괄 표준화` 메뉴(DSTermRecommend.vue) — 이 업무용으로 제작됨.
