## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 기록물에 **ISAD(G) 국제표준 기술**(군·계열·철·건 4계층)을 부여하고, **공개·보존기간을 정기 재평가**해서 폐기까지 결정. 보존 후 활용·정리의 핵심.

```
[보존된 기록물]
        ↓

   ├ §10.1 기술분류 (군·컬렉션 → 분류 → 이력)
   ├ §10.2 기술 (스케줄링 → 내용요약 → 집합기술 → 키워드)
   ├ §10.3 서비스제목 관리
   ├ §10.4 공개재분류 (5년·30년 주기)
   ├ §10.5 홈페이지서비스 관리
   ├ §10.6 보존기간 재분류
   ├ §10.7 폐기처리(전자)
   └ §10.8 폐기처리(비전자)
```

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **ISAD(G)** | International Standard Archival Description (General). 기록물 기술 국제표준 |
| **기술분류 4계층** | 군(군기술서) → 군계열(계열기술서) → 철 → 건 |
| **컬렉션** | 주제별 묶음 (군과 다른 분기) |
| **집합기술** | 군·계열 단위 기술 (개별 기록물 아닌 묶음에 대한 설명) |
| **공개재분류** | 비공개 → 공개 가능 여부 재평가 (5년/30년 주기) |
| **30년 경과** | 비공개 기록물이 생산 후 30년 지나면 **공개 원칙** |
| **보존기간 재분류** | 기존 보존기간 만료 시 재책정 / 보류 / 폐기 |
| **기획재분류** | 정책적 일괄 재분류 |
| **임시보관함** | 분류 중 임시 보관 영역 |
| **기능어** | 철에 부여하는 업무 기능 키워드 |

## 1. 워크플로 + 테이블 매핑

```
[§10.1 기술분류 — 군/계열 트리 관리]
군·컬렉션 관리 → 군계열 이력 + 분류 이력
        ↓
   기록물 분류 (분류·미분류·임시보관·기타)

[§10.2 기술 — 실제 기술서 작성]
기술 스케줄링 → 내용요약 등록 (철·건)
            → 반출의뢰
            → 집합기술 (군/계열 기술서 + 분류기록물)
            → 기능어/키워드 등록 (철 기능어 + 건 키워드)
            → 매체수록 판단 + 결과 조회

[§10.4 공개재분류 — 5년/30년 주기]
스케줄링 → 5년 또는 30년 재분류
        → 기획재분류 (정책 일괄)
        → 공개분류 (철·건 단위 검토서)
        → 공개재분류 기준서 관리
        → 반출 → 현황 조회 → 대상조회

[§10.6 보존기간 재분류]
스케줄링 → 재분류 → 현황

[§10.7~10.8 폐기처리]
전자·비전자 별도 스케줄링 + 처리
```

### 관련 테이블 (검증된 BSID PK 테이블 중)
- **기술분류 트리**: `CM_DESC_CLASS_DOCHIS`, `CM_DESC_CLASS_HIS`, `CM_DESC_CLASS_RELHIS`
- **기술서**: `SV_DESCWRITING_DOC` (철 기술서), `SV_DESCWRITING_DET` (건 기술서), `SV_DESCWRITING_KIKWAN` (생산/수집이관기관)
- **임시보관**: `CM_DESC_CLASS_TEMPKEEP_DOC` (기술분류 임시보관함)
- **공개분류**: `SV_DOCUMENT_OPEN` (공개분류), `SV_OPEN_LMT / _HIST` (공개제한)
- **공개제한 페이지**: `SV_OPEN_LIMITED_PAGE`
- **공개재분류**: `SV_DOCUMENT_RECLASS_LIST`, `SV_OPEN_RECLASS_HIST`, `SV_OPEN_RECLASS_DOCUMENT`
- **보존기간 재분류**: `SV_ARCHIVE_RECLASS_LIST`
- **폐기**: `SV_DISUSE_ARCHIVE` (철 폐기), `SV_DISUSE_DETAIL` (건 폐기, 2023 추가)
- **폐기심의**: `RG_SEXHAUSTARCIVE` (폐기심의서)
- **세계기록유산**: `US_UNESCO_RITM`

## 2. 주요 기능 상세

### §10.1 기술분류 (5 하위)

#### §10.1.1 군·컬렉션 관리
- **4단계 트리** 관리: 전체/군/군계열/컬렉션/컬렉션계열
- 등록·수정·**레벨 변경**·폐지(이력관리 대상) / 삭제
- 군분류정보 (생산기관 등록) + 계열분류정보 (분류체계+분류코드+보존기간)
- **전거데이터 연동** (생산기관 연혁정보 조회)

#### §10.1.2 기록물 분류
- §10.1.2.1 분류 기록물
- §10.1.2.2 미분류 기록물
- §10.1.2.3 임시보관 기록물
- §10.1.2.4 기타 기록물

#### §10.1.3~5 이력·통계
- 군계열 이력 / 기록물분류 이력 / 기술통계 관리

### §10.2 기술 (8 하위)

| 절 | 기능 |
|---|---|
| §10.2.1 | 기술 스케줄링 |
| §10.2.2 | 내용요약 등록 (철 + 건) |
| §10.2.3 | 반출의뢰 (서고 → 작업장) |
| §10.2.4 | **집합기술** (기술서내역 + 분류기록물) |
| §10.2.5 | 기능어/키워드 등록 (철 기능어 + 건 키워드) |
| §10.2.6 | 기능어/키워드 등록 현황 |
| §10.2.7 | 매체수록 판단 |
| §10.2.8 | 매체수록 결과조회 |

### §10.3 서비스제목 관리
- 외부 공개용 제목 별도 관리 (원제목과 다를 수 있음 — "기통검" 통합검색용)
- RG_DOCUMENT.SERVICE_BND_TTL 컬럼 연계

### §10.4 공개재분류 (9 하위) — 가장 큰 영역

| 절 | 기능 |
|---|---|
| §10.4.1 | 공개재분류 스케줄링 |
| §10.4.2 | **공개재분류(5년)** — 정기 5년 주기 |
| §10.4.3 | **공개재분류(30년)** — 생산 후 30년 시 공개 원칙 |
| §10.4.4 | 기획재분류 (정책 일괄) |
| §10.4.5 | 기록물 공개분류 (기본·세부 + 재분류검토서) |
| §10.4.6 | 공개재분류 기준서 |
| §10.4.7 | 기록물반출 (서고에서) |
| §10.4.8 | 공개재분류 현황 |
| §10.4.9 | 공개재분류 대상조회 |

### §10.5 홈페이지 서비스 관리
- §10.5.1 홈페이지 서비스 관리 (대상 등록·제외)
- §10.5.2 홈페이지 서비스 이력
- RG_DOCUMENT.HP_SERVICE_YN 컬럼 연계 (포털 홈페이지 서비스 대상여부)

### §10.6 보존기간 재분류 (3 하위)
- 스케줄링 → 재분류 → 현황
- 30년 이하 보존기간 만료 시 재책정 (재책정 / 보류 / 폐기)
- 준영구 70년 경과 시 재평가 (동종대량은 50년)

### §10.7 폐기처리(전자) / §10.8 폐기처리(비전자)
- 각각 스케줄링 + 폐기처리
- 폐기 심의서 별도 (RG_SEXHAUSTARCIVE)

## 3. 코드값·상태값

### 3-1. 기술분류 5단계
전체 / 군 / 군계열 / 컬렉션 / 컬렉션계열

### 3-2. 분류체계 (계열등록 시)
정부기능분류(BRM) / 기록물분류기준표 / 공문서분류표

### 3-3. 공개재분류 주기
- **5년 주기**: 정기
- **30년 시점**: 비공개→공개 원칙 적용

### 3-4. 보존기간 재분류 결과
재책정 / 보류 / 폐기

### 3-5. 분류 상태
분류 / 미분류 / 임시보관 / 기타

### 3-6. 보존기간 재평가 트리거
- 30년 이하 만료
- 준영구 70년 경과 (동종대량 50년)

### 3-7. 폐기 상태 (RG_DOCUMENT.DISUSE_COND_CD)
폐기상태코드 (정확한 값 미확인)
