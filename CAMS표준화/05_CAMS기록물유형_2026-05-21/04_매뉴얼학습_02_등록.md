## 0. 본 문서의 위치 (생명주기 좌표)

> 🎯 **한 줄 요약**: 등록 = **RMS(RAMP)를 거치지 않고 CAMS에서 직접** 메타를 만드는 채널. 인수와 합쳐 CAMS 데이터 진입의 2대 경로.

```
[CAMS 데이터 진입 채널]
                                       ┌→ 인수영역 RG_M* → RG_T* ──┐
RMS(RAMP) ──── 인수 (A01) ─────────────┘ 자동, NEO 파일 흐름        │
                                                                  ├→ RG_DOCUMENT
[CAMS 직접 입력] ── 등록 (A02, ★본 문서) ── RG_T* 또는 직접 ──────┘   RG_DETAIL
  ├ 기획수집 (해외·민간·구술·박물 등)                                  + 유형별 부속
  ├ 납본 (정부간행물 발간등록번호 신청·발급)                            (정식 영역)
  ├ 자체수집 (역사·총독부·도서)
  └ 인수후 대량등록 (비전자 메타 보완)
```

**왜 등록 채널이 별도로 필요한가**:
- RMS(=RAMP)는 행정기관의 업무 기록만 다룸 → **공공기관 외부**에서 들어오는 기록은 RMS를 거칠 수 없음
- 따라서 해외·민간·구술·박물·도서·이중보존매체 등은 CAMS에서 **직접 등록**해야 함
- 정부간행물은 발간기관이 **납본** → CAMS 직접 등록 (홈페이지 연계 또는 사용자 수기)

## 🎓 이 문서를 읽기 전에 — 약어 빠른 풀이

> 기본 약어(BSID·DSID·NEO·ARCAVETYPE·BRM 등)는 [03_매뉴얼학습_01_인수.md §🎓 약어 빠른 풀이](03_매뉴얼학습_01_인수.md) 참고. 등록(A02) 단계에서 추가로 자주 나오는 용어만 정리.

### 진입 채널 구분

| 용어        | 풀이                                           |
| --------- | -------------------------------------------- |
| **인수 채널** | RMS(생산기관)에서 NEO 파일로 자동 흘러들어오는 경로 (A01)       |
| **등록 채널** | CAMS 직원이 화면에서 **직접 메타 입력**하는 경로 (A02 = 이 문서) |
| **기획수집**  | 국가기록원이 능동 발굴해서 들여온 기록물 (A03)                 |
| **납본**    | 정부간행물 발간기관이 의무적으로 CAMS에 보내는 행위               |
| **자체수집**  | 역사적·국가적 가치로 직접 수집한 것                         |

### 유형 구분

| 용어         | 풀이                                 |
| ---------- | ---------------------------------- |
| **일반기록물**  | 행정문서·역사기록·총독부기록 (텍스트 위주 기록물)       |
| **시청각기록물** | 사진·필름·녹음·동영상                       |
| **정부간행물**  | 정부가 발간한 책자·잡지·연구보고서 등 (납본 의무 대상)   |
| **행정박물**   | 정부 활동에서 나온 물리적 박물 (현판·기념패·외교 선물 등) |
| **구술기록**   | 인터뷰 녹취 (CAMS가 직접 인터뷰 수행해서 생성)      |
| **해외기록물**  | 해외에서 수집한 사료 (한국 관련 외국 자료)          |
| **민간기록물**  | 개인·단체가 기증·기탁한 기록물                  |
| **일반도서**   | 영구보존 가치가 있는 도서류                    |
| **이중보존매체** | 원본 외에 추가로 만든 보존용 매체 (DVD·마이크로필름 등) |
|            |                                    |

### 등록·발간 관련

| 용어         | 풀이                                     |
| ---------- | -------------------------------------- |
| **발간등록번호** | 정부간행물 식별 번호. 발간기관이 신청하면 부여             |
| **납본**     | 발간 후 15일 이내에 국가기록원에 책자를 보내는 의무         |
| **폐간**     | 정기간행물이 더 이상 발행되지 않게 됨 (등록 종료)          |

| **복본**     | 같은 간행물의 여러 부수 (예: 같은 책 10권)            |
| **추가정보**   | 행정박물에서 박물유형별로 입력하는 동적 메타 (수령경위·선물가액 등) |

### 민간기록물 분기

| 용어             | 풀이                                              |
| -------------- | ----------------------------------------------- |
| **CHOICE_DIV** | 민간기록물 선정구분 컬럼. **01=지정기록물 / 02=위탁기록물**          |
| **지정기록물**      | 국가가 "이건 국가지정기록물이다"라고 행정 절차로 결정한 것 (A03 §3.2 참고) |
| **위탁기록물**      | 소유주가 CAMS에 맡긴 것 (소유는 그대로)                       |

### 구술기록 관련

| 용어         | 풀이                                        |
| ---------- | ----------------------------------------- |
| **구술자**    | 인터뷰 대상 (말하는 사람)                           |
| **면담자**    | 인터뷰 진행자 (질문하는 사람)                         |
| **촬영자**    | 영상·음성 녹화 담당                               |
| **녹취자**    | 녹음을 텍스트로 옮기는 사람                           |
| **매체별 분철** | 1개 인터뷰가 여러 테이프·파일로 나뉘면 각 매체마다 별도 철로 자동 분리 |

### 대량등록 관련

| 용어         | 풀이                                  |
| ---------- | ----------------------------------- |
| **임시등록**   | 엑셀 업로드 후 정식 등록 전까지 RG_T*에 머무는 상태    |
| **검수**     | 임시등록 데이터에 오류 없는지 검증                 |

| **업로드 서식** | 기록물 유형별 엑셀 양식 (시스템이 ZIP으로 제공)       |

## 2. 단계별 기능 상세 — 12 유형 절순

### 2.1.1 일반기록물 (일반문서·역사·총독부)

3종 공통 패턴 — 모두 **철 목록 관리 + 건 목록 관리** 2단계:

**철 등록 필드 (공통)**:
- 생산기관·이관기관·생산시작/종료연도·기록물분류 (BRM)·제목·권호수·이관일자
- 보존시설(A서울/B부산/C대전/D성남)·보존기간·보존방법·보존장소·기록물형태
- **원본구분**·구문서번호·구MF번호·내용요약·비고·특수목록·인수인계정보

**건 등록 필드 (공통)**:
- 등록일자·문서번호·제목·시행일자·공개구분
- 기안자(업무담당자)·수신자·발신자·결재권자·페이지·쪽수
- 인명/법인명·지명(우편번호 검색)·번지·사건명·축척·생년월일
- 저작권·내용요약·비고

**유형별 차이**:
| 유형 | 차이점 |
|---|---|
| 일반문서 | 표준 패턴 |
| 역사기록물 | 인수자·수집연도·기증자·원어명·언어 추가 / **인명/법인명 직접 입력** |
| 총독부기록물 | 일반문서와 거의 동일 + 분류체계만 CM_OLDGOV_DIVSYS |

**등록구분 (3종)**: 등록중 / 등록완료 / 서고배치 후

**부가 기능**:
- 등록완료 (철·건 단위)
- 순번재정렬 (건의 페이지 기준)
- 관련건 등록 (관련 문서)
- 건삽입 (앞에 끼워넣기)
- 단독건 ↔ 관련건 변환
- 특수목록 추가
- 엑셀 다운로드

### 2.1.2 시청각기록물

기본목록 (철 + 건) 관리. ARCAVETYPE=02.

**철 등록 필드 특이사항**:
- **기록물형태 선택지가 2종으로 좁음**: 사진/필름류 / 녹음/동영상류
- **원본매체** 별도 필드 (기록물형태에 따라 분기)
- 수량·생산기관·이관기관·생산시작/종료연도

**부속 테이블**:
- SV_ARCHIVE_ADDITION_ITEM (시청각기본추가)
- SV_ADDITION_LANGUAGE (언어 추가)
- SV_ARCHIVE_ADDITION_LANG (철 언어)
- SV_DOCUMENT_ADDITION_ITEM (건 추가)
- SV_ARCHIVE_CONDITION_TABLE / _TAB2 (철 상태 평가)
- SV_VISUAL_FILE (동영상 파일)
- SV_VISUAL_MEDIA (시청각 매체)
- SV_IMPORTANCE_HUMN (주요 인물)
- SV_IMPORTANCE_SCENE (대표 화면)

**저작권 관리** 화면 별도 진입 (목록의 저작권 버튼).

### 2.1.3 정부간행물 — 가장 복잡한 4단계 워크플로

```
[등록 신청]                                     [기관 등록]                  [납본 확인]
홈페이지 발간등록신청 ──→ RG_ARCHPRT_REQ        →  RG_GOVTINFO (마스터)    →  RG_GOVTINFO 갱신
                          RG_ARCHPRT_REQ_RELLOG    + 발간등록번호 부여        + 납본일자 입력
오프라인 수기 신청    ─────→                    (자동/수동/재부여)         + 납본처리부서
                                                    │                       (사회/경제/특수)
                                                    ├ ST_PUBLICATIONREGIST   │
                                                    ├ RG_BALGANREGIST       └→ 납본체크
                                                    └ 추가정보·목차·주기
                                                       (RG_GOVTINFO_CR)
[복본 등록]                                     [전자파일 업로드]
RG_GOVTMASTER (BSID+BOOK_GUBUN+BOOKNO 복합키)   RG_GOVTFILE_REG_REQ / _INFO (본문)
                                                RG_GOVTADDFILE_REG_REQ / _INFO (첨부)
[폐간]                                          [미송부 조회]
폐간신청 → RG_ABANDSTATE                        조회 전용 (15일 이내 납본 의무 미이행)
폐간이력: 등록 / 폐간
폐간사유 + 비밀번호 + 신청자정보
```

**§2.1.3.1 정부간행물등록 — 발간등록번호 부여 방식 3종**:
- **신규부여(자동)**: 시스템이 자동 생성
- **신규부여(수동)**: 사용자가 직접 입력
- **기존번호 재부여(기발급)**: 기존 발급번호 조회 후 재사용

**신청구분 (2종)**: 기관신청 / 본소신청

**납본처리부서 (3종)**: 사회 / 경제 / 특수

**보완사항 (납본 미흡 사유 4종)**:
1. 발간등록번호 미부여간행물
2. 발간등록번호 미인쇄간행물
3. 발간등록번호 인쇄오류
4. 간행물 납본부수 부족

**§2.1.3.2 폐간신청 → RG_ABANDSTATE**

## 6. 인수 ↔ 등록 공유 영역 — RG_T* 임시등록

```
[A01 인수 §1.3.7 인수확정]                [A02 등록 §2.1.12 대량등록]
이관기록물검수 통과                          엑셀 업로드 → 임시등록
       ↓                                           ↓
   RG_T* 임시영역 (TBSID/TDSID)        ←──── 공유 ────  RG_T* 임시영역
       ↓                                           ↓
   관리번호 부여                                검수 → 승인 (관리번호 부여)
       ↓                                           ↓
   RG_DOCUMENT / RG_DETAIL (정식 BSID/DSID) ── 양쪽 모두 같은 정식 영역 ──┘
```

→ 인수와 등록이 다른 진입점이지만 **마지막 정식 등록 직전에 같은 RG_T* 영역을 거침**. 이게 두 흐름의 통합점.

**RG_T* 테이블 전체**:
- RG_TDOCUMENT (기본목록 미러)
- RG_TDETAIL (세부목록 미러)
- RG_TDOCTUK (기본 특수목록 미러)
- RG_TDETTUK (세부 특수목록 미러)
- RG_TADMIN_ADDINFO (행정박물 추가정보 미러)
- RG_TGOVTINFO (정부간행물 마스터 미러)
- RG_TDETPER (인명/사건정보 미러)

각 정식 테이블에 대응되는 임시 미러 — 컬럼 구조 동일 (마지막에 TBSID→BSID 변환만).

## 8. 미확정 / 검증 필요 사항

1. **민간기록물 ARCAVETYPE 코드** — 03이 미사용인지, 민간용인지 데이터로 확인 필요. CHOICE_DIV 단독 분기일 수도
2. **일반도서 적재 테이블** — 별도 마스터(RG_BOOK 같은) 없음. RG_DOCUMENT의 어떤 컬럼 사용하는지 매핑
3. **총독부간행물(RG_OLD_GOVTINFO)** — 매뉴얼 §2.1.1.3은 "총독부기록물"인데 스키마는 "총독부간행물"로 명명. 일반 총독부 기록물(문서)와 간행물(도서) 분리 적재 추정 — 코드 흐름 검증 필요 ([02_비전자기록물_유형별_테이블관계.md §5](02_비전자기록물_유형별_테이블관계.md) 참고)
4. **대량등록 상태값** — RG_DOC_LARGE_REG 컬럼 코드값 미확인 (검수/승인 상태 코드)
5. **이중보존매체 vs 매체수록** — A09 매체수록과 RG_TRANSFER_MEDIA의 관계
6. **민간기록물 박물의 분류체계** — CM_GOVART_DIVSYS 공유 추정. 확인 필요
