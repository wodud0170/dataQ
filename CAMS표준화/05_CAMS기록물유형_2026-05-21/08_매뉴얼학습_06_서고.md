## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 보존시설(서울·부산·대전·성남) 서고 내 **위치 관리·반출입·점검·이송**. CAMS 물리 보존의 중심 모듈.

```
[A05 정리 완료] → ★ A06 서고 → [A07 보존 / A11 열람]
   ├ 6.1 서고배치 (1차 배치 + 재배치 + 시뮬레이션)
   ├ 6.2 반출·반입 (열람·보존처리·복원 등 사유로)
   ├ 6.3 정수점검 (수량 확인)
   ├ 6.4 서고점검 (서고 자체 점검)
   ├ 6.5 이송 (보존시설 간 이동)
   ├ 6.6 RFID 관리 (고정형 리더기 + 태그발행기)
   ├ 6.7 기록물 위치별 현황
   ├ 6.8 서고 현황
   └ 6.9 반환 (열람 후 원위치 복귀)
```

---

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **서고** | 기록물을 보관하는 큰 단위 (방·층) |
| **서가** | 서고 내 책장 단위 |
| **련/단/순** | 서가 내 위치 좌표 (련=가로 / 단=세로 / 순=깊이) |
| **정수점검** | 수량 일치 점검 (대장 vs 실물) |
| **서고점검** | 서고 환경·구조 점검 |
| **반출/반입** | 서고 밖으로 꺼냄 / 다시 넣음 |
| **긴급반출** | 정식 절차 생략 긴급 반출 |
| **이송** | 보존시설 간 이동 (예: 서울 → 대전) |
| **반환** | 열람 등 사유로 반출된 것을 원위치로 |
| **고정형 리더기** | 출입구 등에 설치된 RFID 자동 인식 장치 |
| **시뮬레이션** | 가상 배치 검증 |

## 1. 워크플로 + 테이블 매핑

```
[배치]                        [관리]                    [회수]
A05 → 6.1.1 서고배치 → ←──── 6.1.2 재배치
          ↓                       ↑
     6.1.3 서가정보              6.1.7 정보관리
          ↓                       ↑
     6.1.4 RFID 재발행           6.1.8 시뮬레이션
          ↓
     6.1.5 배치확인 → 6.1.6 배치현황
          
[반출입]
6.2.1 반출 → A07 보존처리 / A11 열람
6.2.2 긴급반출 (별도 절차)
6.2.3 반입
6.2.4 미반입현황 / 6.2.5 반출입현황
6.2.6 무단반출입 제외 (RFID 무단 인식 처리)
6.2.7~9 이력 (인계인수·반출입·삭제)

[정기 점검]
6.3 정수점검 (스케줄링 → 점검)
6.4 서고점검 (스케줄링 → 점검)

[이송 (지역 간)]
6.5.1 스케줄링 → 6.5.2 이송 → 6.5.3 입고 → 6.5.4 서고배치의뢰

[RFID 인프라]
6.6 고정형리더기·태그발행기·반출입이력·현황

[반환]
6.9.1 검색 → 6.9.2 스케줄링 → 6.9.3 처리
```

### 관련 테이블 (추정, 스키마 검증된 BSID PK 테이블 중)
- **서고배치**: `SV_ARCHIVE_ARRANGE_LIST / _HIS` (서고배치내역·이력)
- **반출입**: `RF_INOUTSTATUS` (반출입이력), `RF_MVHIS` (이동이력)
- **정수점검**: `SV_QUANTITY_CHECK_LIST`
- **서고점검**: 별도 점검 테이블
- **이송**: `SV_TRANSFER_ENTRY_LIST` (이송·입고)
- **위치이력**: `RG_POSITION_HIS`, `RG_ARCH_PLACE_HIS` (보존소 변경)
- **RFID**: `ST_RFIDTAG`, `RF_TAGPUBHIS` (태그발행이력)
- **고정형리더기**: 별도 장비 테이블

## 2. 주요 기능 상세

### §6.1 서고배치 (8 하위)

| 절 | 기능 |
|---|---|
| §6.1.1 | 서고배치 (정리완료분 인수 + 배치 정보 등록) |
| §6.1.2 | 서고재배치 (위치 변경) |
| §6.1.3 | 서고/서가정보 (마스터 관리) |
| §6.1.4 | RFID 태그 재발행 |
| §6.1.5 | 서고배치 확인 (배치 완료 확정) |
| §6.1.6 | 서고배치 현황 |
| §6.1.7 | 기록물 정보관리 |
| §6.1.8 | 시뮬레이션 관리 (가상 배치) |

**조회 조건**: 보존시설, 인수일, 의뢰부서/일자/자, 배치일, 기록물형태, 처리형태, 보존등급, 원본매체, 규격, RFID 발행유무

### §6.2 반출·반입 (9 하위)

| 절 | 기능 |
|---|---|
| §6.2.1 | 반출 |
| §6.2.2 | 긴급반출 (별도 승인 절차) |
| §6.2.3 | 반입 |
| §6.2.4 | 미반입현황 (반출 후 미반입) |
| §6.2.5 | 반출입현황 |
| §6.2.6 | 무단반출입 제외 (오인식 처리) |
| §6.2.7 | 인계인수이력 |
| §6.2.8 | 반출입이력 |
| §6.2.9 | 반출의뢰삭제이력 |

### §6.3 정수점검 / §6.4 서고점검
- 각각 스케줄링 + 점검
- 정수점검 = 수량 확인 (RFID 활용)
- 서고점검 = 서고 자체 (환경·시설)

### §6.5 이송 (보존시설 간 이동) — 4단계
1. 이송 스케줄링
2. 이송 (출발)
3. 입고 (도착)
4. 서고배치의뢰

### §6.6 RFID 관리

| 절 | 기능 |
|---|---|
| §6.6.1 | 고정형 리더기 |
| §6.6.2 | 태그발행기 등록 |
| §6.6.3 | 반출입이력 조회 |
| §6.6.4 | 고정형 리더기 현황조회 |

### §6.7~§6.8 현황 조회
- §6.7 기록물 위치별 현황 (서고-서가-련-단-순)
- §6.8 서고 현황 (서고 단위 통계)

### §6.9 반환 — 3단계
1. §6.9.1 반환기록물 검색
2. §6.9.2 반환 스케줄링
3. §6.9.3 반환 처리

## 3. 코드값·상태값

### 3-1. 보존시설 (4종)
서울 / 부산 / 대전 / 성남 (+ 대전기록관 별도)

### 3-2. 서가 위치 좌표
서고 → 서가 → 련 → 단 → 순

### 3-3. RFID 발행유무
미발행 / 발행중 / 발행

### 3-4. 처리형태 / 보존등급 / 원본매체
조회 조건으로 사용 (상세 코드 미확인)

### 3-5. 반출 사유
열람·보존처리·복원·M/F촬영·반환 등 (사유별 절차 다름)
