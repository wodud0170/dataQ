## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **비정형 통계** | 정형 보고서 양식 없이 자유 조회 통계 |
| **누계 현황** | 누적 통계 (시작 이후 총량) |
| **분기별** | 1·2·3·4분기 |
| **소장량** | 현재 보유 수량 |
| **이관현황** | RMS에서 받은 현황 |
| **수집현황** | 기획수집 + 자체수집 합계 |
| **태그신규/재발행** | RFID 태그 발행 통계 |
| **무단유출** | 정식 절차 없이 반출된 의심 건 |

## 1. 14개 통계 영역 매트릭스

### §13.1 주요통계 (13 종) — 대시보드용

| # | 통계 |
|---|---|
| 1 | 기록물수집-기관유형별 |
| 2 | 기록물수집-연간이관현황 |
| 3-5 | 해외기록물 (유형별/나라별/연도별) |
| 6-7 | RFID (연도별/유형별 태그부착) |
| 8-9 | 기록물소장 (연도별/서고별) |
| 10-12 | CAMS 유형/형태/생산기관별 |
| 13 | 전자기록물 육안검수 오류현황 |

### §13.2 기획수집 업무 통계 (7 종)
- 해외기록물 수집현황 (나라/유형) / 연도별 일반기록물 / 시청각 / 행정박물 / 간행물 / 마이크로필름(해외) / 분기별

### §13.3 비정형 통계 (9 종) — 유형별 수집·보유
- CAMS / 행정박물 / 시청각 / 정부간행물 / 해외 / 민간기록 / 정부간행물 발간등록번호 / 매체수록 평가 / RFID 태그발행

### §13.4 등록업무 통계 (17 종)
- 누계 (일반·시청각·간행물·해외M/F)
- 년도별 / 총괄표 / 전체보유 (4종) / 생산기관이관
- 발간등록현황 (기관별·기관유형별·전문기관)
- 기록물 소장·등록목록 / 생산년도별 소장량

### §13.5 보존업무 통계 (13 종)
- 유형별 현황 (문서·간행물·시청각·박물)
- 보존서고별 / 서고·서가 배치
- 행정박물 통계 (유형별·최근4년·특정유형 기관별 / 기관유형별)
- 보존처리 현황

### §13.6 기술/재분류 통계 (6 종)
- 생산년도/기관/종류별 기술 / 보존기간재분류 총괄·전 통계
- 대통령·일반매체수록·시청각 평가

## 2. 통계 데이터 원천 (추정)

### 관련 통계 테이블 (검증)
- **CAMS 종합**: `ST_CAMSSTATS` (CAMS 수집보유통계)
- **매체수록 평가**: `ST_EVALUATIONSTAT`
- **RFID**: `ST_RFIDTAG`
- **생산현황 통계**: `RG_STAT_SDOCUMENT / _SDETAIL`
- **생산현황 일괄작업**: `RG_STAT_SREPORT_BATCH_JOB`
- **유형별 보고서**: TB_*_REPORT_FORM 계열 (일반/시청각/박물/회의록/비밀/이중보존/조사연구/정부간행물)
- **육안검수 오류**: `ST_FILE_ERROR_CNT`, `SV_RG_INSU_ERRTYPE_STAT`
- **자료실 통계**: `SV_GOVT_QUANTITY_CHECK_LIST`

### TB_*_REPORT_FORM 9종 (유형별 생산현황)
- TB_ADAF_REPORT_FORM (행정박물)
- TB_CNFRN_REPORT_FORM (회의록)
- TB_DUP_MEDIA_REPORT_FORM (이중보존매체)
- TB_GENR_RCDS_REPORT_FORM (일반기록물)
- TB_GVMT_PBL_REPORT_FORM (정부간행물)
- TB_IQRY_EXPP_REPORT_FORM (조사연구검토서)
- TB_SCRT_RCDS_REPORT_FORM (비밀기록물)
- TB_SNH_RCDS_REPORT_FORM (시청각기록물)
