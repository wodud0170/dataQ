## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 보존된 기록물을 **외부에 공개·제공**. 정보공개청구 처리, 복제M/F 대출, 자료실 운영, 콘텐츠 기획 등 **서비스 단계**.

```
[A01~A10 보존 완료된 기록물]
        ↓
   ★ A11 열람활용
   ├ §11.1 열람대장관리 (정보공개청구 처리)
   ├ §11.2 복제M/F관리 (마이크로필름 대출)
   ├ §11.3 자료실관리 (정부간행물 자료실)
   └ §11.4 콘텐츠기획 (전시·교육 콘텐츠용)
        ↓
   국민·연구자·기관
```

**왜 필요한가**: 보존만 하고 활용 못하면 의미 없음. 정보공개법에 따른 의무 + 콘텐츠로의 활용까지 처리.

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **정보공개청구** | 국민이 공공기관 기록물 열람·복제를 청구하는 권리 (정보공개법) |
| **정보공개처리대장** | 청구 접수~처리 이력 대장 |

| **반입의뢰** | 다시 서고에 넣기 |
| **복제M/F** | 마이크로필름 사본 (열람용) |
| **자료실** | 정부간행물 일반 열람 공간 |
| **콘텐츠기획** | 전시·교육 등 활용 콘텐츠 제작 계획 |

## 1. 워크플로 + 테이블 매핑

```
[§11.1 정보공개]                           [§11.2 복제M/F]
청구접수 → 처리대장 등록 → 반출의뢰         인수 → 배치 → 점검 → 대출
       → 소장유무검색 → 결재상신
       → 인수 → 반입의뢰

[§11.3 자료실 (정부간행물)]                 [§11.4 콘텐츠기획]
인수 → 배치 → 점검                         스케줄링 → 대상선정 → 반출·반입
```

### 관련 테이블 (추정)
- 정보공개: `US_INSPREQ_*` (열람요청), `US_*` 계열 (User Service)
- 복제M/F: `SV_MF_*` (M/F 관리)
- 자료실: `SV_GOVT_ARRANGE_LIST` (자료실배치), `SV_GOVT_QUANTITY_CHECK_LIST` (점검)
- 콘텐츠: 스케줄링 + 반출입 (`SV_JOB_*`)

## 2. 주요 기능 상세

### §11.1 열람대장관리 — 정보공개청구

#### §11.1.1 정보공개처리대장
- **목록 조회 + 상세보기**
- 상세 화면 액션:
  - **반출의뢰**: 청구 대상 기록물 반출 요청
  - **인수**: 반출된 기록물 인수
  - **반입의뢰**: 다시 서고로
  - **소장유무검색**: 청구 대상 기록물 보유 확인
  - **결재상신**: 처리 결재 등록 (수신자·제목·본문)
  - **삭제** (반출입 내역 없을 때만)

#### §11.1.2 정보공개청구서접수
- 청구서 직접 등록·저장

#### §11.1.3 기록물 반입
- 반출된 기록물 반입 처리

#### §11.1.4~5 통계용 처리대장
- **재산/행형/신분/시청각/기타** 건수 별도 통계 입력
- 엑셀 업로드 양식 제공

### §11.2 복제M/F관리

| 절 | 기능 |
|---|---|
| §11.2.1 인수 | 열람실로 이송된 복제M/F 인수 |
| §11.2.2 배치 | 자료실에 배치 |
| §11.2.3 점검 | 주기적 상태 점검 |
| §11.2.4 대출 | 대출 처리 + 반입 처리 |

조회 조건: 보존시설, 이송부서/담당자/일자, M/F 번호, 서고/서가

### §11.3 자료실관리 (정부간행물)

| 절 | 기능 |
|---|---|
| §11.3.1 자료실인수 | 이송된 정부간행물 인수 |
| §11.3.2 자료실배치 | 자료실 서고에 배치 |
| §11.3.3 자료실점검 | 점검 내용 등록 |

### §11.4 콘텐츠기획

#### §11.4.1 콘텐츠기획 스케줄링
- 스케줄링명·작업예정일·콘텐츠담당자·비고
- 대상선정 / 대상수정

#### §11.4.2 기록물반출
- 콘텐츠용 기록물 반출/반입
- 반출정보 확인
