## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 기록물을 **M/F(마이크로필름)·스캔 이미지·DVD 등 다른 매체에 변환·복제**하는 작업. 보존 또는 활용 목적.

```
[A07 보존 중인 비전자기록물]
        ↓
   ★ A09 매체수록 (8 영역)
   ├ §9.1 보존매체수록 조정 (대상선정·매체지정)
   ├ §9.2 M/F 촬영 (10 하위, 가장 큰 영역)
   ├ §9.3 스캐닝 (7 하위)
   ├ §9.4 디지털화 작업 (3 하위)
   ├ §9.5 디지털화(MAM) (2 하위)
   ├ §9.6 보존매체관리 (6 하위)
   ├ §9.7 보존매체수록관리 (5 하위)
   └ §9.8 매체수록 결과조회
```

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **M/F (Microfilm)** | 마이크로필름. 종이를 필름에 축소 촬영 (보존성 100년+) |
| **스캐닝** | 종이를 디지털 이미지로 변환 |
| **디지털화** | 시청각·박물 등을 디지털 데이터로 변환 |
| **MAM** | Media Asset Management. 시청각 대용량 디지털화 시스템 |
| **OD** | Optical Disc. CD/DVD/블루레이 등 광학 매체 |
| **보존매체** | 원본 외에 별도로 만든 보존용 매체 |
| **(구)M/F** | 옛날에 만들어진 마이크로필름 (등록 관리용) |

## 1. 워크플로 + 테이블 매핑

```
[조정 → 대상선정 → 작업]
§9.1 보존매체수록 조정 → 매체지정
       ↓
   ┌──┴──┐
   ↓      ↓
§9.2 M/F  §9.3 스캐닝 / §9.4 디지털화 / §9.5 MAM
   ↓      ↓
§9.6~§9.7 보존매체 등록·관리 → §9.8 결과조회
```

### 관련 테이블 (검증된 BSID PK 테이블)
- **M/F**: `SV_MF_DOCUMENT_LIST` (M/F 촬영 세부내역)
- **스캐닝**: `SV_DIGITAZED_FILE` (디지털화 파일)
- **OD**: `SV_OD_RECORDING_LIST` (OD 수록내역), `SV_OD_RECORDINGDETAIL_PLAN` (OD 수록 세부)
- **매체수록 의견**: `SV_MEDIA_OPINION` (수록 의견), `SV_MEDIA_RECODING_CONTROL` (수록 조정)
- **매체 미반입**: `SV_NOT_CARRYIN_LIST`
- **스케줄링**: `SV_JOB_SCHEDULE_TIF` (TIF), `SV_JOB_SCHEDULE_DOCUMENT` (세부)

## 2. 주요 기능 상세

### §9.1 보존매체수록 조정 (2 하위)

#### §9.1.1 보존매체수록 대상선정
- **기술·상태평가·컨텐츠시스템**의 매체수록 의견 취합
- 조회: 보존시설·기록물형태·**훼손상태** 등
- 매체수록 조정의견 등록

#### §9.1.2 보존매체 지정
- 어느 매체로 수록할지 결정 (M/F·스캔·OD)

### §9.2 M/F 촬영 (10 하위) — 가장 큰 영역

| 절 | 기능 |
|---|---|
| §9.2.1 | M/F 촬영 스케줄링 |
| §9.2.2 | M/F 촬영 (실제 작업) |
| §9.2.3 | M/F 배치 의뢰 |
| §9.2.4 | M/F 복제 (사본 만들기) |
| §9.2.5 | M/F RFID 태그발행 |
| §9.2.6 | 복제 M/F RFID 태그발행 |
| §9.2.7 | M/F 촬영계획서 조회 |
| §9.2.8 | M/F 복제 인수 |
| §9.2.9 | M/F 촬영기록물 조회 |
| §9.2.10 | **(구)M/F 등록** (외부 수집 M/F를 시스템에 등록) |

### §9.3 스캐닝 (7 하위)

| 절 | 기능 |
|---|---|
| §9.3.1 | 스캐닝 스케줄링 |
| §9.3.2 | 스캐닝 작업 |
| §9.3.3 | 스캐닝 검사 |
| §9.3.4 | 보존매체수록 RFID 태그발행 |
| §9.3.5 | 스캐닝 인수 |
| §9.3.6 | 복제 M/F 대출의뢰 |
| §9.3.7 | 재스캐닝 |

### §9.4 디지털화 작업 (3 하위)
- 스케줄링 + 디지털화 + RFID 태그발행

### §9.5 디지털화(MAM) (2 하위)
- 시청각 대용량 전용 - 스케줄링 + 디지털화
- MAM 시스템 외부 연동

### §9.6 보존매체관리 (6 하위)

| 절 | 기능 |
|---|---|
| §9.6.1 | 보존매체 정보 |
| §9.6.2 | 보존매체수록 계획서 작성 |
| §9.6.3 | 계획서 현황 |
| §9.6.4 | OD 복제 |
| §9.6.5 | 서고배치 의뢰 |
| §9.6.6 | OD 반출의뢰 |

### §9.7 보존매체수록 관리 (5 하위)
- 스케줄링 / 수록 / RFID / 서고배치 / 결과조회
- A08 §8.2와 유사하지만 활용용 매체 중심

### §9.8 매체수록 결과조회
- 모든 매체수록 작업의 종합 결과 조회

미발행 / 발행중 / 발행

### 3-4. M/F 사용 구분
보존용 / 열람용 / 복제용

## 5. A08 vs A09 차이 (재정리)

| 항목 | A08 보존포맷 | A09 매체수록 |
|---|---|---|
| 대상 | **전자기록물** (NEO·PDF/A) | **비전자기록물** (종이·필름·박물) |
| 목적 | 100년 보존용 | 활용용 + 보존 백업 |
| 매체 | 보존스토리지 + DVD | M/F + 스캔 + OD |
