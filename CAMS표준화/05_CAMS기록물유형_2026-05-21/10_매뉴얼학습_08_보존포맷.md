## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 전자기록물의 **100년 보존**을 위한 포맷 변환 + 매체 수록. NEO와 PDF/A-1로 변환하고 보존스토리지·DVD에 저장.

```
[A01 인수에서 NEO로 들어온 전자기록물]
        ↓
   ★ A08 보존포맷
   ├ §8.1 보존포맷변환작업
   │   ├ 보존포맷변환 (PDF/A-1 → NEO)
   │   ├ 스토리지저장 (보존스토리지)
   │   ├ 변환관리 (취소·재변환)
   │   └ 재변환이력
   └ §8.2 보존매체수록 (장기보존스토리지 → DVD 등 오프라인)
       ├ 스케줄링
       ├ 수록
       ├ RFID
       └ 서고배치
```

**왜 필요한가**: 디지털은 미디어·포맷이 바뀌면 못 읽음. **장기보존 표준(NEO·PDF/A-1)으로 변환** + **분산 보존**(스토리지 + 오프라인 매체)으로 지진·화재 대비.

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **PDF/A-1** | 텍스트 장기보존 표준 PDF. 외부 폰트·링크 없이 자체완결적 |
| **NEO** | NAK's Encapsulated Object. 전자기록물 장기보존 객체. XML+PDF/A+서명+메타 |
| **장기보존포맷** | NEO + 부속 (영구 보존용) |
| **문서보존포맷** | PDF/A-1 (텍스트 변환만) |
| **보존스토리지** | 영구 저장용 디스크 |
| **보존매체** | DVD·블루레이 등 오프라인 백업 매체 |
| **재변환** | NEO 규격 변경 등으로 다시 변환 (2017년 규격 변경 시) |

## 1. 워크플로 + 테이블 매핑

```
[변환 흐름]
원본파일 ──→ 문서보존포맷변환 (PDF/A-1) ──→ 장기보존포맷변환 (NEO)
                                              ↓
                                          스토리지저장 (보존스토리지)
                                              ↓
                                          보존매체수록 (DVD·블루레이)
                                              ↓
                                          RFID 태그 + 서고배치

[변환 상태] 미변환 → 변환중 → 변환완료 / 변환오류
```

### 관련 테이블 (추정)
- **변환 작업**: `SV_NEO_FILE` (NEO 파일), `SV_PDF_FILE` (PDF/A 파일)
- **변환 이력**: 별도 `_HIS` 테이블
- **매체수록 스케줄링**: `SV_JOB_SCHEDULE_*` 계열
- **보존매체 마스터**: `SV_PRESERV_*` 또는 매체 관리 테이블
- **RFID**: `ST_RFIDTAG`, `RF_*`

## 2. 주요 기능 상세

### §8.1 보존포맷변환작업

#### §8.1.1 보존포맷변환
- **2단계 변환**:
  1. **문서보존포맷변환** (건 단위): 원본 → PDF/A-1
  2. **장기보존포맷변환** (철/건 단위): PDF/A-1 → NEO
- **변환상태 5종**: 전체 / 미변환 / 변환중 / 변환오류 / 변환완료
- **NEO 뷰어**: 변환 결과 직접 확인

#### §8.1.2 스토리지저장
- 변환된 NEO 파일을 **보존스토리지**에 저장
- 조회 조건: 기록물형태, 생산기관, 보존기간, 생산년도, 철제목

#### §8.1.3 보존포맷변환관리 (취소)
- **문서보존포맷 변환취소** / **영구보존포맷 변환취소**
- 변환 후 메타 수정 등으로 재변환이 필요할 때
- 철 단위 + 건 단위 별도

#### §8.1.4 재변환대상선정
- **변경된 현 메타데이터** 기준으로 재변환 대상 조회
- 접수년도·생산기관 단위로 조회
- 변환 상태별 목록 + 재변환요청

#### §8.1.5 재변환이력관리
- 기록물별 재변환 이력 조회
- 변환일자 기준 검색

### §8.2 보존매체수록관리 — 오프라인 분산 보존

#### §8.2.1 보존매체수록스케줄링
- 스케줄링명·수록예정일·수록담당자 등록
- **대상선정**: 스케줄에 수록할 기록물 선정
- **대상수정**: 스케줄 내 기록물 추가·삭제

#### §8.2.2 보존매체수록
- 스케줄 따라 보존매체에 수록
- "지정된 폴더에 복사" 후 매체 굽기 (외부)

#### §8.2.3 RFID태그발행
- 장기보존매체에 RFID 부착
- 태그발행기 + 발행구분(라벨출력/라벨+태그출력)

#### §8.2.4 서고배치의뢰
- 매체 → 서고에 배치 의뢰
- 시청각·박물 등 일반 서고배치와 다른 흐름 (매체 전용)
