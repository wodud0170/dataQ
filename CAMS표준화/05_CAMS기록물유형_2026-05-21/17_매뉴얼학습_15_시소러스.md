## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 시소러스 = **용어 관계 사전**. "자동차"의 상위어 "교통수단", 동의어 "차량", 관련어 "도로" 같은 관계를 등록해 검색·분류에 활용. 전거(고유명사)와 별도, 일반 어휘 대상.

```
[시소러스 vs 전거]
시소러스 = 일반 명사 (예: 경제, 교통, 환경) — 분류·검색
전거    = 고유 명사 (예: 박정희, 5·18, 서울) — 표준화

[C01 시소러스 영역]
   ├ §1 용어관리 (등록·편집·신청·삭제)
   ├ §2 분류관리
   ├ §3 관계지시기호 관리 (BT/NT/RT/UF 등 표준 부호)
   ├ §4 통계 (구축·작업·신청·주제·BEST)
   └ §5 반출 (XML/엑셀 등 외부 추출)
```

## 🎓 약어 빠른 풀이 (시소러스 표준 약어)

| 약어 | 풀이 |
|---|---|
| **BT** | Broader Term — **상위어** (자동차의 BT = 교통수단) |
| **NT** | Narrower Term — **하위어** (교통수단의 NT = 자동차·기차) |
| **RT** | Related Term — **관련어** (자동차의 RT = 도로) |
| **UF** | Used For — 이 용어가 대신하는 비채택어 |
| **USE** | UF의 반대. "이 용어 대신 ○○ 사용" 표시 |
| **SN** | Scope Note — **범위주기**. 용어 사용 범위 설명 |
| **CC** | Category Code — **카테고리 코드** |
| **TT** | Top Term — 최상위어 |
| **고립어** | 관계가 전혀 없는 용어 |
| **미판정어** | 관계가 확정되지 않은 용어 |
| **검증/미검증** | 관리자 검증 통과 여부 |
| **한정어** | 동음이의어 구분용 (예: "사과(과일)" vs "사과(용서)") |
| **패씻(Facet)** | 분류 기준 |
| **신청용어** | 외부 사용자가 등록 요청한 용어 |

## 1. 워크플로 + 테이블 매핑

```
[용어 수명주기]
   ┌─ 신청용어 (사용자 요청) ─┐
   │                          ↓ 관리자 검토
   │                       등록 / 거부
   │                          ↓
   직접 등록 ───────→ 용어 등록 (관계 부여: BT/NT/RT/UF/SN/CC)
                          ↓
                       검증 처리
                          ↓
                       활용 (검색 확장, 분류, A12 §12.3 관련용어)
                          ↓
                    수정 / 삭제후보 등록 → 삭제
```

### 관련 테이블 (추정)
- **용어 마스터**: `TH_THESAURUS` (도메인 종합 문서)
- **용어 관계**: `TH_TERM`
- **신청용어**: `TH_APPLYTERM` — APPSTATUS (1:접수, 2:등록, 3:거부)
- **카테고리/분류**: `TH_*` 계열

## 2. 주요 기능 상세

### §1.1.1 용어 등록 및 편집

**용어 검색 특수문자**:
| 패턴 | 의미 |
|---|---|
| `경제` | "경제"로 **시작**하는 용어 |
| `*경제*` | "경제"를 **포함**하는 용어 |
| `*경제;` | "경제"로 **끝나는** 용어 |
| `경제>` | "경제" **다음에 나오는** 용어 |

**검색 범위 (7종)**:
전체 / 검증용어 / 미검증용어 / **고립어** / **미판정어** / CC / SN

**용어 표현 (목록 표시 방식)**:
- 굵은 글씨 — 관계 없는 용어 (BT 미설정)
- 보통 글씨 — 관계 있는 용어 (BT 있음)
- 흐린 글씨 — **비우선어** (오른쪽에 우선어 표시)

**용어 등록 흐름**:
1. 등록할 용어 입력 (**한자 변환** 가능)
2. 관계 선택 (BT/NT/RT/UF 등)
3. **카테고리 선택** (CC 사용 시)
4. **중복검사** 클릭
5. **범위주기(SN)** 입력 (필요 시)
6. 패씻 입력 (있으면)
7. 등록 → 관계목록 확인

**TopTerm 보기**:
- 선택 용어의 **상하위 관계 전체 트리** 조회
- 하위 있음 → `+` 아이콘 / 하위 없음 → 문서 아이콘
- 검색용어 = 갈색바탕 노란색, BT = 초록색 이탤릭

**용어 이력 관리**:
- 입력/수정/검증 일자, 수정 비고, 사용자, 변경구분/상태/관계/일자/용어 등 추적

### §1.2 신청용어
- 외부 사용자가 새 용어 등록 요청
- 동일 용어는 **요청수**로 집계 (최근 정보 기준 표시)
- 액션: 등록 / 거부 / 기간별 삭제 / 엑셀 저장

### §1.3 삭제용어
- 삭제 요청 처리 (전거 삭제후보와 유사 흐름)

### §2 분류관리 — 시소러스 분류체계
- 시소러스 자체의 분류 체계 (대/중/소)
- 등록·수정·삭제

### §3 관계지시기호 관리

| 연계 | 관계 |
