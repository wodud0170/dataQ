## 0. 본 문서의 위치 (생명주기 좌표)

> 🎯 **한 줄 요약**: 기획수집 = **등록(A02)·인수(A01) 이전의 사전 활동**. 국가기록원이 외부 민간·해외 기록물을 **능동적으로 발굴·수집**하는 단계. 등록·인수에 데이터를 공급.

```
[기획수집 (A03, ★본 문서)]                  [등록·인수 (A01·A02)]              [정식 영역]
 │
 ├ §3.1 기획수집 (능동 수집 워크플로)
 │   ① 분류체계 관리 (주제 분류 구축)
 │   ② 소재정보조사 (어디에 있는지 조사)
 │   ③ 주제별기록물선정 (수집할 것 선정)
 │   ④ 계획수립 (수집 계획 작성)
 │   ⑤ 수집현황등록 (실제 수집 결과)        →    A02 등록 (해외·민간·박물·도서 등)
 │                                              → RG_DOCUMENT
 └ §3.2 국가지정기록물 (행정 지정 절차)
     ① 지정등록 (신청 접수 또는 직권)
     ② 지정결과서 (현장조사·심의·고시)        →    A02 등록 (민간 CHOICE_DIV=01 지정)
     ③ 사후관리 (지정 후 모니터링)             → RG_DOCUMENT
     ④ 지정해제 (지정 종료 절차)
```

**왜 기획수집이 별도로 필요한가**:
- RMS(=RAMP)는 공공기관의 **자동 이관** 채널 — 외부 민간·해외 기록물은 잡히지 않음
- 국가기록원이 **주제별로 계획을 세우고 능동 발굴**해야 함 (예: 위안부·5·18·역사적 사건 관련 민간 보유 기록)
- 수집한 기록물은 A02 등록으로 흘러들어 RG_DOCUMENT에 적재
- 그 중 **국가적 가치가 특별히 높은 민간 기록물**은 별도 행정 절차로 "국가지정기록물"로 지정 → 보존·반출 제한·소유권 모니터링 대상

**법적 근거**: 공공기록물법 + 국가기록물 지정 제도 (민간 보유 기록물 보호)

## 🎓 이 문서를 읽기 전에 — 약어 빠른 풀이

> 기본 약어는 [03_매뉴얼학습_01_인수.md §🎓 약어 빠른 풀이](03_매뉴얼학습_01_인수.md) 참고. 기획수집(A03)에 특화된 용어만 정리.

### 기획수집 = 능동 발굴 활동

| 용어 | 쉬운 풀이 |
|---|---|
| **기획수집** | 국가기록원이 **알아서 외부 기록을 찾아내서 수집**하는 활동. 가만히 있어도 RMS에서 들어오는 인수와 정반대 개념 |
| **소재정보조사** | "어디에 무엇이 있는지" 사전 조사. 수집 대상을 찾아내는 단계 |
| **소장처** | 그 기록물을 실제로 가지고 있는 곳 (개인 집·도서관·외국 기관 등) |
| **소장인** | 기록물을 보유한 개인 |
| **관리인** | 실무로 그 기록물을 관리하는 사람 (소장인과 다를 수 있음. 예: 작가 사후 유족이 보관 → 관리인은 출판사) |
| **주제구분** | 기획수집을 위한 분류 기준. 예: "5·18 민주화운동", "위안부", "친일파 행적" 같은 주제 단위 |

### 수집 형태 4종

| 형태 | 풀이 |
|---|---|
| **수집** | 일반적인 가져오기 (대가 지불 또는 무상) |
| **기증** | 소유주가 무상으로 영구히 넘김 (소유권 이전) |
| **위탁** | 소유주가 보관만 맡김 (소유권은 그대로) |
| **복제** | 원본은 두고 복사본만 가져옴 |

### 국가지정기록물 = 행정 지정 절차

| 용어 | 쉬운 풀이 |
|---|---|
| **국가지정기록물** | 민간이 가진 기록물 중 "국가가 보존가치를 공식 인정한 것". 지정되면 함부로 처분 불가, 사후관리 대상 |
| **지정** | 국가가 "이건 국가지정기록물이다"라고 결정하는 행정 절차 (지정신청 → 심의 → 고시) |
| **직권등록** | 외부 신청 없이 담당자가 알아서 지정 신청을 올리는 것 |
| **신청서 등록** | 외부에서 들어온 지정 신청을 시스템에 등록 |
| **고시** | 결정 사항을 공식 공표 (관보에 게재) |
| **사후관리** | 지정 후 정기적으로 "그 기록물 잘 보관되고 있는지" 확인하는 활동 |
| **소유권변동** | 지정 기록물의 주인이 바뀜 (상속·매매 등) → 국가에 신고 의무 |
| **지정해제** | 지정을 종료하는 절차. 멸실·훼손 등 사유 발생 시 |
| **지정서 회수** | 지정 시 발급했던 공식 서류를 해제 시 회수 |

### 분류 단계

| 용어 | 풀이 |
|---|---|
| **대/중/소분류** | 일반적 분류 계층 (큰 분류 → 작은 분류) |
| **주제구분** | 기획수집 전용 추가 분류 (위 4단계와 별도) |

### 분류 연결·해제

| 용어 | 풀이 |
|---|---|
| **분류연결** | 어떤 기록물을 어떤 주제에 매핑 (한 기록물이 여러 주제에 동시 연결 가능) |
| **분류해제** | 매핑 끊기 |

## 1. 기획수집 전체 흐름 (PL_* 14테이블)

```
[§3.1 기획수집] — 능동 수집 5단계
                                             [적재 테이블]
3.1.1.1 분류체계 관리                     →  PL_CLASS  (기획수집주제)
   (대/중/소분류 + 주제구분)                  사용여부 / 분류단계 / 분류코드 / 분류명
        ↓
3.1.1.2 소재정보조사                      →  PL_RECORD  (소재정보조사)
   (소장처구분·국가·기관·소장인·관리인)         소장인 / 관리인 / 기록물명 / 생산년도
        ↓
3.1.1.3 주제별기록물선정                  →  PL_CLASS ↔ PL_RECORD 연결
   (분류연결 / 분류해제)                     (조회 결과로 분류 매핑)
        ↓
3.1.1.4 주제별기록물현황                  →  (PL_CLASS + PL_RECORD 조인 조회)
   (주제구분·소주제·소장기관·기록물명)
        ↓
3.1.1.5 계획수립                          →  PL_COLLECTPLAN  (기획수집계획)
   (계획년도·계획명·추진일정·소주제·담당자)
        ↓
3.1.2.1 수집현황등록                      →  PL_PLANRECORD  (수집현황)
   (조사자·현장조사일자·기록물유형)              ↓
                                          ↓ 수집 완료 결과
                                       A02 등록 (해외·민간·박물·도서 등)
                                          ↓
                                       RG_DOCUMENT/RG_DETAIL


[§3.2 국가지정기록물] — 지정 행정 절차 6단계 (생애주기)

3.2.1 지정등록                            →  PL_ASSIGNREQ  (국가기록물지정신청)
   (신청구분: 직권등록 / 신청서)              + PL_ASSIGNREQFILE  (첨부파일)
   소장인·신청인·주민번호·전화·주소 등         신청상태: 신청중 / 검토중 / 승인완료
        ↓
3.2.2 지정결과서 등록                     →  PL_ASSIGNREQDISCUSS  (지정대상조사_심의)
   (현장조사·검토·심의·고시·인수 일자)         ↓
        ↓
   (심의 통과 시 정식 지정)                 →  PL_ASSIGN  (국가기록물지정)
        ↓
3.2.3 사후관리                            →  PL_ASSIGNAFTERMANAGE  (지정기록물사후관리)
   (안내통보 → 조치결과통보)                 + PL_ASSIGNAFTERFILE  (첨부파일)
   관리상태: 소유권변동/관리환경불량/상태불량/기타
        ↓
3.2.4 지정해제 요청                       →  PL_ASSIGNREVOKE  (국가기록물지정해제)
   (요청일자·해제요청사유·신청자·연락처)        + PL_ASSIGNREVOKEFILE  (첨부파일)
        ↓
3.2.5 지정해제관리                        →  PL_ASSIGNREVOKE  업데이트
   (검토·심의·해제통보·고시·지정서 회수)
        ↓
3.2.6 지정해제기록물현황                  →  (PL_ASSIGNREVOKE 조회)
```

**핵심 발견 — `PL_` 접두사 = Plan/기획수집·국가지정 영역**:
이 영역은 다른 RG_*, SV_*와 완전히 분리된 **별도 도메인**. 14개 테이블 모두 PL_ 접두사로 통일.

## 2. 단계별 기능 상세

### §3.1 기획수집 — 능동 수집 워크플로

#### 3.1.1.1 기획수집 분류체계 관리 → `PL_CLASS`

**목적**: 언론, 민간, 해외, 사건·사고, 정책결정 등 **주제별 분류** 구축.

**입력 필드**:
- **분류단계 (4종)**: 대분류 / 중분류 / 소분류 / 주제구분
- 분류코드 / 분류명 / 주요내역
- **사용여부**: 사용 / 미사용

**조회**:
- 분류명 또는 분류코드로 검색
- 사용여부 필터 (전체/사용/미사용)

**제약**: 분류명 중복 금지 ("분류명() 이미 등록되어있습니다")

#### 3.1.1.2 소재정보조사 → `PL_RECORD`

**목적**: 주제별로 **어디에 무엇이 있는지** 조사 등록.

**조회 조건 (1단계 — 소장처)**:
- 소장국가 / 소장처구분 / 소장기관

**조회 조건 (2단계 — 소장인/관리인/기록물)**:
- 소장인 / 관리인 / 기록물명

**등록 필드**:
- 소장기록물제목 / 소장인 / 관리인 / 생산년도

**참고**: 옛 테이블 `CM_DOCPOS_PLACE`(기록물소장처)는 **삭제대상** 표기됨 → PL_RECORD로 통합 추정.

#### 3.1.1.3 주제별기록물선정

**목적**: PL_CLASS(주제) ↔ PL_RECORD(소장기록물)를 **연결/해제**하는 매핑 작업.

**기능**:
- 분류별 검색 (분류명/분류코드)
- **분류연결**: 미연결 기록물 → 분류 연결
- **분류해제**: 연결 기록물 → 분류 해제

→ 같은 기록물이 여러 주제에 동시 매핑 가능 (다대다 관계)

#### 3.1.1.4 주제별기록물현황

조회 전용 화면. 매핑 완료된 결과를 보는 대시보드.

**조회 조건**: 주제구분 / 주제·소주제 / 소장기관 / 기록물명

#### 3.1.1.5 계획수립 → `PL_COLLECTPLAN`

**목적**: 선정된 기록물에 대해 **수집계획서** 작성.

**등록 필드**:
- 계획년도 (4자리) / 계획명 / 추진일정 (FROM-TO)
- 수집계획명 / 소주제 (PL_CLASS 참조) / 담당자

#### 3.1.2.1 수집현황등록 → `PL_PLANRECORD`

**목적**: 계획 → **실제 수집 결과 등록**. 수집/기증/위탁/복제 결과.

**조회 조건 (1단계 — 계획별)**:
- 계획년도 / 계획명 / 추진일정

**조회 조건 (2단계 — 결과별)**:
- 소장기관 / 소장기록물

**등록 필드**:
- 조사자 / 현장조사일자 / 기록물유형

**부가 기능**:
- 일괄등록 (다수 소장기록물 선택 후 일괄 처리)

→ **수집 완료된 기록물은 A02 등록의 해외/민간/박물/도서 메뉴로 흘러들어 RG_DOCUMENT에 적재됨**

### §3.2 국가지정기록물 — 행정 지정 절차

#### 3.2.1 지정등록 → `PL_ASSIGNREQ` + `PL_ASSIGNREQFILE`

**목적**: 신청인 접수 또는 담당자 직권으로 국가지정 신청 등록.

**조회 조건**:
- 신청일자 / **신청상태** / 기록물제목 / 신청자명 / **지정여부** / 소장인명

**상태값**:
- **신청상태 (4종)**: 전체 / 신청중 / 검토중 / 승인완료
- **지정여부 (3종)**: 전체 / 지정 / 미정

**등록 필드**:
- **신청구분 (2종)**: 직권등록 (담당자 자체 신청) / 신청서 (외부 접수)
- **기록물제목 구분 (2종)**: 개인 / 법인
- 신청일자 / 소장인 (성명·주민번호·전화·주소) / 신청인 (성명·주민번호·전화·주소·소장인과의관계)
- 첨부파일 (PL_ASSIGNREQFILE에 적재)

#### 3.2.2 지정결과서 등록 → `PL_ASSIGNREQDISCUSS` + `PL_ASSIGN`

**목적**: 심의·결정 결과 등록.

**5단계 일자 관리**:
1. 현장조사일자
2. 검토일자
3. 심의일자
4. 고시일자
5. 인수일자

**심의 통과 시** → `PL_ASSIGN`(국가기록물지정)에 정식 등록 → 보호 대상 기록물로 관리 시작

#### 3.2.3 사후관리 → `PL_ASSIGNAFTERMANAGE` + `PL_ASSIGNAFTERFILE`

**목적**: 지정 후 정기/수시 모니터링 + 이력 관리.

**조회 조건**: 지정번호 / 소유자명 / 기록물제목

**관리상태 (5종)**:
- 관리상태선택 (기본값)
- 소유권변동
- 관리환경불량
- 상태불량
- 기타

**등록 필드 (이력)**:
- 사후관리 안내통보일자 → 소유자에게 통보
- 소유자(성명·주민/법인번호·연락처)
- **조치결과 통보일자** → 소유자가 응답
- 첨부파일

**조회 추가**:

## 6. 다른 영역과의 연계

### 6-1. 기획수집 → 등록(A02)
```
PL_PLANRECORD (수집현황)
       ↓ 수집 완료
A02 등록 메뉴 진입:
  ├ §2.1.6 해외기록물 → RG_DOCUMENT (ARCAVETYPE=06)
  ├ §2.1.7 민간기록물 → RG_DOCUMENT (CHOICE_DIV=01/02)
  ├ §2.1.4 행정박물   → RG_DOCUMENT + RG_ADMIN_ADDINFO
  └ §2.1.5 구술기록   → RG_ORAL_ARCHIVE (별도 키)
```

→ PL_PLANRECORD에는 "어떻게 수집했는가"만, 정작 기록물 메타는 RG_*에 적재.
→ 두 영역 연결 키는 명시되지 않음 — **PL_PLANRECORD ↔ RG_DOCUMENT 외래키 매핑 검증 필요**.

### 6-2. 국가지정기록물 → 민간기록물 등록
```
PL_ASSIGN (지정 완료)
       ↓
A02 §2.1.7 민간기록물 → RG_DOCUMENT (CHOICE_DIV=01 지정기록물)
                                    또는 02 위탁기록물
```

→ `CHOICE_DIV` = 01:지정기록물 / 02:위탁기록물 (인수 학습문서 §3-1에서 발견).
→ 즉 **CHOICE_DIV=01인 RG_DOCUMENT 행 = PL_ASSIGN에 대응되는 국가지정기록물**.

## 7. 미확정 / 검증 필요 사항

1. **PL_PLANRECORD ↔ RG_DOCUMENT 연결 키** — 수집 결과가 등록으로 흘러갈 때 어떤 키로 매핑되는지 (BSID 부여 시점·방식)
2. **PL_ASSIGN ↔ RG_DOCUMENT (CHOICE_DIV=01) 매핑** — 지정 결정 후 RG_DOCUMENT 등록 자동/수동 흐름
3. **PL_RECORD 와 SP_OUTCOLLECTION (외부소장물)** — 둘 다 외부 보유 기록 관리. 차이 확인
4. **소재정보조사의 소장인/관리인 컬럼** — 주민번호 저장 여부 (개인정보 보호 영향)
5. **지정해제 후 RG_DOCUMENT 처리** — PL_ASSIGNREVOKE 완료 시 RG_DOCUMENT는 어떻게 변경되는지 (CHOICE_DIV 변경 / 삭제 / 별도 플래그)
