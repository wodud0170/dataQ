## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 전거 = **표준화된 고유명사 사전**. "박정희" / "박정희 대통령" / "故 박정희" 같은 표기 차이를 하나로 통일해 검색·연관 분석 정확도를 높임.

```
[전거가 필요한 이유]
원문에 "박정희 대통령" 검색 → 다른 표기("박정희", "朴正熙") 누락
전거 등록 후 → 검색어 자동 확장 → 모든 표기 매칭

[B01 전거관리 영역]
   ├ XML Import (대량 등록)
   ├ 4종 전거 등록 (기관단체·인물·사건·지명)
   ├ 전거관리·유형관리
   ├ 수정요청·전거후보·삭제후보 워크플로
   └ 통계 (작업자별·기관유형별)
```

**활용**:
- A02 등록 시 인명/법인명 입력 → 전거에서 자동 선택
- A12 검색 시 관련용어 검색 → 전거 기반 검색어 확장
- 외부 공개 시 표준 명칭 사용

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **전거(典據)** | 표준화된 권위 있는 명칭 사전 (Authority Record). ISAAR(CPF) 국제표준 |
| **대표명** | 전거의 공식 명칭 (예: "박정희") |
| **대등명/대등표목** | 같은 의미의 다른 표기 (예: "朴正熙", "P. C. Park") |
| **비채택어** | 비공식 표기. 검색은 되지만 표준은 아님 (예: "차지철의 상관") |
| **세부유형** | 전거 종류 내 세부 분류 (예: 인물 → 정치인/예술가/학자) |
| **존립기간/생몰년일** | 기관 존속 또는 인물 생몰 기간 (FROM~TO) |
| **관계지정** | 기관·인물·사건 간 관계 매핑 (예: "박정희는 새마을운동(사건)을 시작") |
| **상세정도** | 최소 / 전체 / 부분 |

## 1. 워크플로 + 테이블 매핑

```
[전거 4종 등록]
├ 기관단체 전거 (정부기관·공공기관·민간단체)
├ 인물 전거       (대통령·각료·역사인물 등)
├ 사건 전거       (5·18·새마을운동 등)
└ 지명 전거       (행정구역·역사지명)

[수명주기]
신규 등록 → 전거관리 (검색·수정) → 수정요청 → 전거후보 → 삭제후보
                                  ↓
                            관리자 확인 후 반영

[입력 방식]
① XML Import (대량)
② 수동 입력 (단건)
```

### 관련 테이블 (추정)
- **전거 마스터**: `KH_AUTH_*` 또는 별도 전거 영역 (도메인 종합 문서 §4 참조)
- **유형 관리**: 전거 종류별 세부유형 테이블
- **수정요청·후보**: 별도 워크플로 테이블

## 2. 주요 기능 상세

### §1.1.1 전거 XML Import
- 사전 약속된 XML 규격 파일을 업로드
- 대량 데이터 일괄 등록 (외부 시스템 연동)

### §1.1.2 전거 등록 (4종 수동 입력)

#### §1.1.2.1 기관/단체 전거
**주요 등록 필드**:
- 세부유형 / **대표명** (필수)
- 기관코드·기관명 (검색 선택) / 대등코드·대등명
- 기관차수 / **대등표목 / 비채택어**
- **존립기간** (FROM~TO. 현존이면 종료일 비움)
- 설치근거 / 기관역사 / 소재지
- **하위조직변천** (행추가: 일자·규모·내용)
- **주요업무** (행추가: 내용·시작·종료)
- 기능어·기타정보 (행추가)
- **기관장** (행추가: 직책·취임·퇴임·설명)
- **관계지정** (행추가: 관계범주·관계형식·기관/인물/사건명·관계·직책·생성·폐지일)
- 작성규칙·상세정도·작성언어·주기사항·홈페이지·누락사유·참고정보원

#### §1.1.2.2 인물 전거
공통 + 인물 특화:
- 대표인명 / 대등인명 / 비채택어
- **생몰년일** (FROM~TO + 사망여부 체크)
- 본관·본적지·출생지
- 종교 (행추가: 종교명)
- 국적 (행추가: 국적·시작·종료)
- **주요직책** (행추가: 내용·시작·종료)
- **주요경력** (행추가: 경력)
- 관계지정

#### §1.1.2.3 사건 전거
공통 + 사건 특화:
- 대표사건명 / 대등사건명 / 비채택어
- **발생일** (FROM~TO)
- 본관 (어디서?)
- 사건개요
- **발생장소** (행추가: 발생지역)
- 관계지정

#### §1.1.2.4 지명 전거
공통 + 지명 특화:
- 대표지명 / 대등지명 / 비채택어 등 (간략)

### §1.1.3 전거관리

**조회 조건**:
- 전거종류 / 기관코드·기관명 / 기관차수
- 입력일·존폐일 (FROM~TO)
- 최상위·차상위·최하위명 / 유형
- 존폐여부

**액션**:
- XML 저장 / 엑셀 저장 / 초기화
- **상세화면**: 전거정보 / 삭제후보등록 / **연계기록물** 조회

### §1.1.4 유형관리
- 전거 종류별 **세부유형 정의**
- 트리 구조 (대분류 → 세부)

### §1.1.5 수정요청조회
- 외부에서 들어온 **수정요청 검토**
- 상태변경: 확인 중 / 확인완료

### §1.1.6 전거후보조회
- **신규 전거 등록 요청** 처리
- 요청상태 관리

### §1.1.7 삭제후보조회
- **삭제 요청** 처리
- 삭제 / 취소 (후보에서 제거)

### §2. 전거통계
- §2.1 작업자별 통계 (누가 얼마나 입력했나)
- §2.2 기관유형별 통계

| 연계 | 관계 |
|---|---|

## 5. 미확정 / 검증 필요

1. **전거 적재 테이블 정확한 이름** — KH_AUTH_* 추정만 됨
2. **관계지정 데이터 모델** — 다대다 관계인지, 별도 관계 테이블인지
3. **XML 규격** — 외부에서 받는 XML의 정확한 스키마
