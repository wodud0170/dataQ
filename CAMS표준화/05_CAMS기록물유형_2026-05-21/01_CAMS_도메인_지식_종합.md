## 1. CAMS 시스템 개요

### 1-1. 정체

- **CAMS** = 중앙영구기록관리시스템 (Central Archives Management System)
- 운영: 행정안전부 국가기록원
- 도입: **2006년** "개별시스템 통합(문서·시청각 등 **8종 통합**)"
- 짝 시스템: **RMS** (생산기관) — RMS에서 영구이관 대상 → CAMS로 인수

→ **"15종" 이라는 인지의 기원**: 8종 통합 시작 + 등록 매뉴얼의 11종 + 매체·도서 등 = 약 15종

### 1-2. 시스템 변천 (1장 소개)

| 시기 | 사건 |
|---|---|
| 1999 | 공공기관의 기록물관리법 제정 |
| 2001~2005 | 자료관시스템 → 기록관시스템 |
| **2006** | **CAMS 출범 (8종 통합)** |
| 2007 | 세부기능 확대, RMS 연계 |
| 2008~2010 | 비밀기록물·웹기록물 수집 등 |
| 2012 | 행정박물 3D 스캐닝 |
| 2013 | 전자기록물 인수 개편 |
| 2014~2015 | 비정형 통계, 기계검수 |
| 2016 | 전자기록물 이관규격 간소화 (8종 → 1종) |
| 2017 | NEO 규격 변경 |

### 1-3. 핵심 개념

- **NEO** (NAK's Encapsulated Object) = 전자기록물 장기보존 단위 객체. XML + PDF/A-1 + 전자서명 + 메타데이터를 묶은 컨테이너
- **장기보존포맷** = PDF/A-1 (텍스트), TIFF/JPEG/PNG (이미지 등)
- **BSID** = 기록물철 ID (Basic Series ID)
- **DSID** = 기록물건 ID (Detail Series ID)
- **MBSID/MDSID** = 인수 단계의 임시 BSID/DSID (이관 영역, RG_M*)
- **BRM** = 정부기능분류체계 (기능·목적·조직)
- **단위과제** = 기능분류의 최하위 단위 (8자리 코드)

## 3. 인수 → 등록 워크플로 (2장 인수 매뉴얼)

```
RMS (생산기관)
   ↓ 1. 생산현황관리
   ├ 생산현황접수 (RMS → CAMS)    [W3]
   ├ 생산현황검수
   └ 생산현황확정
   ↓ 2. 인수일정/이관목록확정       [W4]
   ├ 주요프로세스 Map (기록물인수, 품질검사)
   └ 이관검토요청결과통보 (오프라인접수, 승인·통보처리)
   ↓ 3. 이관기록물접수              [W5]
   ├ 온라인 (RMS → CAMS)
   ├ 폐쇄망 RMS / 자료관시스템
   ├ 기록관시스템
   └ 시청각기록물 (별도 흐름!)
   ↓ 4. 육안검수                    [W6]
   ├ 육안검수대상확정 (접수번호목록 → 기록물목록)
   ├ 검수담당자배정현황
   └ 이관기록물검수 (NEO뷰어 검수, 건목록)
   ↓ 5. 전자기록물검수 + N차 품질검사
   ↓ 6. 정식 등록                   [W7]
   = RG_M* (인수영역) → RG_DOCUMENT (관리영역) 승격
```

**핵심 발견**:
- **시청각기록물은 인수 단계에서 별도 흐름** — 2.4.1(5/5) 절. 일반 인수 4단계와 분리
- **온라인 (RMS→CAMS)** vs **폐쇄망 RMS / 자료관 / 기록관시스템** 4가지 인수 경로
- **NEO뷰어** 가 전자기록물 검수의 핵심 도구

## 5. 스키마 분석과 cross-check 결과

### 5-1. ✓ 매뉴얼로 입증된 내 가설

| 가설 | 매뉴얼 증거 |

| RG_DOCUMENT/RG_DETAIL = 모든 등록 기록물의 마스터 | A02 매뉴얼이 모든 유형이 동일한 "철-건" 구조로 등록됨을 보여줌 |
