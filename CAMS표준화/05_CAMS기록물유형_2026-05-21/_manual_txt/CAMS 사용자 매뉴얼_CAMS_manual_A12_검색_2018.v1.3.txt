1) 기록물철상세검색 조회화면
①화면 설명 : 기록물에 대하여 다양한 검색조건과 방식을 통해 다양하고 신속한 기록물을 
검색/활용할 수 있는 기능입니다.
②버튼 설명
검색범위,기록물형태,보존기관,생산기관코드,생산년도,제목을 조회 항목에 입력

중 이중보존매체는 다른 기록물과 함께 검색되지 않으며 전체 선택시 이중보존 
매체는 제외
기록물 철목록에서 제목을 클릭하고 감사증적 버튼을 클릭하면 해당 기록물의 
상태이력을 확인
기록물 철목록에서 제목을 클릭하고 매체평가이력 버튼을 
클릭하면 해당기록물의 매체평가상태를 확인 
기록물 철목록에서 제목을 클릭하고 보존기간평가이력 버튼을 
클릭하면 해당기록물의 보존기간평가이력 확인 
기록물 철목록 제목을 클릭하고 상태검사(점검) 버튼을 클릭하면 해당 기록물의 
상태검사(점검) 상태를 확인 가능 * 상태검사(점검)이력이 있는 경우 출력

12.9.2 원문다운로드
전자기록물 및 전자화기록물에 대한 원문 다운로드를 할 수 있습니다.
1) 원문다운로드
기록물 다운로드 스케줄링 검색 기능을 제공하며, 요청한 기록물 원문을 다운로드 할 수 있습니다.
기본적으로 다운로드 권한이 있는 사용자만 해당 메뉴 접근이 가능하며, 사용자 개인의 다운로드 
스케줄만 조회 및 다운로드가 가능합니다.
①조회항목 설명
스케줄링명
다운로드 스케줄링명을 입력합니다.
스케줄링상태
스케줄링 상태를 선택합니다.
요청일
 버튼을 클릭하여 요청일을 선택합니다.
요청자
 버튼을 클릭하여 요청자를 선택합니다. (관리자만 가능)
②
 : 검색조건에 해당하는 다운로드 스케줄을 조회합니다.
③스케줄링명: 스케줄링명을 클릭하면 해당 스케줄링의 기록물 목록을 확일 할 수 있는 화면으로 
이동합니다.
④
 : 서버 내 파일 다운로드 완료 및 압축 파일 생성이 완료되면, 사용자 PC로 다운로드 합니다.
