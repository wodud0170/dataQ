11.1.1 정보공개처리대장
정보공개처리대장 목록 및 상세정보를 조회, 수정 등의 기능을 제공합니다.
1) 정보공개처리대장 목록조회
①화면 설명 : 정보공개처리대장에 등록된 목록조회
②버튼 설명
조건창에 입력된 조건을 초기화
조건창에 입력된 조건으로 목록을 조회
검색 목록으로 조회 된 정보공개청구서 목록을 액셀형태로 저장
정보공개청구서 접수화면으로 이동

2) 정보공개처리대장 목록 상세보기
①화면 설명 : 공개처리대장 목록에 선택된 목록에 대한 상세보기 제공
②버튼 설명
반출의뢰 버튼을 클릭하여 나타나는 기록물 반출 팝업화면에서 정보공개대상 기
록물을 검색하여 선택 후 반출의뢰를 합니다.
인수 버튼을 클릭하여 반출의뢰한 기록물을 인수 처리합니다.
반입의뢰 버튼을 클릭하여 반출된 기록물을 반입의뢰 처리 할수 있습니다.
소장유무검색 버튼을 클릭하여 출력된 팝업창에서 검색 조건을 입력하여 정보공
개를 원하는 기록물을 조회하고 열람기록물로 등록 할 수 있습니다.
결재상신 버튼을 클릭하여 출력된 팝업창에서 수신자,제목,본문을 입력하고 팝
업창의 결재산싱 버튼을 다시 한번 클릭함으로 해당 내용을 저장 할 수 있습니
다.
삭제버튼을 클릭하면 조회한 정보공개청구서를 삭제 할 수 있습니다. 기록물 반
출입 내용이 없을 경우만 삭제가 가능합니다.
수정으로 버튼을 클릭하면 조회한 정보공개청구서 수정화면으로 이동합니다.
목록으로 버튼을 클릭하면 이전 정보공개청구서 목록 조회 화면으로 이동합니
다.

11.1.3 기록물 반입
①화면 설명 : 정보공개청구서에서 반출 되었던 기록물을 반입의뢰 처리 할 수 있습니다.
②버튼 설명
반입대상조회 버튼을 클릭하여 출력된 팝업화면에서 검색 조건을 입력하고 검
색된 반입대상기록물 목록에서 반입을 원하는 기록물을 선택하여 반입대상건선
택 버튼을 클릭하면 반입의뢰대상 목록으로 선정 할 수 있다.
검색 결과로 출력된 기록물 목록에서 반입대상 기록물을 선택하여 반입대상건
선택 버튼을 클릭하면 반입대상기록물 목록으로 등록됩니다.
버튼을 클릭하면 조회 결과로 나온 기록물 목록을 반입의뢰 할 수 있다.
