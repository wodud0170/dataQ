## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 인수(A01)·등록(A02)에서 "정리의뢰" 처리된 비전자 기록물의 물리적 정리 작업 (라벨링·상자편성·소독). **물리적 보존 준비 단계**.

```
[A01 §1.3.12 정리의뢰] 또는 [A02 §2.1.11 정리의뢰]
                 ↓
        ★ A05 기록물정리 ← 이 문서
        ├ §5.1 정리인수 (의뢰 받음)
        ├ §5.2 표지/색인목록 출력 (철라벨·철표지·색인목록)
        ├ §5.3 상자편성 (보존상자에 담기)
        ├ §5.4 상자라벨출력
        ├ §5.5 정부간행물분류 (C1·C2 분기)
        └ §5.6 소독의뢰
                 ↓
        [A06 서고] 서고배치
```

**왜 필요한가**: 비전자(종이·필름·박물)는 물리 보존 전 라벨·상자편성·소독이 필요. 전자는 NEO 변환만으로 보존 가능하지만 비전자는 손으로 만져야 함.

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **철라벨** | 기록물철 단위에 부착하는 식별 라벨 |
| **철표지** | 철의 표지 (소개 페이지) |
| **색인목록** | 철 안의 건 목록 (목차 같은 것) |
| **보존상자** | 기록물을 담는 표준 상자 (대/소/제작상자) |
| **상자편성** | 여러 철을 1개 보존상자에 묶음 |
| **소독의뢰** | 비전자 기록물의 곰팡이·해충 제거 처리 |
| **C1 (서고보존)** | 정부간행물의 보존용 사본 (소독 → 서고) |
| **C2 (스캐닝의뢰)** | 정부간행물의 활용용 사본 (스캔 → 디지털) |
| **M/F** | Microfilm. 마이크로필름 |

## 1. 워크플로 + 테이블 매핑

```
[A05 기록물정리 워크플로]

§5.1 정리인수            정리의뢰서 인수 / 반려 / 일괄인수
       ↓
§5.2 표지·색인 출력       철라벨·철표지·색인목록 출력
       ↓
§5.3 상자편성            보존상자 크기 입력 → 상자에 담기
       ↓
§5.4 상자라벨출력         상자에 부착할 라벨
       ↓
§5.5 정부간행물분류       C1(서고보존) → 소독, C2(스캐닝) → 디지털화
       ↓
§5.6 소독의뢰            제본완료 기록물 소독
       ↓
[A06 서고배치]
```

**관련 테이블 (추정)**:
- 정리의뢰서: `CM_DESC_CLASS_TEMPKEEP_DOC` (기술분류임시보관함내역 — 의뢰서로 추정)
- 상자편성: `RG_DOCUMENT.BOX_TYPE` (1:보존상자(소) 2:보존상자(대) 3:제작상자) + `BOX_CLASS_SEQ_NO`
- 라벨·태그: `ST_RFIDTAG` + `RF_*`
- 소독: SV_PRESERV_* 계열 (보존 영역)

## 2. 주요 기능 상세

### §5.1 기록물정리인수
- **조회 조건**: 등록위치(서울/부산/대전/부산), 인수일, 의뢰부서, 의뢰일, 의뢰자, 기록물종류, 관리번호, RFID 발행여부
- **액션**: 인수 / 반려 / 일괄인수 / 라벨출력 / 엑셀저장
- 정리인수 처리 시 **인수일** 자동 기록

### §5.2 표지/색인목록 출력
- **§5.2.1 철라벨출력**: 조회 후 다중 선택 가능
  - 철라벨 / 철표지 / 색인목록 (색인목록만 단일 선택)
  - **서고배치 의뢰** 가능 — 단, **시청각·행정박물·구술기록·이중보존매체**만
- **§5.2.2 철라벨출력(전체)**: 서고/서가/련/단/관리번호 단위로 일괄 출력

### §5.3 상자편성
- **조회 조건**: 기록물상태 (**상자편성대상/제본/서고**), 서고위치, RFID
- **등록 필드**: 상자종류 + 가로(장)·세로(고)·폭·무게(kg)
- 시청각·행정박물·구술기록·이중보존매체는 서고배치 의뢰 가능

### §5.4 상자라벨출력
- 일반/민간기록물 라벨 별도 출력
- 상자편성 취소 가능

### §5.5 정부간행물분류 — 복본 분기
- **C1 (서고보존)**: 보존용 복본 → 소독의뢰
- **C2 (스캐닝의뢰)**: 활용용 복본 → 스캐닝 (디지털화)
- 같은 간행물의 복본을 용도별로 분리

### §5.6 소독의뢰
- 제본 완료 기록물만 소독 의뢰
- 시청각기록물만 서고배치의뢰 가능 (다른 유형은 별도 흐름)

## 3. 코드값·상태값

### 3-1. 등록위치 (보존시설)
서울 / 성남 / 대전 / 대전기록관 / 부산

### 3-2. 기록물상태 (상자편성용)
상자편성대상 / 제본 / 서고

### 3-3. 상자종류
보존상자(소) / 보존상자(대) / 제작상자

### 3-4. 정부간행물 복본구분
C1 (서고보존) / C2 (스캐닝의뢰)

### 3-5. 출력 가능 라벨 종류
철라벨 / 철표지 / 색인목록 / 상자라벨

### 3-6. RFID 발행여부
미발행 / 발행

## 5. 미확정 / 검증 필요

1. **정리의뢰서 적재 테이블** — 매뉴얼에 명시 안 됨. CM_DESC_CLASS_TEMPKEEP_DOC 또는 별도 RG_정리* 테이블 가능성
2. **상자편성 적재** — RG_DOCUMENT의 BOX_* 컬럼 직접 갱신인지, 별도 상자 마스터 테이블이 있는지
3. **C1/C2 복본구분** — RG_GOVTMASTER의 BOOK_GUBUN과 매핑되는 코드인지
