## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **소독** | 곰팡이·해충 제거 (감마선·훈증·저온 등) |

| **탈산** | 산성지의 산을 중화 (종이 수명 연장) |

| **매체이전** | 시청각 매체 노후화 시 새 매체로 |
| **현장조치** | 반출·입 없이 서고 내에서 직접 처리 |

## 1. 워크플로 + 테이블 매핑

```
[공통 패턴 — 11 영역 모두]
스케줄링 → (의뢰접수) → 작업 → 결과 조회

[특수: 복원]
스케줄링 → 의뢰접수 → 복원 → (현장조치 옵션) → 결과조회

[특수: 행정박물]
인수 (별도) → 스케줄링 → 처리 → 검색

[특수: 종이복제]
스케줄링 → 외부복제 의뢰접수 → 복제 → 검색
```

### 관련 테이블 (추정)
- **공통 스케줄링**: `SV_JOB_SCHEDULE_*` 계열
- **보존처리**: `SV_PRESERV_PROCESS_LIST` (보존처리내역)
- **상태평가**: `SV_ARCHIVE_CONDITION_TABLE / _TAB2` (철 상태), `SV_DOCUMENT_CONDITION_TABLE` (건 상태)
- **상태표준**: `SV_ARCHIVE_STANDARD2 / _3` (조사내역)
- **점검**: `SV_QUANTITY_CHECK_LIST`
- **복원요청**: `SV_PRESERV_REQUEST_ARCHIVE`
- **복원 전후**: `SV_PAPER_RESTOR_TAB`
- **시청각 매체이전**: `SV_MEDIA_MIGRATION_LIST`, `SV_JOB_SCHEDULE_TRANS_MEDIA`
- **행정박물 평가**: `SV_ARCHIVE_CONDITION_TAB3 / SV_ARCHIVE_STANDARD3`
- **박물 보존처리**: `SV_GOVTOBJ_PRESERV_INFO`
- **평가 분류**: `SV_ARCHIVE_PARITY / _HIS`

## 2. 주요 기능 상세

### §7.1 소독 (2 하위)
- **소독 스케줄링**: 스케줄링명·소독예정일·소독담당자·비고 + 대상선정
- **소독 처리**: 결과 등록

### §7.2 상태검사(점검) (4 하위)
- §7.2.1 스케줄링
- §7.2.2 점검 (스케줄 목록 → 기본목록 → 세부목록)
- §7.2.3 상태검사 검색
- §7.2.4 상태·정수점검 (전자)

### §7.3 제본 (2 하위)
- 스케줄링 + 제본

### §7.4 탈산 (3 하위)
- 스케줄링 + 탈산 + 결과조회

### §7.5 복원 (5 하위)
- §7.5.1 스케줄링
- §7.5.2 복원의뢰 접수
- §7.5.3 복원 (스케줄링 목록 조회)
- §7.5.4 **복원(현장조치)** — 반출입 없이 현장에서
- §7.5.5 결과조회

### §7.6~§7.7 디지털복원
- §7.6 시청각용 (3 하위)
- §7.7 종이기록물용 (3 하위)
- 각각 스케줄링·처리·결과조회

### §7.8 보존처리(시청각) (4 하위)
- 스케줄링·의뢰접수·처리·결과조회

### §7.9 보존처리(행정박물) (4 하위)
- §7.9.1 인수 (별도 인수 절차)
- §7.9.2 스케줄링
- §7.9.3 처리
- §7.9.4 검색

### §7.10 종이기록물 복제 (4 하위)
- 복제 스케줄링
- **외부복제 의뢰접수** (외부 업체 의뢰)
- 복제
- 검색

### §7.11 매체이전(시청각) (3 하위)
- 매체이전 스케줄링
- 매체이전
- 매체관리번호 부여
