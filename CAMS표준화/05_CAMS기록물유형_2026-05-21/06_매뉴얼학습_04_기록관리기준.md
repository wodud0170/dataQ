## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: 모든 기록물 적재의 **기준이 되는 마스터데이터**(분류체계·보존기간) 관리. 인수/등록/검색이 다 이 기준을 참조함.

```
[A04 기록관리기준 = 마스터데이터 영역]
        │
        ├ §4.1 준칙관리 (보존기간 책정 기준)
        │   ├ 고유업무준칙   (각 부처만의 업무)
        │   ├ 공통업무일정표 (모든 부처 공통)
        │   ├ 공통업무보존기간표 (기관/처리과 공통)
        │   └ 기록관리준칙 (기관별 단위과제)
        │
        ├ §4.2 단위과제 보존기간관리 (RMS→CAMS 협의 워크플로)
        │   ├ 단위과제접수 → 조정 → 승인/통보 → 재통보
        │
        ├ §4.3 기록관리기준표 검색
        ├ §4.4 기록물 분류 기준표 (2004년부터, BRM 기반)
        └ §4.5 공문서보존기간표 (2004년 이전, 연도별 별도)
```

**왜 중요한가**: 등록·인수 시점에 "이 기록물 보존기간이 몇 년인가?"를 결정하려면 여기서 만든 단위과제·준칙을 참조. 잘못 책정하면 영구보존돼야 할 것이 폐기되거나, 폐기돼야 할 것이 영구 적재됨.

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **BRM** | Business Reference Model. **정부기능분류체계**. 기능·목적·조직 3축으로 정부 업무를 분류한 표준 (2004년~) |
| **단위과제** | BRM의 최하위. 8자리 코드. "어느 업무 단위인가" 식별 단위. 보존기간 책정 단위 |
| **준칙** | 보존기간을 어떻게 책정할지에 대한 **규칙·근거** |
| **고유업무** | 그 부처만 수행하는 업무 (예: 외교부의 비자 발급) |
| **공통업무** | 모든 부처가 공통으로 하는 업무 (예: 회계, 인사) — 기관공통 / 처리과공통으로 분리 |
| **영역분류** | 공통업무를 묶는 큰 분류 |
| **소기능** | 영역분류 안의 작은 분류 |
| **대/중/소분류** | 기관별 준칙의 분류 계층 |
| **2004년 분기점** | 2004년 정부기능분류시스템 시행 → 이전은 공문서보존기간표, 이후는 BRM |

## 1. 워크플로 + 테이블 매핑

### 1-A. 마스터데이터 영역 (CM_* 접두사)

**CM = Code Master**. 분류체계·코드 마스터를 보관하는 영구 영역.

```

   ├ CM_SKILL_DIVSYS_HIST   (이력)
   ├ CM_UNITBS_SKILLDIV     (단위업무 기능분류 매핑)
   ├ CM_ORGAN_SKLDIV        (기관별 기능분류)
   ├ CM_SKLDIV_REFLAW       (관련 법령)
   ├ CM_SKLDIV_REFINFOSYS   (관련 정보시스템)
```

## 2. 주요 기능 상세

### §4.1 준칙관리

**4단계 트리** — "어떤 업무인가"를 단위과제까지 좁히는 분류 체계:

| 단계 | 공통업무 | 기관별 (기록관리준칙) |
|---|---|---|
| 1 | 기준년도 (SM_RULE_YEAR) | 시행년도 (SM_RULE_YEAR_ORGAN) |
| 2 | 영역분류 (SM_AREA_CTGR) | 대분류 (SM_RULE_CTGR) |
| 3 | 소기능 (SM_CTGR_LTL_TITLE) | 중분류 (SM_RULE_MID_CTGR) |
| 4 | 단위업무 (CM_UNIT_TASK) | 단위과제 (SM_DOC_RULE) |

→ 각 단위에 보존기간(1~영구 8종)이 책정됨.

**기준년도 일괄복사**: 신규 시행년도 등록 시 기존 년도의 모든 분류·소기능·단위과제 데이터를 **신규년도로 일괄 복사** (해마다 처음부터 만들지 않도록 자동화).

### §4.2 단위과제 보존기간 관리 워크플로

```
[RMS (각 부처 기록관)]      [CAMS (국가기록원)]
       │
       │  단위과제 보존기간 조정 요청
       │  (온라인 자동 / 오프라인 XML 파일)
       ↓
       단위과제접수 (4.2.1)              → SM_UNITSBJ_RECEIPT
       │
       단위과제조정 (4.2.2)
       │  ├ 4.2.2.1 조정현황 (처리상태)
       │  └ 4.2.2.2 보존기간조정 (분류체계 검색 + 조정)
       │  (조정사유 입력)
       ↓
       단위과제승인/통보 (4.2.3)         → 미확정 → 확정 → 통보
       │
       파일생성·다운로드 (4.2.4)         → 오프라인 통보용
       │
       단위과제승인 재통보 (4.2.5)       → 온라인 재통보
```

### §4.3~§4.5 검색·기준표

- **§4.3 기록관리기준표 검색**: 보존기간/분류년도/기관유형/과제유형 등으로 조회
- **§4.4 기록물 분류 기준표**: **2004년부터** 생산된 기록물용. BRM 기반 연계
- **§4.5 공문서보존기간표**: **2004년 이전** 생산된 기록물용
  - 4.5.1 통합 / 4.5.2 연별 (1964/1979/1984/1992/1997년도 별도 보관)

## 3. 코드값·상태값

### 3-5. 단위업무 구분 (4종)
처리과공통 / 기관공통 / 유사공통 / 고유업무

기관공통업무 / 처리과공통업무

## 4. 다른 영역과의 연계

### 4-1. 인수·등록과의 관계
```
A04 기록관리기준 (마스터 책정)
       ↓ 보존기간·분류체계가 확정되면
A01 인수 / A02 등록
   ├ 기록물철 등록 시 분류체계 선택 (BRM → 단위과제)
   ├ 보존기간 책정 (CM_CLASS_BASTABLE 참조)
   └ RG_DOCUMENT.KIKAN, DOCBUNRYUNO 등 컬럼에 기록
```

### 4-2. RMS와의 연계
- RMS가 단위과제 보존기간 조정 요청 → CAMS 접수 → 조정 → 통보
- 온라인: 대용량송수신 / 오프라인: XML 파일

### 4-3. 외부 시스템
- **정부기능분류시스템**: BRM 마스터 제공
- **행정표준코드시스템**: 기관코드 표준

1. 이지원분류체계와 BRM의 정확한 관계 (이지원 = 청와대 업무관리시스템?)
