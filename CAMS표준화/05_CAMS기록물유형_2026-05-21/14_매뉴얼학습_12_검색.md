## 0. 본 문서의 위치

> 🎯 **한 줄 요약**: CAMS 내부 사용자(직원·연구자)가 보존된 기록물을 **검색·조회·다운로드**하는 화면. 외부용(국가기록포털)과 별개.

```
[보존된 기록물 (RG_DOCUMENT 등)]
        ↓
   ★ A12 검색
   ├ §12.1 기록물철상세검색 (가장 많이 쓰는 화면)
   ├ §12.2 기록물건상세검색
   ├ §12.3 신통합검색 (검색엔진 + 패싯)
   ├ §12.4 MF색인대장 (보존/열람)
   ├ §12.5 일제강제연행자 (특수 도메인)
   ├ §12.6 지적·임야원도 (특수 도메인)
   ├ §12.7 기술분류검색 (ISAD(G) 군/계열)
   ├ §12.8 통합검색 (철·건·데이터세트)
   └ §12.9 원문다운로드 (스케줄링 + 압축 다운)
```

## 🎓 약어 빠른 풀이

| 용어 | 풀이 |
|---|---|
| **패싯(Facet)** | 검색 결과를 다각도로 필터링 (검색범위·기간·보존기간 등 사이드 필터) |
| **NEO 뷰어** | 장기보존포맷 NEO 파일 전용 뷰어 |
| **통합 Viewer** | 모든 원문 통합 조회 도구 (워터마크·인쇄·페이지 이동 등) |
| **워터마크** | 인쇄·저장 시 원문 위에 부착하는 표시 (좌상·우상·중앙·좌하·우하 / 기본·대·소) |
| **감사증적** | 기록물 상태 변경 이력 추적 |
| **MF색인대장** | 마이크로필름 보유 현황 대장 |
| **기술분류** | ISAD(G) 표준에 따른 군/계열/컬렉션 분류 |
| **데이터세트** | 행정정보 데이터셋 (정형 데이터) |

## 1. 워크플로 + 테이블 매핑

```
[일반 검색]                    [원문 활용]

§12.2 건 상세검색  │
§12.3 신통합검색  ├→ 통합 Viewer ─→ 워터마크 → 인쇄/저장
§12.8 통합검색    │       ↓
                  │   §12.9 원문다운로드 (스케줄링)
                  │
[특수 도메인]      │
§12.4 MF색인대장   │
§12.5 일제강제연행자│
§12.6 지적/임야원도│
§12.7 기술분류    ─┘
```

### 관련 테이블 (추정)
- **검색 엔진**: K2 또는 Konan (코난) — `KN_SEARCH_INDEX_LOG`
- **다운로드 스케줄**: `SV_ORGD_DWLD_*` (원문다운로드 요청)
- **TIF 다운로드 로그**: `SM_TIFDOWNLOG`
- **MF**: `SV_MF_*`
- **일제강제연행자**: `RG_DETILJAE / RG_DETILJAE_DETAIL` (§02 비전자기록물 분석에서 발견)
- **기술분류**: `CM_DESC_CLASS_*`

## 2. 주요 기능 상세

### §12.1 기록물철상세검색 — 가장 많이 쓰는 화면

**조회 조건**:
- 검색범위 (이중보존매체는 별도)
- 기록물형태 / 보존기관 / 생산기관코드 / 생산년도 / 제목

**추가 액션 (제목 클릭 후)**:
- **감사증적** — 상태 이력
- **매체평가이력** — 매체 평가 상태
- **보존기간평가이력** — 보존기간 평가 이력
- **상태검사(점검)** — 점검 상태
- **복원요청** — 복원 요청 + 목록 (반출/반입 없이 현장 조치 가능)
- **다운로드** — 원문/활용본
- **다운로드(신규)** — PDF 변환 + 워터마크 + 스케줄링

**유형별 추가 정보**:
- 행정박물 → 보존처리서·보존처리결과·행정박물상세
- 시청각 → 매체평가이력·저작권
- 민간 → 민간기록물상세
- 공개재분류이력 (모든 유형)

### §12.2 기록물건상세검색
- 생산기관코드·생산년도·제목 + 철 내부 건 목록 + 세부정보 이미지

### §12.3 신통합검색 — 검색엔진 기반
- **검색범위/생산년도/검색어/생산기관코드/공개구분/검색대상** 입력
- **통합기관코드 검색** + 연혁정보 조회
- **관련용어 검색** — 검색어 확장
- **패싯(Facet)**: 검색범위·생산기간·보존기간으로 결과 내 재조회
- 결과 → 기록물상세정보 / 철정보 / 건세부정보 드릴다운

### §12.4 MF색인대장 (마이크로필름)

#### §12.4.1 MF색인대장(보존)
- 서고에 배치된 MF 현황
- 조건: 사용필름·필름규격·서고·서가·련·단·순
- 촬영일자가 "수집"으로 표시되면 외부 수집 MF

#### §12.4.2 MF색인대장(열람)
- 열람용 MF 검색
- 조건: 생산년도·필름번호·문서번호·**대전·서울·부산함번호** (지역별 보관)·부처명·단위기관명·기록물명

### §12.5 일제강제연행자
- 성명·생년월일·본적지·연행지로 검색
- 이미지 View로 원문 확인

### §12.6 지적/임야원도
- 지번·지명·지목·이름(인명) 검색
- 지적원도 / 임야원도 분기

### §12.7 기술분류검색 — ISAD(G) 표준

**3단계 트리**:
- **군기술서** — 최상위 (예: "조선총독부 기록물군")
- **계열기술서** — 군 하위 (예: "내무부 계열")
- **컬렉션·컬렉션계열** — 별도 분기

**분류기록물**:
- 분류된 기록물 목록 + 기술서 작성여부·보존기간재분류여부 검색
- NEO 뷰어 직접 진입 가능

### §12.8 통합검색
- **철·건·데이터세트** 다중 선택 검색
- 조건 항목 + 연산자 + 검색어

### §12.9 원문다운로드 — 권한 기반

#### §12.9.1 다운로드스케줄링
- **개인 단위 스케줄링** (관리자만 타인 조회)
- 등록 필드: 스케줄링명·파일유형 구분·**PDF 통합 여부**·**워터마크 적용 여부**·다운로드 사유
- 대상선정 → 다운로드 요청

#### §12.9.2 원문다운로드
- 서버 압축 완료 후 PC로 다운로드
- 대용량은 분할 압축

## 3. 코드값·상태값

### 3-1. 워터마크 위치 (5종)
좌상단 / 우상단 / 중앙 / 좌하단 / 우하단

### 3-2. 워터마크 크기 (3종)
기본 (화면 가로 약 30%) / 대 (130%) / 소 (60%)

### 3-3. MF 보관 지역
대전함 / 서울함 / 부산함

### 3-4. 기술분류 구분 (5종)
전체 / 군 / 군계열 / 컬렉션 / 컬렉션계열

### 3-5. 통합검색 대상 (3종, 다중선택)
기록물철 / 기록물건 / 데이터세트

### 3-6. 스케줄링 상태
다운로드 스케줄 진행 단계 (상세 코드 미확인)

### 3-7. PDF 통합 여부
전자화-열람용 파일에 대한 철 단위 PDF 통합 여부
