# Phase 0 — 단어사전 후보 / 행안부 표준단어 대조 리포트

> 대상: `CAMS_SCHEMA_원본.xlsx` 컬럼정의 12,818건
> 방법: 컬럼 코멘트를 행안부 표준단어(tb_word 3,281건) + **이음동의어** 기준 최장일치 분해
> 전체 후보 원본: `단어후보_전체.tsv`

## 1. 분해 통계 (이음동의어 흡수 적용)
| 구분 | 컬럼수 | 비율 |
|---|---|---|
| 전체 컬럼 | 12,818 | - |
| 코멘트 없음 (보류) | 429 | 3.3% |
| **표준화 대상** | **12,389** | 100% |
| ├ 행안부 표준단어 100% 분해 | 8,085 | **65.3%** |
| ├ 부분 분해 (표준 + 미존재 혼재) | 4,073 | 32.9% |
| └ 전부 미매칭 | 231 | 1.9% |

> 정책 확정: **변형 표기는 행안부 표준으로 통일** (신규 DB 구축이므로 기존 표기 보존 불필요).
> 위 분해는 **행안부 표준단어에 이미 등록된 이음동의어**를 활용한 것 — `이름`→`명`(757),
> `년도`→`연도`(268), 영문 `ID`→`아이디`(1,999). 표준사전은 일절 변경하지 않음.
> 분해율 49.4% → **65.3%** 상승, 영문 `ID` 1,500건 전량 해소.

### 분해잔여 (단어 아님 — 사전 보강 후 재분해 시 소멸)

### 수량/기간 표기
`1차`/`2차`(차수), `1년`/`3년`/`5년`/`10년`(보존기간) 형태. 숫자+단위 → 단어 `차수`·`년` 처리 검토.

## 4. 영문 혼입 잔여 (정책 적용 후)
`ID`/`SID` 해소 완료. 남은 영문 (247종): `S`(287, SID의 잔여), `SYNC`(57), `NEO`(23), 코드값 단일문자 `M/F/Y/V` 등. 대부분 코멘트 자체 품질 문제 → 코멘트 정정 또는 개별 처리.

## 5. 데이터 정제 선행 항목
- 코멘트 앞뒤 공백 217건 → trim
- 코멘트 오타 (예: `마이그레션`→`마이그레이션`) → 정정
- 괄호 부가설명 `매체유형코드(...)` → 본문/부가설명 분리
