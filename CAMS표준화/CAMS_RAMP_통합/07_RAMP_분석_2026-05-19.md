# RAMP 스키마 표준화 상태 분석 (2026-05-19)

> **상황 변경**: CAMS↔RAMP **DB 통합** — CAMS가 **RAMP 스키마로 흡수**되는 형태로 결정됨.
> 기존 방향(CAMS 자체를 기관표준화)에서 **RAMP 우선 + CAMS 흡수**로 전환.
> 본 문서: 통합 진행 전 RAMP 현재 표준화 상태 진단 + CAMS↔RAMP 매핑 규모 측정.

> 입력: `ramp기관스키마정보.xlsx` (테이블목록 시트 + 컬럼 시트)
> 비고: 테이블 목록과 컬럼 목록이 일부 안 맞을 수 있음 (현 단계 무시).

## 1. RAMP 기본 통계

| 항목 | 수치 | 비고 |
|---|---|---|
| 테이블 | **365** | CAMS 773의 절반 미만 |
| 컬럼 | **5,777** | CAMS 12,818의 45% |
| 컬럼한글명 종류 (= 용어 후보) | **2,040** | |
| 데이터타입 분포 | STRING 89% / NUMERIC 9% / CHAR 1.4% / INTEGER·DATETIME·DATE 극소 | ⚠️ DATETIME 7건·DATE 4건뿐 |
| 도메인 (타입+길이) 종류 | **82** | |

**⚠️ 시간 타입 거의 없음** — 일자/일시 류 컬럼이 대부분 STRING으로 저장돼 있음. 향후 도메인 표준 매칭에서 큰 정정 대상.

## 2. 명명 일관성

| 검사 | 결과 | 평가 |
|---|---|---|
| 영문명 1 → 한글명 N (영문명 중의성) | **0종** | ✅ 완전 1:1 |
| 한글명 1 → 도메인 N (도메인 불일치) | **177종 / 2,040 (8.7%)** | 🔴 표준화 불완전 |

**도메인 불일치 심한 사례:**
| 한글명 | 도메인 개수 | 예 |
|---|---|---|
| 순번 | **8** | INTEGER(10) / NUMERIC(5) / NUMERIC(6) / NUMERIC(10) / NUMERIC(35) … |
| 변경사유 | 5 | STRING(100) / 200 / 500 / 600 / 4000 |
| 파일아이디 | 4 | STRING(13) / 19 / 35 / 60 |
| 파일명 | 4 | STRING(100) / 200 / 256 / 500 |
| 오류코드 | 4 | STRING(1) / 5 / 14 / 15 |
| 보고기록물수·보고기록물철수 | 4 | NUMERIC(7/10/15/38) |

→ **같은 의미 컬럼의 데이터타입·길이가 들쭉날쭉.** RAMP 자체에 도메인 통일 작업이 필요.

## 3. 행안부 + CAMS 기관표준 단어사전으로 RAMP 분해

현재 단어사전 = 행안부 공통표준 3,281 + CAMS 기관표준 145 (방금 적재) = **3,426단어**.

| 분해 결과 | 종류 단위 | 컬럼 단위 |
|---|---|---|
| 완전분해 (모든 단어가 표준에 있음) | **1,421 / 2,040 (69.7%)** | **3,991 / 5,777 (69.1%)** |
| 부분분해 (일부 미존재) | 614 (30.1%) | — |
| 전체실패 | 5 (0.2%) | — |

→ RAMP 컬럼명의 **약 70%가 현재 단어사전으로 표준화 가능**, **30%는 추가 단어 큐레이션 필요**.
CAMS의 분해율(71.7%)과 유사한 수준.

## 4. CAMS ↔ RAMP 매핑 규모

| 비교 | 결과 |
|---|---|
| 한글명 교집합 (CAMS AFTER 표준한글명 2,941 vs RAMP 한글명 2,040) | **262종** |
| CAMS에만 있는 한글명 | 2,679 |
| RAMP에만 있는 한글명 | 1,778 |
| 영문컬럼명 교집합 | **0종** ⚠️ |

**의의:**
- **한글명 262종은 같은 의미 컬럼** — 흡수 시 직접 매핑 가능 (공개여부·검수일자·관리번호·기관코드·기능분류명 등 기록관리 공통 용어).
- **영문컬럼명은 완전히 다름** — CAMS의 표준명은 행안부 약어 조합(`_build.py` 산물), RAMP는 자체 명명. **통합 시 영문명 컨벤션을 어느 쪽으로 갈지 결정 필요**.

**CAMS 신규 145단어 중 RAMP에도 등장: 33개** (감독·감염·경광등·광·기록물건·납본·메타·복제·비밀·사료·서고·시청각 등). → CAMS 단어 등록이 RAMP에도 직접 적용됨. **헛수고 아님.**

## 5. 통합 전략 — 결정 필요 항목

### D9 (신규). 영문명 컨벤션
- **선택지 (a)**: RAMP 영문명 컨벤션 따름 (RAMP 우선 정책 충실, but CAMS 표준화 산출물 영문명 재작성 필요)
- **선택지 (b)**: 행안부 약어 조합(`_build.py` 방식)으로 통일 (RAMP 영문명도 재작성)
- **선택지 (c)**: 양쪽 영문명 보존, 표준 용어는 한글명만 통일

### D10 (신규). RAMP 도메인 불일치 177종 정리
- 같은 한글명의 도메인을 어느 쪽으로 통일할지 그룹별 결정 (`순번`·`변경사유`·`파일명` 등)
- 도메인 표준(`TB_DOMAIN`, 128종) 매칭 검증

### D11 (신규). CAMS↔RAMP 매핑 표
- 262 직접매핑 + 의미 매핑 후보 발굴 (영문명 다른데 의미 같은 경우)
- 흡수 후 잔여 CAMS-only 컬럼 처리 정책 (신규 추가 vs 기존 RAMP 컬럼 재사용)

### D12 (신규). RAMP 추가 단어 큐레이션
- RAMP 부분분해 614종 → 미존재 단어 발굴 → 행안부 매핑 또는 기관표준 신규 등록
- 기존 CAMS 큐레이션 방식(`_curate.py`)을 RAMP에도 적용

## 6. 권고 작업 순서

```
A. RAMP-only 단어 큐레이션  (614 부분분해 해소)
   ↓
B. RAMP 도메인 불일치 177종 정리  (D10)
   ↓
C. 영문명 컨벤션 결정  (D9)
   ↓
D. CAMS↔RAMP 매핑 표 작성  (D11)
   ↓
E. 통합 02_BEFORE_AFTER 재생성 + 용어·도메인 등록
```

기존 CAMS 단어 145건 적재는 그대로 유효 (RAMP에도 33개 직접 매칭, 나머지도 기록관리 공통 용어).
