## 2. 도메인 일관성 진단

### 2-1. 다중도메인 용어 — 같은 한글명·여러 타입/길이
**177종 (전체 용어의 8.7%)** — 같은 의미인데 컬럼마다 데이터타입/길이가 들쭉날쭉.

심한 사례 상위:
| 용어 | 도메인 개수 | 분포 |
|---|---|---|
| 순번 | **8** | INTEGER(10)×23 / NUMERIC(6)×22 / NUMERIC(38)×6 … |
| 변경사유 | 5 | STRING(100/200/500/600/4000) |
| 파일아이디 | 4 | STRING(13/19/35/60) |
| 파일명 | 4 | STRING(100/200/256/500) |
| 오류코드 | 4 | STRING(1/5/14/15) |
| 보고기록물수 / 보고기록물철수 | 4 | NUMERIC(4~38) |

→ 산출: `RAMP_도메인불일치_진단.tsv` (177행, 도메인 분포 포함)

### 2-2. 형식 suffix ↔ 실제 도메인 불일치
한글명 끝 형식단어가 기대하는 도메인과 다른 케이스. **45종** 검출.

대표 사례:
- `~일자` 인데 **STRING(14/17) 또는 CHAR(8)** — `검색일자` STRING(17), `종료일자`·`이관일자`·`파기등록일자` CHAR(8)
- `~일시` 인데 **DATE / STRING(8/15) / CHAR(14)** — `정정일시` DATE, `배포일시` STRING(8), `접수시작일시·종료일시` STRING(15)
- `~여부` 인데 **STRING(2)** — `스캔검사완료여부`

→ 산출: `RAMP_suffix_도메인불일치.tsv`

### 2-3. 시간 컬럼이 거의 STRING
DATETIME 7건 + DATE 4건만 = **0.2%**. 일자/일시 컬럼 거의 전부가 STRING.
→ 실제 데이터 타입 정정 + 도메인 표준 매칭이 큰 작업.

## 3. 용어 구성 (R8) — 형식단어로 끝나는가

용어 = `업무단어 + 형식단어` 구성 충족 검사 (R8).
행안부 형식단어 545종 기준 매칭.

| 결과 | 용어 종류 | 컬럼수 |
|---|---|---|
| 형식단어로 끝남 (R8 OK) | 1,474 (72.3%) | 4,436 (76.8%) |
| **미종결 (R8 위반)** | **566 (27.7%)** | **1,341 (23.2%)** |

### 미종결 566종의 성격 — 둘로 나뉨

**(a) 코멘트정정으로 자동 해결 가능 (변형어 → 행안부 표준어)**
이미 `코멘트정정_규칙.tsv` 에 있는 규칙 적용 시 R8 충족:
| 변형어 → 표준어 | RAMP 영향 사례 |
|---|---|
| `순번 → 일련번호` | 순번(58), 인수순번(17), 이관그룹순번(17), 문서유형순번(12), 정렬순번(5) 등 |
| `년도 → 연도` | 생산년도(45), 인수년도(28), 이관년도(22), 재분류년도, 인계년도 등 |

→ 단, **순번은 별도 처리 결정** (아래 §4 참조).

**(b) 형식단어 없음 — 보충 결정 필요**
용어에 형식단어가 아예 안 들어간 케이스:
`비고(28)`, `공식표제(25)`, `파일경로(12)`, `매체포맷(8)`, `저장매체(8)`, `검색어(8)`,
`버전(8)`, `공개시기(6)`, `열람범위(8)`, `보존위치(7)`, `특수기록물유형(7)`, `작업상태(7)` …

→ 각 용어에 적합한 형식단어 보충 결정 필요 (`명`, `구분`, `내용`, `상태`, `여부` 등 중에서).

→ 산출: `RAMP_용어_형식단어미종결.tsv` (566행)

## 4. KEY 컬럼 — `순번` 계열 상세

`순번`은 변형어→일련번호로 흡수하지 않고 **별도 형식단어로 등록 + 용어 추가** 방향 (KEY 용도가 명확하므로).

### 4-1. 규모
- 한글명에 '순번' 포함: **242컬럼 / 63종 용어** (전체 컬럼의 4.2%)
- **18가지 도메인**으로 갈라짐

### 4-2. 전체 도메인 분포
| 도메인 | 컬럼수 | 비율 |
|---|---|---|
| **NUMERIC(6)** | **89** | **37%** ← 최빈 |
| NUMERIC(3) | 37 | 15% |
| NUMERIC(38) | 27 | 11% |
| INTEGER(10) | 26 | 11% |
| NUMERIC(10) | 22 | 9% |
| STRING(19) | 12 | 5% |
| 기타 12종 | 29 | 12% |

### 4-3. 도메인 불일치 14종
| 용어 | 컬럼 | 주 도메인 | PK 비율 |
|---|---|---|---|
| 순번 단독 | 58 | INTEGER(10)×23, NUMERIC(6)×22 외 6종 | **41/58 (71%)** |
| 인수순번 | 17 | NUMERIC(6)×15, NUMERIC(38)×2 | 8/17 |
| 이관그룹순번 | 17 | NUMERIC(3)×11, NUMERIC(38)×6 | 12/17 |
| 문서유형순번 | 12 | NUMERIC(6)×11, NUMERIC(10)×1 | 0/12 |
| 분할매체순번 / 인수인계순번 / 오류순번 / 정렬순번 / 행위자순번 / 기록물건순번 / 작업순번 / 일정순번 / 바이러스이력순번 / 파일순번 | 2~7 | 각각 2~3 도메인 | 다양 |

### 4-4. 통일 권고 — 3등급 분류

| 등급 | 도메인 | 적용 후보 |
|---|---|---|
| 일반 KEY 순번 | **NUMERIC(10)** 또는 **INTEGER(10)** | `순번`, `인수순번`, `오류순번`, `폐기순번` 등 (PK 다수) |
| 작은 그룹/하위 순번 | **NUMERIC(3)** | `이관그룹순번`, `인수인계순번`, `기관인수/인계순번`, `첨부파일순번` 등 (1~999) |
| 합성 ID 순번 | **STRING(고정)** | `기록물건인수순번 STRING(19)` 등 다른 시스템·합성키 — 분리 검토 |

## 6. 결정·작업 항목

### 즉시 결정 권장
- **D9**. 영문명 컨벤션 (RAMP 따름 / 행안부 약어 / 둘 다 보존) — 통합 영향 큼
- **D10**. 도메인 통일 방향 — 177 다중도메인을 최빈/최장/타입우선 중 어느 기준?
- **D13 (신규)**. **`순번` 형식단어 등록 + 도메인 3등급화** (NUMERIC(10) / NUMERIC(3) / STRING)
- **D14 (신규)**. **시간 컬럼 STRING → DATETIME/DATE 정정 정책** — 데이터 타입 변환 필요

### 후속
- **D11**. CAMS↔RAMP 매핑 정책 (262 직접매핑 + 의미매핑 후보)
- **D15 (신규)**. R8 형식단어 보충 — 형식단어 없는 용어(`비고·공식표제·파일경로`…) 처리

### 즉시 산출 가능 (결정 없이도)
- 177 다중도메인 권장 통일 도메인 매핑 표
- 566 R8 미종결을 (a)코멘트정정해결 / (b)형식단어보충 으로 분류한 표
- CAMS↔RAMP 한글명 매핑 후보 표 (262종 + 의미매핑)
