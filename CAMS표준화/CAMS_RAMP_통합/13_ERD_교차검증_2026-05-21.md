## 3. 컬럼명 교차검증 (PK 표본)

ERD 의 PK 컬럼(size 1.2, Gulim 폰트) 971개 중 **자주 등장하는 코어 키** 표본:

| ERD 한글 PK | 추정 영문(내 분류) | 사용자 확정 매핑 | 검증 |
|---|---|---|---|
| **기본목록** | BSID (기본목록 SID) | K0+ (BSID↔fls_id) | ✓ — 사용자 확정과 일치 |
| **세부목록** | DSID (세부목록 SID) | (BSID+DSID)↔(fls_id+ritm_id) | ✓ |
| **기록물철분류번호** | (BSID 와 별도 식별자?) | — | ⚠ ERD의 별도 분류번호. BSID 와의 관계 확인 필요 |
| **기록물건분류번호** | (DSID 와 별도) | — | ⚠ 동일 검증 필요 |
| **단위업무코드** | UNIT_TASK_CD | K8 (8자) | ✓ |
| **기능분류코드** | FUNC_CLSF_CD | K7 | ✓ |
| **상위기능분류코드** | — | K7 분기 | ⓘ 부모-자식 |
| **소기능분류코드** | — | K7 분기 | ⓘ |
| **검토년도/일련번호** | EXAM_YEAR + EXAM_SEQ | — | ✗ 매핑 안 만듦 |
| **공개검토년도/일련번호** | OPEN_EXAM_YEAR + OPEN_EXAM_SEQ | — | ✗ 매핑 안 만듦 |
| **생산년도** | PROD_YEAR | — | — |
| **스케줄링일련번호** | SCHD_SEQ | — | — |
| **기록물점검ID** | INSPECT_ID (W13) | — | — |
| **첨부파일일련번호** | APPEND_FILE_SEQ | — | — |

### 핵심 발견

1. **BSID↔기본목록**, **DSID↔세부목록** 사용자 확정 매핑 **이름까지 그대로** ERD에 표시됨. 매핑 근거 강화.
2. **단위업무코드**(K8), **기능분류코드**(K7) ERD 에서 그대로 발견 — 사용자 확정 키 매핑이 ERD 와 일치.
3. **기록물철분류번호**, **기록물건분류번호** — ERD에 BSID/DSID 와 별도로 존재. 내가 K0+ 매핑할 때 이 둘의 관계를 따로 확인 안 함. **추가 조사 필요**.

## 4. ERD 시각 그룹 vs 11번 문서 영역 색상

ERD 의 영역 라벨이 **5단계 색** (사용/미사용/특수) 으로 구분돼 있을 가능성 (PyMuPDF 색상 추출은 0x000000 단일이라 텍스트는 검은색 통일, 영역 박스 색은 별도 분석 필요). 11번 문서의 🟢/🟡/🔵 등급은 **데이터 풍부도 기준**이지 ERD 색 기준 아님 — 두 기준이 다름을 명시할 것.
