# 분석 보고서 출력 설계

**작성일**: 2026-04-13
**상태**: 설계

---

## 1. 개요

### 1.1 목적
표준화 진단 및 구조 변경 진단 결과를 종합하여 **시각화된 보고서**로 출력한다. 화면 미리보기 + PDF/Excel 다운로드를 제공하여 경영진/담당자에게 데이터 품질 현황을 보고할 수 있게 한다.

### 1.2 메뉴 구조

```
분석                       ← 신규 대메뉴
  ├─ 표준화 분석 보고서       (표준화 진단 결과 종합 보고서)
  └─ 구조 변경 분석 보고서    (구조 변경 진단 결과 종합 보고서)
```

## 2. 표준화 분석 보고서

### 2.1 보고서 구성 (6개 섹션)

| # | 섹션 | 내용 | 데이터 소스 |
|---|------|------|-----------|
| 1 | 모델 개요 | 모델명, 데이터소스, 테이블/컬럼/인덱스/제약조건 수, 최종 수집일 | TB_DATA_MODEL + TB_DATA_MODEL_STATS |
| 2 | 표준화 준수율 요약 | 전체 준수율 게이지, 이슈 유형별 파이차트 (용어 미존재/한글명 불일치/타입 불일치/길이 불일치) | TB_DIAG_JOB + TB_DIAG_RESULT |
| 3 | 테이블별 준수율 | 테이블별 전체 컬럼수, 이슈 컬럼수, 준수율 바차트 + 테이블 | TB_DIAG_RESULT GROUP BY OBJ_NM |
| 4 | 비표준 컬럼 목록 | 이슈 컬럼 전체 목록 (테이블명, 컬럼명, 이슈 유형, 추천 용어) | TB_DIAG_RESULT |
| 5 | 진단 추이 | 최근 5~10회 진단 준수율 변화 라인차트 | TB_DIAG_JOB 최근 N건 |
| 6 | 요약 및 권고사항 | 주요 이슈 Top 5, 개선 권고 문구 | 자동 생성 |

## 3. 구조 변경 분석 보고서

### 3.1 보고서 구성 (4개 섹션)

| # | 섹션 | 내용 | 데이터 소스 |
|---|------|------|-----------|
| 1 | 모델 개요 | 모델명, 스키마, 수집 기준일시, 진단일시 | TB_STRUCT_DIAG_HISTORY |
| 2 | 변경 요약 | 컬럼/인덱스/제약조건 변경 건수 카드 + 변경유형별 파이차트 | TB_STRUCT_DIAG_HISTORY 통계 |
| 3 | 변경 상세 | 컬럼/인덱스/제약조건 변경 목록 (탭) | TB_STRUCT_DIAG_*_DETAIL |
| 4 | 진단 이력 추이 | 최근 5~10회 변경 건수 추이 바차트 | TB_STRUCT_DIAG_HISTORY 최근 N건 |

## 4. PDF 다운로드

### 4.1 방식 선택

| 방식 | 장점 | 단점 |
|------|------|------|
| **OpenPDF (iText fork)** | 서버 의존성 없음, 경량 | 차트 이미지 별도 생성 필요 |
| **Headless 브라우저** | 화면 그대로 PDF | 서버에 브라우저 설치 필요 |
| **Apache PDFBox** | 경량, 순수 Java | 레이아웃 수동 제어 |

→ **OpenPDF** 권장: Maven 의존성 추가만으로 사용 가능, 차트는 JFreeChart로 이미지 생성 후 삽입

### 4.2 PDF 구성

- A4 세로, 헤더에 로고+제목+일시
- 각 섹션별 페이지 분리
- 차트: JFreeChart로 PNG 생성 → PDF 삽입
- 테이블: OpenPDF Table API

### 4.3 대안: 프론트 PDF

프론트에서 `html2canvas` + `jsPDF`로 현재 보고서 화면을 캡처하여 PDF 생성하는 방식도 가능. 서버 부담 없음.

## 5. Excel 다운로드

기존 ExcelDownloadService + ExcelExportHandler 패턴 활용. 다중 시트:

| 시트 | 내용 |
|------|------|
| 모델 개요 | 기본 정보 1행 |
| 테이블별 준수율 | 테이블명, 전체, 이슈, 준수율 |
| 비표준 컬럼 | 전체 이슈 컬럼 목록 |
| 구조 진단 요약 | 컬럼/인덱스/제약조건 변경 건수 |
| 진단 추이 | 최근 N회 준수율 |

## 6. API 설계

| Method | URL | 설명 |
|--------|-----|------|
| GET | `/api/report/standardReport` | 표준화 분석 데이터 조회 (6개 섹션 통합) |
| GET | `/api/report/structReport` | 구조 변경 분석 데이터 조회 (4개 섹션 통합) |
| GET | `/api/report/standardReportExcel` | 표준화 보고서 Excel 다운로드 |
| GET | `/api/report/standardReportPdf` | 표준화 보고서 PDF 다운로드 |
| GET | `/api/report/structReportExcel` | 구조 변경 보고서 Excel 다운로드 |
| GET | `/api/report/structReportPdf` | 구조 변경 보고서 PDF 다운로드 |
