## 자동 회귀 한계 (반성)

본 이슈들의 공통 원인 — 자동 회귀 105 phase 가 검증한 것 vs 검증 못 한 것:

| 검증한 것 | 검증 못 한 것 |
|---|---|
| 매퍼 SQL 결과 키/값 | DDL 정합성 (NOT NULL 등 제약) |
| API endpoint 응답 코드 | API 후속 흐름 (INSERT → SELECT → 결과 노출) |
| UI 메뉴 진입 + 그리드 헤더 | UI 시각적 일관성 (헤더 줄바꿈, 사이즈 혼재) |
| 부분 시나리오 (예: import 만) | 풀 시나리오 (모델 생성 → 수집 → 진단 → 결과 → 통계) |

→ **진단 풀 흐름 통합 selenium 1건 추가 필요**:
- 모델 등록 → 수집 → 표준 진단 시작 → 결과 조회 → 진단 통계 진입 까지 풀 클릭
- 이런 통합 케이스가 있었으면 #1 dm_clct_id 에러를 자동으로 잡았을 것
