# 승인 기능 버그 리포트

## 버그 1. 승인 버튼이 안 보임

**현상**: 승인 화면에서 일괄 승인/반려 버튼이 아예 안 보임
**원인**: `MMApproval.vue:28` - `v-if="isAdmin"` 조건으로 관리자만 버튼 표시
- `adminCheck()`에서 `GET /api/login/isAdmin` 호출 → 결과가 false이면 버튼 숨김
- 현재 로그인 계정이 관리자가 아니거나, `isAdmin` API가 에러를 리턴하는 경우

**확인 필요**: 현재 로그인 계정의 관리자 여부, `/api/login/isAdmin` 응답값

**추가 문제**: 행을 클릭해야 하단 상세 패널에 개별 승인/반려 버튼이 나타남 → 행 클릭 안 하면 승인할 방법이 아예 없음

## 버그 2. 상단 빈 버튼 (첫 번째 칩)

**현상**: 칩 그룹 맨 앞에 텍스트 없는 빈 칩이 보임
**원인**: `MMApproval.vue:6` - `v-chip-group v-model="activeStatusFilter" mandatory`
- 초기값 `activeStatusFilter: 'REQUESTED'` 인데 `v-chip-group`의 `v-model`은 **인덱스 기반**으로 동작
- `value="REQUESTED"` 등 문자열 값을 사용하고 있지만, Vuetify 2의 `v-chip-group`은 `mandatory` + `v-model` 조합에서 인덱스와 value가 충돌할 수 있음
- 결과: 첫 번째 위치에 빈 칩 렌더링

---

## 버그 3. 자동 표준화에서 등록한 용어가 승인 목록에 안 나옴 (핵심 버그)

**현상**: DSTermRecommend에서 일반 사용자로 용어를 등록하면 승인 화면에 나타나지 않음
**원인**: `DataStandardController.java:2012`

```java
// registerTermsBatch 메서드 내부
if (isAdmin) termsVo.setAprvYn("Y");
// ← else 분기 없음! 일반 사용자일 때 aprvYn = null
session.insert("terms.insertTerms", termsVo);
```

**비교 - 단어는 정상**:
```java
// 같은 메서드 내 1962-1963줄
if (isAdmin) wordVo.setAprvYn("Y");
else wordVo.setAprvYn("N");  // ← 있음
```

**결과**:
- TB_TERMS에 `APRV_YN = NULL`로 INSERT됨
- approve.xml `selectStdAprvStatList` 블록1: `WHERE APRV_YN = 'N'` → NULL은 매칭 안 됨
- 승인 목록에 영원히 안 나타남
- 승인도 불가, 사용도 불가인 유령 용어가 됨

**영향 범위**: registerTermsBatch로 등록된 모든 일반 사용자의 용어
