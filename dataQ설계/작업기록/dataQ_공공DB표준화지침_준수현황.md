# 공공기관 데이터베이스 표준화 지침 준수 현황

**기준 문서**: [별표 1] 데이터 표준사전 관리항목 (공공기관의 데이터베이스 표준화 지침)
**대상 시스템**: Narae DataQ

## 1. 표준용어 (TB_TERMS)

| 지침 항목 | 필수 | 시스템 컬럼 | 준수 | 비고 |
|-----------|------|------------|------|------|
| 표준용어명 | O | TERMS_NM | ✅ | 한글, 특수문자/공백 불가 |
| 영문명 | O | - | ⚠️ 해당없음 | 지침에는 명시되나, 행안부 배포 표준용어에도 영문 Full Name 미제공. 약어명만 관리 |
| 영문약어명 | O | TERMS_ENG_ABRV_NM | ✅ | 구성단어 약어 조합 |
| 용어설명 | O | TERMS_DESC | ✅ | |
| 표준도메인명 | O | DOMAIN_NM | ✅ | 도메인 FK |
| 허용값 | O | - (도메인에서 참조) | ⚠️ | DOMAIN.ALLOW_VAL_LST로 간접 관리 |
| 관리부서명 | O | - | ❌ **미존재** | |
| 표준코드명 | △ | CODE_GRP | ✅ | 코드 그룹 참조 |
| 업무분야 | O | - | ❌ **미존재** | BRM 분류체계 |
| 제정일자 | O | CRET_DT | ✅ | 생성일시로 대체 |

### 추가 관리 항목 (지침 외)
| 시스템 컬럼 | 설명 |
|------------|------|
| COMM_STND_YN | 공통표준 여부 |
| APRV_YN | 승인 여부 |
| REQ_SYS_CD | 요청 시스템 코드 |
| USE_YN | 사용 여부 |

### 미준수 항목 분석
1. **영문명 (Full Name)**: 지침에는 별도 관리 요구하나, 행안부 배포 표준용어 데이터에도 영문 Full Name이 없음. 실무적으로 약어명만 관리하는 것이 관례.
2. **관리부서명**: 부서 개념 자체가 시스템에 없음.
3. **업무분야**: BRM 분류체계 미적용.

## 7. 기타 사항

### 시스템이 추가로 관리하는 항목 (지침 범위 외)
- **승인 프로세스** (APRV_YN, APRV_USER_ID, APRV_STAT_UPDT_DT)
- **요청 시스템** (REQ_SYS_CD) — 시스템별 단어/용어 관리
- **공통표준 여부** (COMM_STND_YN)
- **사용 여부** (USE_YN)
- **변경 이력 추적** (TB_CHANGE_HISTORY)
- **영향도 분석** (TB_IMPACT)
- **자동 표준화 추천** (TB_WORD_DICT 기반)

### 형식단어 어미 강제 규칙
- 지침: "해당 표준단어가 도메인 특성을 지닌 형식단어(분류어)인지의 여부를 기재"
- 시스템: WORD_CLSF_YN으로 관리 ✅
- 행안부 공통표준 13,159건 전부 형식단어로 끝남 → **공공기관 표준의 기본 규칙**
- 기관표준 등록 시에도 동일 기준 적용

**모든 등록 경로에서 형식단어 어미 검증 적용 완료:**

| 등록 경로 | 검증 |
|----------|------|
| 용어 화면 등록 (createTerms) | ✅ 마지막 단어 WORD_CLSF_YN='Y' 체크 |
| 표준화 추천 일괄등록 (registerTermsBatch) | ✅ 동일 |
| 표준화 추천 수정 다이얼로그 (confirmEdit) | ✅ 서버에서 실시간 확인 |
| 용어 엑셀 업로드 (uploadTermsList) | ✅ 동일 |
