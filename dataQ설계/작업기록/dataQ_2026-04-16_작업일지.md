### test_word_approval_flow.py 개발 과정

#### 테스트 시나리오
1. jyjang 로그인 → 단어 등록 (미승인 상태 생성)
2. space 로그인 → 승인 화면에서 해당 단어 승인
3. space → 단어 사전에서 승인된 단어 검색 → 삭제

#### 주요 해결 과제 및 수정사항

**네비게이션 메뉴 클릭 문제**
- `v-list-group` 안의 메뉴가 접혀있어 직접 클릭 불가
- 해결: `parent_group_text` 파라미터 추가 → 부모 그룹 헤더를 먼저 펼친 후 하위 메뉴 클릭
- 네비게이션 드로어 스크롤 → ActionChains.move_to_element()로 대시보드(최상단)로 이동 후 탐색

**승인 버튼 접근 문제**
- 상세 패널 하단의 개별 승인 버튼이 뷰포트 밖 (displayed=False)
- 해결: 체크박스 선택 + "일괄 승인" 버튼 사용 (화면에 이미 노출된 버튼 활용)
- SweetAlert 확인 팝업 처리 ("선택한 N건을 승인하시겠습니까?")

**등록 확인 방법**
- 미승인 단어는 단어 사전에서 기본 조회 안 됨 (승인 여부 필터)
- 해결: 마이페이지 → 요청 현황에서 등록 확인 (실제 사용자 플로우)

**DOM 클릭 준수**
- 모든 조작을 DOM 클릭으로 제한 (execute_script는 스크롤 보조만 허용)
- ActionChains.move_to_element().click() 으로 스크롤+클릭 통합
- 입력: send_keys(Keys.CONTROL, "a") → send_keys(value) 패턴

**기타 수정**
- UNIQUE 충돌 방지: 단어명에 랜덤 suffix 부여 (셀레니움XXX)
- 모달 input에 기존 데이터 잔존 → Ctrl+A 후 덮어쓰기
- 브라우저 높이 900 → 1080 증가 (뷰포트 밖 요소 감소)

#### DB 수정 사항
- `space` 계정 관리자 권한: `UPDATE quality.tb_user SET adm_yn = true WHERE user_id = 'space'`
