## 2. DDL 변경

```sql
-- 1. TB_DATA_MODEL: DM_DS_ID NULL 허용
ALTER TABLE quality.TB_DATA_MODEL ALTER COLUMN DM_DS_ID DROP NOT NULL;

-- 2. TB_DATA_MODEL_CLCT: 스냅샷 원천 구분
ALTER TABLE quality.TB_DATA_MODEL_CLCT ADD COLUMN CLCT_TYPE VARCHAR(20) DEFAULT 'DBMS';
COMMENT ON COLUMN quality.TB_DATA_MODEL_CLCT.CLCT_TYPE IS '수집 유형: DBMS(DB수집), MANUAL(수동), ERWIN(ERwin임포트)';

-- 3. TB_DATA_MODEL_OBJ: DB 코멘트 원본 저장
ALTER TABLE quality.TB_DATA_MODEL_OBJ ADD COLUMN OBJ_COMMENT VARCHAR(500);
COMMENT ON COLUMN quality.TB_DATA_MODEL_OBJ.OBJ_COMMENT IS 'DB에서 수집한 테이블 코멘트 원본';

-- 4. TB_DATA_MODEL_ATTR: DB 코멘트 원본 저장
ALTER TABLE quality.TB_DATA_MODEL_ATTR ADD COLUMN ATTR_COMMENT VARCHAR(500);
COMMENT ON COLUMN quality.TB_DATA_MODEL_ATTR.ATTR_COMMENT IS 'DB에서 수집한 컬럼 코멘트 원본';

-- 기존 데이터 마이그레이션: 기존 NM_KR 값을 COMMENT에도 복사
UPDATE quality.TB_DATA_MODEL_OBJ SET OBJ_COMMENT = OBJ_NM_KR WHERE OBJ_COMMENT IS NULL;
UPDATE quality.TB_DATA_MODEL_ATTR SET ATTR_COMMENT = ATTR_NM_KR WHERE ATTR_COMMENT IS NULL;
UPDATE quality.TB_DATA_MODEL_CLCT SET CLCT_TYPE = 'DBMS' WHERE CLCT_TYPE IS NULL;
```

```java
// 설계 논리명 (ATTR_NM_KR) vs 수집 코멘트 (ATTR_COMMENT)
if ("GAP".equals(diagMode)) {
    for (AttrVo currAttr : currentAttrs) {
        AttrVo designAttr = designMap.get(currAttr.getKey());
        if (designAttr != null) {
            // 기존 비교: 타입, 길이, nullable, pk 등
            // 추가 비교: 한글명
            if (!Objects.equals(designAttr.getAttrNmKr(), currAttr.getAttrComment())) {
                // "한글명 불일치" 이슈 기록
                detail.setChangeType("KR_NAME_MISMATCH");
            }
        }
    }
}
```

## 8. 수집 서비스 DBMS별 코멘트 수집 확인

**경로:** `q-executor/src/main/java/qualityexecutor/service/std/DataModelService.java`

현재 코멘트를 가져오는 방식이 DBMS별로 다를 수 있음. 확인 필요:

| DBMS | 테이블 코멘트 | 컬럼 코멘트 | 확인 포인트 |
|------|-------------|-----------|-----------|
| Oracle | ALL_TAB_COMMENTS | ALL_COL_COMMENTS | 이미 수집 중인지 확인 |
| PostgreSQL | pg_description | col_description() | information_schema에는 없음 |
| MySQL/MariaDB | TABLE_COMMENT (information_schema) | COLUMN_COMMENT | 이미 수집 중인지 확인 |
| SQL Server | sys.extended_properties | sys.extended_properties | fn_listextendedproperty() |
| Tibero | ALL_TAB_COMMENTS | ALL_COL_COMMENTS | Oracle과 동일 |

**각 DBMS의 수집 쿼리 파일 위치:**
- `q-executor`에서 사용하는 쿼리는 `DataSourceUtils.getQueryString()` 또는 직접 SQL로 작성
- 코멘트 컬럼이 현재 SELECT에 포함되어 있는지 확인 필요
- 포함되어 있지 않으면 각 DBMS별 수집 쿼리에 코멘트 조인 추가
