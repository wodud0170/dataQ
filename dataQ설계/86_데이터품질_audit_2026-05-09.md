## 기능별 화면 컨셉 (사용자가 이해하기 쉽게 정리 필요)

### 1. 도메인 룰 관리 (DSQualDomainRule)
- **컨셉**: 도메인분류 트리 (예: 전화번호/이메일/주민번호) 별로 검증 룰 (REGEX/NOT_NULL/RANGE 등) 을 바인딩
- **카탈로그**: 시스템 기본 룰 50+ 개 (NOT NULL, EMAIL_FORMAT 등) → 매핑/복사하여 빠르게 시작
- **사용 흐름**: 좌측 트리에서 도메인 선택 → 우측 패널에 적용된 룰 보임 → [룰 추가] 또는 [카탈로그에서 가져오기]

### 2. 값 프로파일링 (DSQualValueProfile)
- **컨셉**: 모델 선택 → 컬럼 선택 → 실제 값 분포 (NULL/UNIQUE/MIN/MAX/길이 등) 통계 즉시 산출
- 단순 조회. 기능 부담 적음

### 3. 업무 규칙 관리 (DSQualRuleManage)
- **컨셉**: 도메인 룰과 별개로 비즈니스 룰 (예: "주문금액 > 0") 등록/관리
- 룰 = 이름 + 설명 + SQL 검증식 + 활성여부

### 4. 업무 규칙 진단 결과 (DSQualRuleResult)
- **컨셉**: 위 3 의 룰을 실행한 이력 + 위반 row 목록
- 진단 실행 자체는 컬럼 규칙 매핑(5)에서 trigger

### 5. 컬럼 규칙 매핑 (DSQualColRule)
- **컨셉**: 모델 컬럼 ↔ 룰 (도메인 룰 OR 사용자 정의 룰) 매핑 + 진단 실행
- **흐름**: 모델 → 컬럼 → 매핑된 룰 보기 → [진단 실행] / [전체 실행] / [컬럼 단위 실행] / [테이블 단위 실행]

### 6. 진단 통계 (DSQualStats)
- **컨셉**: 모델별 / 도메인별 / 룰타입별 위반 건수 + 추이 차트
- 결과 view-only
