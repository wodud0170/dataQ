## 3. 향후 작업 계획

### 3.1 단기 (1~2주)

| 우선순위 | 작업 | 난이도 | 설명 |
|---|---|---|---|
| **P0** | 전체 메뉴 버그 전수 점검 | 중 | 모든 화면 직접 조작하며 의도하지 않은 결과 식별 |
| **P0** | 승인 기능 전면 재점검 | 중 | 승인/반려/재요청 전체 흐름 검증 및 수정 |
| **P1** | 표준 진단 중복 클릭 방지 | 하 | 프론트 starting 플래그 + 백엔드 중복 Job 체크 |
| **P1** | TIMESTAMP 타입 동등성 추가 | 하 | DiagService.isTypeEquivalent에 TIMESTAMP 변형 추가 |
| **P1** | 기존 NULL 데이터 복구 | 하 | `UPDATE TB_TERMS SET APRV_YN='N' WHERE APRV_YN IS NULL` |

### 3.2 중기 (2~4주)

| 우선순위 | 작업 | 난이도 | 설명 | 설계 문서 |
|---|---|---|---|---|
| **P1** | 인덱스/제약조건 수집 | 중 | 별도 수집 메뉴 + 조회 화면 추가 | 29번, 33번, 34번 |
| **P1** | 대시보드 반응형 레이아웃 | 중 | 1920x1080 기준 CSS Grid 재설계 | 24번 |
| **P2** | 데이터모델 리포트 (엑셀/PDF) | 중 | 수집된 모델의 테이블/컬럼 정보 보고서 출력 | 23번 |
| **P2** | 영향도 분석 | 높 | 단어/용어 변경 시 연관 항목 추적 | 15번 |
| **P2** | ERwin 연동 | 높 | ERwin XML 파일 Import/Export | 15번 |

### 3.3 장기 (1~2개월)

| 우선순위 | 작업 | 난이도 | 설명 |
|---|---|---|---|
| **P2** | 논리/물리 모델 전환 | 높 | 데이터 타입 매핑 (Oracle↔PostgreSQL↔MySQL 등) |
| **P2** | 다단계 결재 프로세스 | 높 | 현재 1단계 승인 → 다단계 결재선 설정 가능하도록 |
| **P3** | 데이터 품질 측정 (DQI/CTQ) | 높 | 화면은 존재하나 기능 미구현 상태 |
| **P3** | 데이터 프로파일링 | 높 | 컬럼별 분포, NULL 비율, 유니크 값 등 통계 |
