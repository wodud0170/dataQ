## 5. 자동 표준화 지원

### 5-1. 컬럼 표준화 (DSTermRecommend.vue)

4단계 stepper:
1. **입력** — 텍스트 줄바꿈 / 엑셀 업로드 / 양식 다운로드(`/api/std/downloadTermRecommendTemplate`)
2. **분석** — `/api/std/analyzeTermsBatch` (q-executor 의 `StringWordAnalyzer` + TwitterKoreanProcessor + TermRecommendService)
3. **리뷰** — 행별 상태 (REGISTERED / AUTO / PARTIAL / FAILED) → 수정 모달
4. **완료** — 용어 등록

### 5-2. 수정 모달 — 분류어/도메인 cascade (ca8858d / 61번 문서)

- **분류어 v-autocomplete** — `/api/std/getClassificationWords` 로 545건 로드 (검색/자동완성)
- **도메인 v-select** — `/api/std/getDomainsByClsf?domainClsfNm=XX` cascade
- **cascade 의존**: `currentEditWords[-1].domainClsfNm` (마지막 단어 기준). 도메인만 독립 수정 가능.
- **[분류어 추가]** 버튼: 단어 테이블 행 push + watcher 가 cascade 재로드 + preselect

테스트: `test_ca8858d_clsf_domain.py` 10/10 PASS (분류어 545건 / 도메인 cascade / 모달 / 행 추가)

## 6. 진단 스케줄러 — 65번 문서 / Phase 1~4 완료

### 6-1. 스케줄 관리 (DSScheduleManage.vue)

| 속성 | 값 |
|---|---|
| 권한 | 관리자 전용 |
| 등록/수정 | scheduleNm + diagType (STANDARD/STRUCT/BOTH) + dataModelId + scheduleType (SIMPLE/CRON) |
| SIMPLE 필드 | repeatCycle (DAILY/WEEKLY/MONTHLY) + repeatTime "HH:mm" + dayOfWeek/dayOfMonth |
| CRON 필드 | cronExpr + 실시간 다음 5회 미리보기 (`/cronPreview`) |
| 기본 액션 | 활성/비활성 토글 + [즉시 실행] + [편집] + ⋮ 메뉴(삭제) |
| 삭제 정책 | 물리 삭제. 이력은 `SCHEDULE_NM_SNAPSHOT` 으로 보존 |

### 6-2. 스케줄 실행 (q-executor)

- `QualityExecutorApplication @EnableScheduling`
- `DiagSchedulerRunner`:
  - `@Scheduled(60s)` — 활성 스케줄 평가 + SIMPLE/CRON 트리거 판정 + **SKIP 정책** (같은 모델+유형 RUNNING 존재 시 SKIPPED 이력 후 양보)
  - `@Scheduled(30s)` — `pollCompletion`: 기저 진단 status 폴링 + **CompositeStatus** 합성 (BOTH 는 두 ID 모두 DONE 일 때만 LOG DONE)
  - `@Scheduled(5m)` — `expireStale`: 60분 이상 RUNNING [TIMEOUT] 마감
- `ScheduledDiagLauncher`:
  - STANDARD: `resolveLatestClctId` → TB_DIAG_JOB READY insert → DiagService Thread
  - STRUCT: TB_STRUCT_DIAG_HISTORY READY insert → StructDiagService Thread
  - BOTH: 두 진단 병행 기동, LOG 의 DIAG_JOB_ID + STRUCT_DIAG_ID 모두 세팅
  - 실패 prefix: `[CONFIG]/[DB]/[TIMEOUT]/[DATA_NOT_FOUND]/[UNKNOWN]/[SKIPPED]/[DIAG]`

### 6-3. 실행 이력 (DSScheduleLog.vue)

- 필터: 스케줄 / 상태 (RUNNING/DONE/ERROR/SKIPPED) / 기간
- 테이블 + 행 클릭 → drawer (DIAG_JOB_ID/STRUCT_DIAG_ID/ERROR_MSG 전체)

## 10. 표준화 준수율 계산식 (전 화면 통일)

```
준수율 = (전체 컬럼수 - 이슈 컬럼수) / 전체 컬럼수 × 100
이슈 컬럼수 = COUNT(DISTINCT OBJ_NM || '.' || ATTR_NM) FROM TB_DIAG_RESULT
```
RESULT_CNT(이슈 건수) **아님**. ISSUE_COL_CNT(이슈 컬럼수) 사용.
