## 1. 현재 진행 상황

### 완료된 주요 기능

| 기능 | 비고 |
|------|------|
| 데이터 표준 사전 (단어/용어/도메인/코드) | 등록/수정/삭제/엑셀 업로드/승인 |
| 데이터 모델 수집 (테이블/컬럼/인덱스/제약조건) | Oracle/MariaDB/Cubrid |
| 표준화 진단 (준수율 검증) | 용어/도메인/단어 준수 검사 |
| 구조 변경 진단 (스키마 변경 감지) | 컬럼/인덱스/제약조건 변경 감지 |
| 자동 표준화 추천 (DP 기반 단어분리) | 분석→리뷰→등록 워크플로우 |
| 승인 프로세스 (승인/반려/재요청) | 관리자/일반사용자 분리 |

### 잔여 항목 요약

| 카테고리 | 건수 | 비고 |
|----------|------|------|
| 승인 기능 버그 | 4건 | Critical 1건 포함 |
| 자동표준화/보안/안정성 버그 | 16건 | Critical 2건 포함 |
| 진단 스케줄러 | 신규 개발 | 자동 주기 진단 |
| 분석 결과 보고서 출력 | 신규 개발 | Excel/PDF |
| UI 편의성 개선 | 10건+ | 에러 처리 통일 등 |

## 2. 주차별 개발 계획

### 1주차 (04/14 ~ 04/18) — 개발 DB 이관 + 승인/자동표준화 버그 수정

| 작업 | 기간 | 비고 |
|------|------|------|
| **개발 DB 이관 (내부 DB)** | 월~화 | 개발 환경 PostgreSQL → 내부 서버 이관, 데이터 마이그레이션, 접속 정보 변경 |
| **승인 기능 버그 수정** | 수~목 | 용어 승인 누락(APRV_YN=NULL), 상세보기/일괄처리 충돌, 승인 버튼 미노출, 에러 처리 |
| **자동표준화 안정성 수정** | 목 | 중복 등록 방어(DB 유니크 제약), 메모리 최적화 |
| **테스트 + 잔여 버그 수정** | 금 | 승인 워크플로우 시나리오 검증, NPE 방어 코드 추가 |

### 2주차 (04/21 ~ 04/25) — 보안 수정 + 진단 스케줄러

| 작업 | 기간 | 비고 |
|------|------|------|
| **보안 취약점 수정** | 월~화 | 비밀번호 URL 노출(GET→POST), 평문 반환 차단, 민감정보 로깅 제거, 트랜잭션 정비 |
| **진단 스케줄러 개발** | 수~목 | DB 설계, Spring @Scheduled 기반 자동 진단 실행 (표준화/구조변경), 스케줄 등록/관리 화면 |
| **테스트 + 잔여 버그 수정** | 금 | 스케줄러 자동 실행 검증, 보안 항목 재점검 |

### 3주차 (04/28 ~ 05/02) — 분석 결과 보고서 출력

| 작업 | 기간 | 비고 |
|------|------|------|
| **보고서 API + 화면 개발** | 월~화 | 모델 개요, 표준화 준수율, 테이블별 통계, 구조 진단 결과, 진단 추이 통합 보고서 |
| **보고서 Excel/PDF 다운로드** | 수~금 | Apache POI 다중 시트 Excel, PDF 출력 |
| 05/01(목) | 휴무 | 근로자의 날 |

### 4주차 (05/05 ~ 05/09) — UI 안정화 + 통합 테스트

| 작업 | 기간 | 비고 |
|------|------|------|
| 05/05(월) | 휴무 | 어린이날 |
| **UI 편의성 개선** | 화~수 | 에러 처리 swal 통일, 삭제 확인 모달, 검색 초기화, 에러 핸들링 정비 |
| **전체 통합 테스트** | 목 | 표준사전 등록 → 승인 → 수집 → 진단 → 보고서 출력 전 과정 시나리오 검증 |
| **테스트 보고서 + 릴리즈 노트** | 금 | 최종 테스트 결과, 수정 이력, 잔여 이슈 정리 |
