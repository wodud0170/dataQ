## 1. 메인화면 및 전체 레이아웃 - 해상도 대응 불량

### 1.1 현상
- 1920x1080 100%에서 대시보드 카드, 차트, 검색조건 등이 뭉개짐/줄바뀜
- 3840x2160에서는 정상, 1920x1080에서 67% 축소해야 정상 표시
- 검색조건 영역도 전 화면에서 줄바뀜 발생

### 1.2 원인 분석

| 위치 | 문제 | 상세 |
|------|------|------|
| **QDashboard.vue** | 카드 고정 백분율 | `std-card: 30%`, `aprv-card: 22%` + margin → 100% 초과로 오버플로우 |
| **QDashboard.vue** | 높이 하드코딩 | `calc((100vh - 64px - 48px - 50px) / 2)` → 해상도별 깨짐 |
| **QDashboard.vue** | 도넛 차트 30% x 3 | gap 포함 시 오버플로우 |
| **DSWord/DSTerm** | 검색 필드 고정 200px | flex-wrap 없이 row 고정 → 한 줄 초과 시 오버플로우 |
| **DSDataDiag** | 필터 220px+280px 고정 | flex-grow:0으로 확장 금지, wrap 불가 |
| **styles.css** | 반응형 미디어쿼리 부재 | 916px 모바일 분기만 있고, 1920px 이상 대응 없음 |
| **index.html** | viewport 메타 중복 | 2번 선언 + `user-scalable=no`로 확대 차단 |
| **NdLayout.vue** | Split 15:85 고정 | 네비 288px, 메인 1632px → 반응형 조정 불가 |

### 1.3 수정 방향
- 고정 px/% → CSS Grid 또는 flex-wrap + min-width 기반으로 전환
- 미디어쿼리 3단계 추가 (960px, 1440px, 1920px)
- viewport 메타 중복 제거, user-scalable=no 삭제
- 카드/차트 너비를 CSS Grid `auto-fill` + `minmax()` 사용

## 2. 구조 진단 - 메뉴 구조 문제

### 2.1 현상
- 현재 3개 메뉴: [진단 실행] / [진단 이력] / [스키마 비교]
- 진단 실행과 진단 이력이 기능 80% 중복 (historyHeaders, loadHistory 동일 코드 2벌)
- 스키마 비교는 진단 결과의 다른 뷰에 불과 → 별도 메뉴 불필요
- 사용자가 어디서 뭘 해야 하는지 혼란

### 2.2 코드 중복
```
DSStructDiag.vue:      historyHeaders, loadHistory(), onHistoryClick() → 템플릿에서 미사용 (좀비 코드)
DSStructDiagHistory.vue: historyHeaders, loadHistory(), onHistoryClick() → 동일 로직 중복
```

### 2.3 올바른 구조 (2개 메뉴)

```
구조 진단
├─ 진단 실행    : 모델 선택 → 실행 → 결과 요약 + 이력 목록
└─ 진단 결과    : 이력 선택 → 변경 상세 + 스키마 비교(좌우 분할)
```

- **진단 실행**: 실행 기능 + 하단에 이력 목록 (이전 진단 이력 테이블)
- **진단 결과**: 이력 목록에서 선택 → 변경점 상세 + 현재 스키마 비교(DSSchemaCompare 내용 통합)
- DSStructDiagHistory.vue 삭제, DSSchemaCompare 내용을 결과 화면에 통합

### 4.2 UI 문제

| 문제 | 상세 |
|------|------|
| 행 호버 효과 없음 | 클릭 가능 영역 인지 어려움 |
| 상세 화면 제목 크기 | h6으로 본문과 크기 차이 적음 |
| 댓글 영역 패딩 부족 | pa-2 → 너무 좁음 |
| 모바일 대응 | cols="10" + cols="2" → 모바일에서 버튼 찌그러짐 |
| 에러 처리 | `.catch(err => console.error(err))` → 사용자 피드백 없음 |
| 이중 클릭 방지 | 게시글/댓글 등록 시 중복 요청 가능 |
| 삭제 확인 메시지 | "게시글을 삭제하시겠습니까?" → 어떤 게시글인지 표시 안 함 |

## 5. 기타 발견 사항

### 5.1 단어 분류어 식별 불가 (해결됨)
- 단어 목록에서 어떤 단어가 분류어인지 구분 안 되던 문제
- 수정: 헤더명 "분류어"로 변경 + Y이면 [분류어] 인디고 칩 표시

### 5.2 표준화 추천 검증 부재 (해결됨)
- 미등록 단어가 빈 영문약어로 통과
- 수정 후 재편집 불가
- 분류어 어미 검증 없음
- → 전부 수정 커밋 완료, 추가 테스트 필요

### 5.3 승인 반려/재요청 (해결됨, 검증 필요)
- 반려된 항목 재요청 불가 → reRequestApproval API 추가
- 반려 이력 미표시 → getApprovalHistory API + 상세 패널 이력 테이블 추가
- 승인 쿼리 중복 표시 → NOT EXISTS 조건 + 최신 레코드 필터링 추가
