## 2. DDL 변경 — ⚠️ 0건

오늘 작업은 **TB_DATA_MODEL_OBJ / ATTR / INDEX / CONSTRAINT 의 기존 스키마 그대로** 사용. 신규 컬럼/테이블 추가 없음.

`DDL_claude_generated.sql` 파일 **변경 없음**. 따라서 **다음 PC 의 DB 마이그레이션 작업 불필요**.

### 사유 (왜 DDL 변경이 없는가)
| 의도된 기능 | DDL 변경 필요했나 | 실제 처리 |
|------------|------------------|-----------|
| 테이블 물리명 변경 + cascade | 필요 없음 | 매퍼 5종 UPDATE 로 OBJ_NM / ATTR.OBJ_NM / INDEX.TABLE_NM / CONSTRAINT.TABLE_NM / CONSTRAINT.REF_TABLE_NM 갱신 |
| 영향 카운트 preview | 필요 없음 | 매퍼 SELECT 4종 추가 |
| UPDATE 정합성 (dataType 보존) | 필요 없음 | 기존 row 단건 조회 매퍼 1개 추가 + Controller 로 select→merge→update 흐름 |
| 표준 진단 가드 제거 | 필요 없음 | Java 코드에서 필터 제거 |
| 헤더 라벨 / 그리드 색 / 인라인 편집 | 필요 없음 | 프론트만 |

→ 만약 PC2 에서 새 컬럼/테이블 도입이 필요한 작업을 하려면 [DDL_claude_generated.sql](DDL_claude_generated.sql) 말미에 날짜 + 사유 주석을 함께 추가할 것.

## 3. 개발 환경 (오늘 학습 정리)

### 3-1. 빌드 절차 — **모듈별 순차** (3월부터 불변)
```bash
cd q-common  && mvn install -DskipTests
cd q-center  && mvn package -DskipTests
cd q-executor && mvn package -DskipTests
```
- `mvn package -q` **금지** (repackage 가 조용히 스킵되어 Manifest 없는 plain jar 생성)
- 루트 reactor (`mvn clean package` at root) **금지** — ccf76c4(4-23)에서 시도됐으나 다른 세션에서 본래 모듈별로 원복됨

### 3-2. 프론트 빌드 출력 = **`q-center/src/main/resources/static/`** (Vue CLI 표준 dist 아님)
- [q-center/vue/front/config/index.js](../q-center/vue/front/config/index.js) 가 `assetsRoot` 를 `src/main/resources/static` 로 명시 (initial import 부터 그렇게 설정됨)
- 즉 `cd q-center/vue/front && npm run build` 하면 jar 의 source 가 직접 갱신됨
- **jar 재빌드 없이 페이지 새로고침만으로 새 번들 적용** (단 IDE 모드 전제)

### 3-3. 서버 기동 = **IDE 임시 classpath 모드**
- 사용자 IDE (Spring Boot Run/Debug) 가 `java -cp <임시jar>` 로 기동
- 임시 classpath jar 가 파일시스템 `q-center/src/main/resources/static` 을 직접 classpath 에 등록
- 결과: **프론트만 변경 → npm run build → 새로고침** (서버 재기동 불필요)

### 3-4. Claude 의 빌드/재기동 권한
- 일반 개발: **백엔드 빌드/재기동 자동 수행 안 함**. 사용자가 IDE 로 hot-reload 또는 재기동
- 한 축 마무리: 사용자가 명시적으로 "빌드해" 지시 시에만 실행
- 프론트만 변경: **묻지 말고 즉시** `npm run build` 실행 (확정된 룰)
- **Selenium 재귀 테스트 지시** 시: Claude 가 직접 빌드 + 재기동 + 테스트 사이클 수행 가능

### 3-5. DB
- Postgres 13, **포트 25433** (Windows 네이티브)
- 접속: `user=admin / pw=admin!123 / db=postgres / schema=quality`
- 명령: `PGPASSWORD='admin!123' psql -h localhost -p 25433 -U admin -d postgres`

### 3-6. JDK
- **JDK 1.8 필수** (`C:\Program Files\Java\jdk-1.8`). JDK 21 쓰면 Lombok 충돌
- 환경변수: `export JAVA_HOME="/c/Program Files/Java/jdk-1.8"; export PATH="$JAVA_HOME/bin:$PATH"`

### 3-7. PowerShell 기동 패턴 (jar 모드 시 사용)
58번 절차서 `$centerDir + 상대경로 target\xxx.jar` 패턴. 한글 경로 문제 회피를 위해 `-WorkingDirectory` 필수.
