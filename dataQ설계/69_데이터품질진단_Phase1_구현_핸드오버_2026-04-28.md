## 2. 변경 이력 (디버깅 과정)

빌드 후 테스트 돌리며 발견·수정한 버그:

1. **`Map → String` 직렬화 에러** — Response.setContents(Map) 컴파일 실패. Gson 으로 JSON string 직렬화로 변경
2. **`selectCatalogById` 매퍼 누락** — list 에서 stream filter 로 대체
3. **`@RequestParam` → `@PathVariable`** — `/history/{diagId}` 가 500 에러 원인
4. **TB_DATA_MODEL 컬럼명 misalign** — DATA_MODEL_ID/NM/DS_ID 가 아니라 DM_ID/NM/DS_ID. 매퍼 SQL 5곳 수정
5. **selectDataModelAttrListByClctIdRaw alias 사용** — 결과 alias 가 `tableNm/columnNm` 인데 코드는 `objNm/attrNm` 으로 접근. defensive fallback 추가
