### 2-4. 솔루션군 (SMETA 가족)

| 솔루션            | 역할                                | DataQ 와의 관계               |
| -------------- | --------------------------------- | ------------------------- |
| **SMETA**      | 메타데이터 표준관리 (본 비교 대상)              | **DataQ 대응**              |
| **SDQ**        | Smart Data Quality — 품질관리         | DataQ 의 데이터 품질 진단(값/룰) 대응 |
| **SDQ for AI** | AI 학습데이터 품질 (JSON 스키마, NIA 가이드라인) | DataQ 미보유 영역              |
| **SFLOW**      | 데이터 통합 (HTTP/FTP/JMS)             | DataQ 미보유 영역              |
| **SPORTAL**    | 데이터 카탈로그 / 통합 검색 / Tree Map       | DataQ 의 글로벌 검색 일부 대응      |
| **HYPERGLORY** | RAG 기반 AI Knowledge Management    | DataQ 미보유 영역              |
| **비즈메타**       | SMETA Add-On — 비즈니스 사용자용          | DataQ 미보유                 |

→ **중요**: 비투엔은 **메타관리(SMETA) 와 품질관리(SDQ) 가 별도 솔루션**. 공공 입찰에서 **SMETA + SDQ 동시 도입 패턴**이 일반적. DataQ 는 **양쪽을 한 솔루션에서 통합 제공** — 라이선스 / 통합 비용 차이가 입찰 핵심 메시지.

| 기능                       |   SMETA   | DataQ |        우위        |

| 행정용어사전 참조                |     ✅     |   ❌   |    **SMETA**     |

| **수집 + 표준화 진단 통합**             | ✅              | 별도 단계 없이 한 흐름                      |
| **진단 → 즉시 일괄등록 연계**            | ✅              | 작업 효율성                             |

## 7. 입찰 시뮬레이션 (재산정)

```
시점         A    B    C   평균   SMETA격차
SMETA        95   80   85   87
DataQ 현재   95   60   30   62    -25
DataQ P1     98   88   60   82     -5  ← Phase 1 후 5점차로 좁아짐
DataQ P2     100  95   85   93    +6  ← 추월
```

### 7-1. 시나리오 평가

| 시나리오                | 시기      | DataQ 점수 | 격차     | 권장도                                           |
| ------------------- | ------- | -------- | ------ | --------------------------------------------- |
| X. 즉시 입찰            | 현재      | 62       | -25    | ❌ 매우 불리                                       |
| **Y. Phase 1 후 입찰** | **3개월** | **82**   | **-5** | **✅ 권장** — 정성 평가에서 자동 표준화 + 품질 진단 통합으로 메우기 충분 |
| Z. Phase 2 후 입찰     | 5개월     | 93       | +6     | ✅ 추월 — 차기 입찰                                  |

### 7-2. 입찰 핵심 메시지 (재정리)

```
1. 메타관리 + 데이터 품질 진단 = 한 솔루션
   → SMETA + SDQ 별도 도입 비용 절감

2. 자동 표준화 추천 엔진 (한글→영문약어 자동)
   → SMETA 미보유. DataQ 단독 보유.
   → BMT 시연 시 결정적 차별점.

3. Cubrid 11.2 정식 dialect
   → 국산 DBMS 가산점.

4. 자동 회귀 테스트 27건 통과 + 시연 가이드
   → 운영 안정성 / 인수인계 / 감리 즉시 검증 가능.

5. Phase 1 (3개월) 로드맵으로 ERwin 활성화 + 주제영역/엔터티 보강
   → SMETA 동등 + DataQ 차별점 결합.

6. 진단 → 즉시 일괄등록 연계로 운영 효율 우위.
```

## 9. 학습 결론

### 9-1. 정정된 SMETA 인식

| 76번 가정                 | 정정                                 |
| ---------------------- | ---------------------------------- |
| SMETA = 자체 ERD 시각화 보유  | ❌ → ERwin 위임 (76번 §0 보정 반영됨)       |
| SMETA = ERwin 연동 별도 보유 | ✅ 공식 명시 — DataQ 90% 완성 활성화 시 동등    |
| SMETA = 다중 표준 가정       | ✅ "국내 최초 도입" 보도자료로 확정              |
| SMETA = 데이터 품질 진단 미보유  | ✅ 별도 솔루션 SDQ 로 분리 — DataQ 통합 우위 확정 |
| SMETA = 자동 표준화 추천 미보유  | ✅ 명시 없음 — DataQ 차별화 강력 확정          |

### 9-2. DataQ 입찰 포지셔닝

> **"SMETA 의 메타관리 기능 동등 + SDQ 를 별도 도입할 필요 없음 + 자동 표준화 추천 / 품질 진단 / Cubrid 등 SMETA 미보유 영역에서 차별화"**

이 메시지가 입찰 핵심. Phase 1 (3개월) 작업 완료가 입찰 참여 가능 조건.

### 9-3. 76번 갱신 요약

- §6 SMETA B 점수 75 → 80
- §6 SMETA 평균 85 → 87
- §7 격차 23점 → **25점** (현재) / **5점** (Phase 1) / **추월** (Phase 2)
- §8 12개 미검증 항목 결과 정리
- 새 후속 검증 항목 (8건) 추가
