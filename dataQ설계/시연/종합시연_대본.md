> 단어·용어·도메인 표준 관리부터 데이터 모델 수집·표준화 진단·구조 변경 감지·데이터 품질 검증·진단 스케줄링까지, 데이터 표준화 라이프사이클 전체를 한 솔루션에서 다룹니다."

## 3. 데이터 표준 사전 (10분)

### 3-1. 단어 (2분)

**슬라이드 6 — 단어 관리**
> "표준 단어 사전입니다. 행안부 공통 표준 단어 약 3,300건 + 사용자 추가 단어. 형식단어 (분류어) 여부, 영문약어, 동의어 리스트 등을 관리합니다.
> [실시연] 좌측 메뉴 [데이터 표준 사전 > 단어]. 검색바에서 '회원' 입력 → 매칭 단어들. 행 클릭하면 상세 패널.
> 검색 필터: 단어명, 영문약어명, 형식단어 여부 (전체/형식단어/일반), 등록일자 범위, 승인 여부. 우측 [등록], [일괄 등록], [템플릿 다운로드], [다운로드] 버튼.
> 등록 모달 — 한글 단어명, 영문약어명 (자동 대문자), 영문 풀명, 단어 설명, 도메인 분류 ('금액'/'일자' 등), 형식단어 여부 토글."

### 3-2. 용어 (3분)

**슬라이드 7 — 용어 등록 v2 (81/82번 신규)**
> "용어 — 단어들의 조합으로 만들어진 컬럼명 표준입니다. 이번에 등록 모달을 v2 로 개편했습니다.
> [실시연] [데이터 표준 사전 > 용어] → [등록] 클릭 → 모달.
> 핵심 변화: **단일 폼** (이전엔 3-step stepper). 한글 용어명 입력하면 1초 디바운스 후 **자동 분석**. 백엔드 analyzeTermsBatch API 가 DP 점수 + 동의어 cascade + 미신뢰 토큰 재검색으로 정확한 단어 분리 결과 반환.
> 예시: '회원전화번호' 입력 → [회원, 전화, 번호] 토큰별 한 줄씩, 각 토큰의 매칭 후보 + 영문약어 자동 합성 (MBR_TEL_NO).
> 미등록 단어는 인라인 등록 폼이 즉시 노출 — 모달 안 모달 없이 그 자리에서 등록.
> 마지막 단어가 'CD' 면 도메인 유형이 자동으로 '코드' 토글 → 코드 picker 다이얼로그 활성화 (검색·필터)."

**슬라이드 8 — 용어 분석 케이스**
> "테스트 케이스 4개로 검증된 동작:
> ① **AUTO** — 모든 단어 매칭, 즉시 등록 가능 (예: 회원전화번호 → MBR_TEL_NO)
> ② **PARTIAL** — 일부 미등록 (예: 블라블라일자 → '일자' MATCHED, '블라블라' UNRECOGNIZED → 인라인 등록 폼)
> ③ **FAILED** — 전 토큰 미인식 (예: 라랄라룰루)
> ④ **REGISTERED** — 이미 등록된 용어, 중복 swal 알림"

### 3-3. 코드 + 도메인 + 그룹/분류 + 변경 이력 (2분)

**슬라이드 9 — 코드/도메인/그룹/분류**
> "코드 — 코드 그룹 + 코드 항목으로 분류. 등록일자 범위 검색 신규.
> 도메인 — 데이터 타입/길이 표준 (예: 금액 NUMBER(15,2)). 도메인 그룹/분류로 계층화.
> 변경 이력 — 단어/용어/도메인/코드 모든 항목의 등록·수정·삭제 이력. 변경 사용자, 시각, before/after 값.
> [실시연] [코드] → 검색. [도메인] → 데이터 타입 표준. [도메인 그룹/분류] → 계층. [변경 이력] → 최근 3건 행 클릭 → 상세."

### 3-4. 일괄 등록 + 다운로드 (1분)

**슬라이드 10 — 일괄 등록 양식**
> "5종 정적 XLSX 양식 (단어/용어/도메인/테이블/컬럼). [템플릿 다운로드] 클릭 시 즉시 다운로드. 양식대로 입력 후 [일괄 등록] 시 미리보기 → 커밋. 진단 결과 다운로드는 동적 POI 생성 — 검색 결과 그대로."

### 3-5. 승인 워크플로 (2분)

**슬라이드 11 — 승인 (관리 메뉴)**
> "일반 사용자가 등록 신청 → APRV_YN='N' → [관리 > 승인] 화면에 대기. 관리자가 행별 [승인]/[반려]. 반려 시 사유 인라인 입력.
> 핵심 정책: **단어 선승인** (구성 단어 미승인 시 용어 승인 거부). **cascade 반려** (단어 반려 시 연관 미승인 용어도 동시 반려). **반려 후 물리 삭제** (재등록 가능).
> [실시연] [관리 > 승인] → 대기 행 → 승인/반려. 승인 이력 탭."

### 4-4. 진단 제외 관리 (79번 신규) (4분)

**슬라이드 17 — 진단 제외 관리 (79번)**
> "이번 세션 신규. 임시 테이블, 폐기 예정 테이블, 측정 의미 없는 컬럼을 진단 모수에서 명시적으로 제외.
> [실시연] [데이터 모델 > 진단 제외 관리] → 모델 선택 → 테이블 단위 / 컬럼 단위 탭.
> 행에 표준/구조/품질 3개 진단별 ON/OFF 토글. OFF 시 사유 모달 (선택입력 — 빈 사유로도 OFF 가능).
> Cascade 정책: 테이블 OFF → 그 테이블의 모든 컬럼이 자동으로 모수 제외. 테이블 ON + 컬럼 OFF → 해당 컬럼만.
> 일괄 토글: 체크박스 다중 선택 → 상단 [표준 OFF / 구조 OFF / 품질 OFF / ...ON] 버튼.
> 적용 시점: 표준 진단 즉시, 구조 변경 진단 즉시 (제외 변경 미등장), 품질 진단 컬럼 단위 즉시."

## 8. 데이터 품질 진단 (5분)
