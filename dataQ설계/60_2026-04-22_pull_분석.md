[DSDatamodelStatusColumn.vue](../q-center/vue/front/src/components/DSDatamodelStatusColumn.vue):
```js

L493:  openEditAttrDialog() { if (!this.isLatestClct) return; ... }

```

`isLatestClct` 는 data/computed/methods **어디에도 정의 없음** → `undefined` → `!undefined === true` → **무조건 early return**.

**결과**: [컬럼 추가] 버튼 눌러도 반응 없음. [수정]/[삭제] 아이콘도 먹통. 콘솔 에러 없음 (silent return 이라).

**수정법**: 3줄 삭제만 하면 됨. 단 PC2 작업본이 같은 파일에 걸쳐 있을 가능성이 있어서 오늘은 수정 보류.
