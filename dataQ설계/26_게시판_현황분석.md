# 커뮤니티 게시판 현황 분석

**분석일**: 2026-04-07

---

## 1. 현재 DB 구조

### TB_BOARD (게시글)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| BOARD_ID | VARCHAR(40) PK | UUID |
| BOARD_TYPE | VARCHAR(20) | NOTICE / QNA |
| TITLE | VARCHAR(200) | 제목 |
| CONTENT | TEXT | 내용 (plain text) |
| CRET_USER_ID | VARCHAR(40) | 작성자 ID |
| CRET_DT | TIMESTAMP | 작성일시 |
| UPDT_DT | TIMESTAMP | 수정일시 |
| VIEW_CNT | INTEGER | 조회수 |

### TB_BOARD_COMMENT (댓글)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| COMMENT_ID | VARCHAR(40) PK | UUID |
| BOARD_ID | VARCHAR(40) FK | 게시글 ID |
| CONTENT | TEXT | 댓글 내용 |
| CRET_USER_ID | VARCHAR(40) | 작성자 ID |
| CRET_DT | TIMESTAMP | 작성일시 |

## 2. 현재 구현된 기능

### 2.1 게시글

| 기능 | 구현 | 상세 |
|------|------|------|
| 목록 조회 | ✅ | 타입별(공지/QNA), 페이지네이션, 제목+내용 키워드 검색 |
| 상세 조회 | ✅ | 제목, 내용, 작성자, 작성일, 수정일, 조회수 |
| 조회수 카운트 | ✅ | 상세 조회 시 자동 증가 |
| 글쓰기 | ✅ | 제목 + 내용 (plain textarea), 작성자 ID 표시 |
| 수정 | ✅ | 본인/관리자만, 취소 시 확인 팝업 |
| 삭제 | ✅ | 본인/관리자만, 제목 포함 확인 팝업, 댓글도 함께 삭제 |
| 권한 체크 | ✅ | 공지사항은 관리자만 작성 가능, QNA는 전체 |

### 2.2 댓글

| 기능 | 구현 | 상세 |
|------|------|------|
| 목록 조회 | ✅ | 작성일 오름차순, 작성자/작성일 표시 |
| 댓글 작성 | ✅ | 작성자 ID 표시, textarea |
| 댓글 수정 | ✅ | 본인/관리자, 인라인 textarea 전환 |
| 댓글 삭제 | ✅ | 본인/관리자, 확인 팝업 |

### 2.3 UI/UX

| 항목 | 상태 |
|------|------|
| 목록 → 상세 → 목록 이동 | ✅ |
| 수정 취소 → 상세로 복귀 | ✅ |
| 새글 취소 → 목록으로 복귀 | ✅ |
| 취소 시 확인 팝업 | ✅ |
| 삭제 시 제목 표시 | ✅ |
| 작성 화면에 작성자 ID 표시 | ✅ |
| 댓글 작성 영역에 작성자 ID 표시 | ✅ |

## 3. 미구현 / 부족한 기능

### 3.1 게시글 관련

| 기능 | 상태 | 우선도 | 비고 |
|------|------|--------|------|
| 번호 컬럼 (글 번호) | ❌ | 높음 | 목록에 순번 없음 |
| 공지사항 상단 고정 | ❌ | 높음 | QNA 탭에서도 공지가 상단에 보여야 함 |
| 내용 미리보기 | ❌ | 중간 | 목록에서 내용 일부 표시 |
| 리치 텍스트 에디터 | ❌ | 중간 | 현재 plain textarea만 |
| 파일 첨부 | ❌ | 중간 | 스크린샷/문서 공유 불가 |
| 검색 조건 세분화 | ❌ | 낮음 | 제목만/내용만/작성자 등 |
| 정렬 옵션 | ❌ | 낮음 | 최신순 고정, 조회순/댓글순 없음 |
| 글 임시저장 | ❌ | 낮음 | |
| 수정 이력 표시 | ❌ | 낮음 | "(수정됨)" 뱃지만 표시 |

### 3.2 댓글 관련

| 기능 | 상태 | 우선도 | 비고 |
|------|------|--------|------|
| 댓글 수정일시 | ❌ | 높음 | DB에 UPDT_DT 컬럼 없음 |
| 대댓글 (답글) | ❌ | 중간 | 1depth만 지원 |
| 댓글 수 목록 표시 | ❌ | 중간 | 목록에서 댓글 수 안 보임 |
| 이중 클릭 방지 | ❌ | 중간 | 빠른 연속 클릭 시 중복 등록 가능 |

### 3.3 DB 구조 부족

| 항목 | 상태 | 비고 |
|------|------|------|
| TB_BOARD_COMMENT.UPDT_DT | ❌ | 댓글 수정일시 없음 |
| TB_BOARD 댓글 수 캐시 | ❌ | 매번 COUNT 필요 |
| TB_BOARD 첨부파일 | ❌ | 파일 테이블 없음 |
| TB_BOARD 카테고리/태그 | ❌ | BOARD_TYPE만 있음 |

### 3.4 보안/검증

| 항목 | 상태 | 비고 |
|------|------|------|
| 게시글 수정 시 본인 확인 (백엔드) | ❌ | 프론트에서만 체크, 백엔드 미검증 |
| 댓글 수정/삭제 시 본인 확인 (백엔드) | ❌ | 프론트에서만 체크 |
| XSS 방지 | ❌ | plain text라 현재는 안전하나, 리치텍스트 도입 시 필수 |
| 이중 클릭 방지 | ❌ | 등록/수정/삭제 모두 미적용 |

## 4. API 목록

| Method | URL | 설명 |
|--------|-----|------|
| POST | /api/board/list | 목록 조회 (타입, 키워드, 페이지) |
| GET | /api/board/{boardId} | 상세 조회 + 조회수 증가 |
| POST | /api/board/create | 게시글 등록 |
| POST | /api/board/update | 게시글 수정 |
| POST | /api/board/delete | 게시글 삭제 (댓글도 삭제) |
| GET | /api/board/{boardId}/comments | 댓글 목록 조회 |
| POST | /api/board/{boardId}/comment | 댓글 등록 |
| POST | /api/board/comment/update | 댓글 수정 |
| POST | /api/board/comment/delete | 댓글 삭제 |
