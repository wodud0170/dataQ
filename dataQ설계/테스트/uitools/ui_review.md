## 3. 한계 (자동 + 수동 모두 한계)

본 리뷰가 못 잡은 부분:
- **모달/dialog 내부** — 메뉴 진입만 검증. 등록/수정 모달 안 흐름은 사람이 직접
- **권한별 노출** — admin 화면만 캡처. 일반 사용자 (jyjang) 시점 별도 검증 필요
- **모바일 반응형** — 1500x1000 desktop 만
- **데이터 있는 상태** — 일부 화면은 데이터 0 인 빈 상태 — 데이터 차있을 때 다른 이슈 가능
- **애니메이션/transition** — 정적 스크린샷이라 깜빡임/지연 등 못 봄

## 4. 다음 액션

이 리포트 기반:
1. 🔴 항목 (10개) 우선 fix — 30분~2시간 작업
2. 🟡 항목 (6개) 일관성 정리 — 1시간
