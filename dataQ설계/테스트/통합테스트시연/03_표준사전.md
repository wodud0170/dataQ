## 3-4. test_term_recommend_cases.py

| 항목 | 내용 |
|------|------|
| 검증 | 자동 표준화 추천 7가지 케이스 (10 step) — REGISTERED / AUTO / PARTIAL / FAILED + 영문약어 정확 매칭 |
| 사전 조건 | TB_WORD 시드 (회원/명/번호/상품/주문/등록/일시 ... 등 등록), TB_TERMS 일부 (회원명/회원번호/상품명 등) |
| 실행 시간 | ~22초 |
| 시연 포인트 | 1) 5건 한꺼번에 분석; 2) "상품가격" 같은 REGISTERED; 3) "회원금액" AUTO; 4) "회원성씨" PARTIAL (성씨 미인식); 5) "블라블라" FAILED |

```bash
python "dataQ설계/테스트/selenium/test_term_recommend_cases.py"
```

10 step 모두 PASS = 자동 표준화 알고리즘 (DP+B+D+사후처리+동의어) 정상 동작.

> 알고리즘 변경 시 expected 가 깨지면 [74. 자동표준화 현재상태](../../74_자동표준화_현재상태_2026-05-03.md) 참조해 cases 갱신.
