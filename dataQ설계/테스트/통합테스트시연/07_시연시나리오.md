# 07. 시연 시나리오 (외부 시연용 단축 흐름)

## 시나리오 A — 알고리즘/UX 차별화 (~5분)

DataQ 의 자동 표준화 엔진과 모달 UX 가 핵심 차별점. SMETA 대비 우위 영역 시연.

```bash
python "dataQ설계/테스트/selenium/test_term_recommend_cases.py"
python "dataQ설계/테스트/selenium/test_ca8858d_clsf_domain.py"
```

| 단계 | 보여줄 것 |
|------|----------|
| 1 | term_recommend_cases — 한글 컬럼명 5건 입력 → REGISTERED/AUTO/PARTIAL/FAILED 자동 판정 + 영문약어 정확 매칭 |
| 2 | ca8858d_clsf_domain — 수정 모달의 형식단어 autocomplete + 도메인 cascade |

**메시지**: "한글 컬럼명만 입력하면 표준 준수 영문약어 + 도메인 자동 결정. SMETA 는 수동."
