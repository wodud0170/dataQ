# 00. 사전 준비 — 환경 셋업

테스트 실행 전 다음 4가지가 모두 준비되어야 함:
1. **DB 컨테이너 2개** (dataq-db, oracle-xe)
2. **Java 서버 2개** (q-center 28091, q-executor 28098)
3. **테스트 계정 2개** (space=관리자, jyjang=일반)
4. **Python + Selenium + Edge** 환경

---

## 1. DB 컨테이너 기동

### dataq-db (PostgreSQL 13 — 내부 메타 DB)

```bash
docker start dataq-db
# 또는 최초 실행 시:
# docker run -d --name dataq-db -p 25433:5432 \
#   -e POSTGRES_USER=admin -e POSTGRES_PASSWORD=admin!123 \
#   -e POSTGRES_DB=postgres postgres:13
```

검증:
```bash
docker exec -i dataq-db psql -U admin -d postgres -c "SELECT 1"
# 결과: 1
```

### oracle-xe (테스트용 외부 Oracle)

```bash
docker start oracle-xe
```

검증:
```bash
docker ps --format "{{.Names}}\t{{.Status}}"
# dataq-db   Up X minutes
# oracle-xe  Up X minutes
```

## 2. Java 서버 빌드 + 기동

### 빌드 (코드 변경 시)

```bash
export JAVA_HOME="/c/Program Files/Java/jdk1.8.0_202"
export PATH="$JAVA_HOME/bin:$PATH"
cd "/c/Users/장재영/Desktop/dataQ"
mvn clean package -DskipTests
# 약 2~3분 소요. 빌드 SUCCESS 확인
```

### 기동 — PowerShell 백그라운드 (관리자 권한 불필요)

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk1.8.0_202"
$centerDir = "C:\Users\장재영\Desktop\dataQ\q-center"
$execDir   = "C:\Users\장재영\Desktop\dataQ\q-executor"

Start-Process -FilePath "$env:JAVA_HOME\bin\java.exe" `
  -ArgumentList @("-jar", "target\q-center-0.0.1-SNAPSHOT.jar") `
  -WorkingDirectory $centerDir `
  -RedirectStandardOutput "$centerDir\..\q-center.log" `
  -RedirectStandardError  "$centerDir\..\q-center.err.log" `
  -WindowStyle Hidden -PassThru

Start-Process -FilePath "$env:JAVA_HOME\bin\java.exe" `
  -ArgumentList @("-jar", "target\q-executor.jar") `
  -WorkingDirectory $execDir `
  -RedirectStandardOutput "$execDir\..\q-executor.log" `
  -RedirectStandardError  "$execDir\..\q-executor.err.log" `
  -WindowStyle Hidden -PassThru
```

상세 절차 / 함정 → [58_서버_빌드_기동_절차.md](../../58_서버_빌드_기동_절차.md)

### 기동 확인

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:28091/login
# 200 (q-center)
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:28098/
```

## 3. 테스트 계정

| 계정 | 비밀번호 | 권한 | 용도 |
|------|----------|------|------|
| `space` | `123` | 관리자 (TB_USER.ADM_YN='Y') | 전체 화면 + 등록 즉시 승인 |
| `jyjang` | `123` | 일반 사용자 | 등록 시 결재 대기 |

권한 차이 검증:
```bash
# 관리자 / 일반 사용자 isAdmin
curl -s "http://localhost:28091/api/login/isAdmin?user=space"   # true
curl -s "http://localhost:28091/api/login/isAdmin?user=jyjang"  # false
```

이 두 계정은 테스트 코드가 하드코딩으로 사용. 비밀번호 변경 시 모든 테스트 영향.

## 4. Python + Selenium + Edge

### Python 패키지

```bash
pip install selenium requests openpyxl
```

### Edge WebDriver

Edge 브라우저는 Windows 기본 설치. WebDriver는 Selenium 4 부터 자동 다운로드 됨 (별도 설치 불필요).

수동 설치 시:
```
https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
```

### 검증

```bash
python -c "from selenium import webdriver; d=webdriver.Edge(); d.quit(); print('OK')"
# OK 출력되면 정상
```

## 5. 한 번에 검증 — Smoke 체크

테스트 시작 전 환경이 정상인지 1분만에 확인:

```bash
# 1) DB 2개 떠있나
docker ps --format "{{.Names}}" | grep -E "dataq-db|oracle-xe" | wc -l
# 결과: 2

# 2) 서버 2개 응답하나
curl -s -o /dev/null -w "center:%{http_code}\n" http://localhost:28091/login
curl -s -o /dev/null -w "executor:%{http_code}\n" http://localhost:28098/

# 3) 권한 분기 OK
curl -s "http://localhost:28091/api/login/isAdmin?user=space"
curl -s "http://localhost:28091/api/login/isAdmin?user=jyjang"

# 4) Selenium 실행
python -c "from selenium import webdriver; d=webdriver.Edge(); d.get('http://localhost:28091'); print(d.title); d.quit()"
```

모두 정상이면 [01_실행_및_상세.md](01_실행_및_상세.md) 로 진행.

## 6. 자주 빠뜨리는 사전 조건

| 항목 | 확인 |
|------|------|
| dataq-db 의 quality 스키마 | `docker exec -i dataq-db psql -U admin -d postgres -c "\dt quality.*"` 로 테이블 목록 확인 |
| ndata 스키마 (TB_DATA_SOURCE) | `\dt ndata.*` 결과에 TB_DATA_SOURCE 있어야 함 |
| 단어/용어 시드 데이터 | TB_WORD ~ 3300건, TB_TERMS ~ 13000건 (환경에 따라 다름) |
| Oracle 연결 | TB_DATA_SOURCE 의 `auKCmbwFQtm8aiazz7b2bf` (oralce새로) Oracle dial 가능 |
| q-center 로그 위치 | `C:\Users\장재영\Desktop\dataQ\q-center.log` (서버 기동 후) |

DB 가 비어있으면 일부 테스트(글로벌 검색, 자동 표준화 등)는 의미 있는 결과 안 냄. 시드 데이터가 있는 환경에서 시연 권장.
