표준화/구조 변경 진단 대상에서 OBJ/ATTR 단위로 제외하는 기능. 약 4분 소요.

## 8-1. test_diag_target_imsi.py

| 항목 | 내용 |
|------|------|
| 검증 | 임시 테이블 IMSI_TEST_001/002/003 생성 → 단건/일괄 OFF (테이블·컬럼 단위) → 표준 진단 + 구조 변경 진단 매퍼가 OFF row 를 모수에서 정확히 제외하는지 → ALTER 후 OFF 변경 미등장 → ON 복귀 시 모수 복귀 → cleanup |
| 실행 시간 | ~230초 (Oracle DDL + dataq-db 매퍼 SQL 검증) |
| 시연 포인트 | **데이터 모델 → 진단 제외 관리** 화면. 테이블 단위 / 컬럼 단위 탭. 표준/구조/품질 3개 토글 + OFF 시 사유 모달 (선택입력). 일괄 토글 / 상세 다이얼로그 |

### 검증 12 phase 요약

| Phase | 내용 |
|------|------|
| P1 | Oracle 컨테이너에 IMSI_TEST_001/002/003 생성 (3 테이블 12 컬럼) |
| P2 | dataq-db 메타 INSERT (수집 흉내) |
| P3 | OBJ 단건 OFF — TEST_001 표준 + 사유 |
| P4 | OBJ 일괄 OFF — TEST_002/003 구조 + 사유 |
| P5 | ATTR 단건 OFF — TEST_001.NAME 구조 + 사유 빈칸 (NULL 저장) |
| P6 | ATTR 일괄 OFF — TEST_002.CODE/VALUE 표준 |
| P7 | 표준 진단 매퍼 — 모수 5 / 제외 7 (cascade 적용) |
| P8 | 구조 진단 매퍼 — 모수 4 (TEST_001 cascade) |
| P9 | ALTER + 메타 갱신 (XYZ_DATA len 변경, NEW_COL 추가, ETC len 변경) |
| P10 | 구조 매퍼 재검증 — OFF 변경은 모수 미포함 (TEST_001.XYZ_DATA 만 등장) |
| P11 | 모든 OBJ ON 복귀 + 표준 모수 13 회복 / 사유 NULL 클리어 |
| P12 | Oracle DROP + dataq-db row 정리 |

### 시연 포인트 — UI

1. 데이터 모델 → **진단 제외 관리** 메뉴 진입 (관리자 전용)
2. 모델 선택 (DB 연결된 모델만 표시)
3. **테이블 단위 탭**:
   - 행에 표시: 테이블명 + 한글명 + 표준/구조/품질 ON 아이콘 (녹색) ↔ OFF (회색)
   - 단건 토글: 아이콘 클릭 → OFF 시 사유 모달 (선택 입력, 빈 사유로 OFF 가능)
   - 일괄 토글: 체크박스 다중 선택 → 상단 [표준 OFF / 구조 OFF / 품질 OFF / ...ON] 버튼
4. **컬럼 단위 탭**: 동일 패턴, OBJ_NM + ATTR_NM 으로 표시
5. **[상세] 다이얼로그**: 행 우측 [상세] 버튼 → 진단별 사유 + 마지막 변경자/일시 전체 조회

### Cascade 정책

- 테이블 OFF → 그 테이블의 **모든 컬럼이 자동으로 진단 모수 제외** (컬럼 토글 무관)
- 테이블 ON + 컬럼 OFF → 해당 컬럼만 제외, 나머지 포함

### 적용 시점

- 표준 진단: 즉시 (다음 진단 실행부터)
- 구조 변경 진단: 즉시 (제외 테이블/컬럼의 변경은 결과에 미등장)
- 품질 진단: 컬럼에 한해 즉시 (테이블 단위 cascade 는 67/70번 정식 구현 시 통합)
