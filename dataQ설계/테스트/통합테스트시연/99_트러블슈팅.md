# 99. 트러블슈팅

## 환경 문제

### Q1. `Edge` WebDriver 못 찾음 / 버전 불일치
```
selenium.common.exceptions.SessionNotCreatedException: Message: session not created
```
**해결**:
- Edge 브라우저 최신 버전인지 확인
- `pip install --upgrade selenium` 으로 Selenium 4.x 사용 (자동 드라이버 다운로드)

### Q2. 한글 IME 환경에서 textarea 입력 실패
**증상**: send_keys 가 v-model 에 반영 안 됨 (test_ca8858d_clsf_domain 등)
**해결**: 이미 fix 됨 (JS prototype value setter 패턴). 만약 새 테스트 작성 시 동일 패턴 사용:
```js
const setter = Object.getOwnPropertyDescriptor(window.HTMLTextAreaElement.prototype, 'value').set;
setter.call(el, val);
el.dispatchEvent(new Event('input', { bubbles: true }));
```

### Q3. 좀비 java 프로세스로 포트 충돌
```
Address already in use: 56516 (또는 28091)
```
**해결**:
```bash
tasklist | findstr -i java
# zombie PID 확인 후
taskkill //F //PID <PID>
```
JMX 포트(56516)의 경우 winnat reservation 도 점검:
```bash
netsh int ipv4 show excludedportrange protocol=tcp
```

### Q4. q-center 가 28091 안 뜸
**증상**: 빌드 SUCCESS 후 `curl /login` 응답 없음
**확인**:
- `q-center.log` 의 마지막 줄 — `Started` 메시지 있나?
- `q-center.err.log` 에 stack trace 있나?
- DB 접속 실패 시 stack 에 `HikariCP` / `Connection refused` 보임 → dataq-db 컨테이너 확인

## 데이터 문제

### Q5. test_term_recommend_cases.py — PARTIAL 케이스 AUTO 됨
**증상**: 테스트가 "이름"/"나이" 단어를 미등록 가정했지만 등록되어 있어 AUTO 됨
**해결**: 케이스 코드 갱신 — `test_term_recommend_cases.py` 의 cases 목록을 진짜 미인식 단어로 변경 (예: "회원성씨", "주문무지개")

### Q6. test_date_range_filter.py — 0건 케이스에서 행이 잡힘
**원인**: TB_WORD/TB_TERMS/TB_TERMS(코드) 의 CRET_DT 가 1900~1901 또는 2099 범위 안에 들어가는 데이터가 시드에 있음
**해결**: 시드 데이터 점검. 일반적으로 환경 세팅 시 발생 안 함

### Q7. test_full_approval_flow.py — 결재 대상 없음
**원인**: 결재 대기(APRV_YN='N') 행이 환경에 없음
**해결**: 일반 사용자(jyjang)로 단어/용어 등록 후 결재함 진입. 또는 시드 SQL 재실행

### Q8. test_logical_model_e2e — 모델 ID 충돌
**증상**: 같은 이름 모델이 이미 있어 등록 실패
**해결**: 테스트는 timestamp suffix 사용. 충돌 시 잔여 데이터 정리:
```sql
DELETE FROM quality.TB_DATA_MODEL WHERE DM_NM LIKE '%TEST%2026%';
```

## 알고리즘/UI 변경에 따른 회귀

### Q9. 자동 표준화 결과가 예전과 다름 (분리/매칭)
**원인**: 2026-05-03 알고리즘 변경 (B+D + 사후처리 + 동의어)
- DP 에 SPLIT_PENALTY=8000 추가
- 1자 비형식단어 점수 격하 (5000)
- 사후처리에서 동의어(ALLOPH_SYNM_LST) 매핑

**검증**: 변경 의도와 결과가 맞으면 OK. 기존 expected 가 오래됐으면 갱신 필요. 상세 → [74. 자동표준화 현재상태](../../74_자동표준화_현재상태_2026-05-03.md)

### Q10. "분류어" 라벨 검색 실패
**원인**: 행안부 지침 기준 "분류어" → "**형식단어**" 로 가시 텍스트 통일 (2026-05-03)
**해결**: 셀레니움 코드의 `"분류어 추가"` 등 텍스트 매칭 → `"형식단어 추가"` 로 변경

## 마스터 러너 자체 문제

### Q11. 일부 테스트만 [MISSING]
**원인**: `run_all.py` 의 GROUPS 배열에 등록한 파일이 selenium 폴더에 없음
**해결**: 파일 경로 확인. 또는 GROUPS 에서 제거

### Q12. [TIMEOUT] — 10분 초과
**원인**:
- 서버 응답 지연 (DB 락, GC pause)
- 무한 대기 셀렉터 (UI 변경으로 못 찾음)
**해결**:
- q-center.log 의 마지막 시각 확인
- 해당 테스트 단독 실행으로 stack trace 확인 (timeout 안 걸리고 진짜 에러 보임)

### Q13. 일부 테스트만 [SKIP]
**원인**: `--filter <pattern>` 옵션 사용 시 일치하지 않는 파일은 SKIP. 정상 동작.
