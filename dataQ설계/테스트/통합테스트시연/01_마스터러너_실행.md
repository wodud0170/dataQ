# 01. 마스터 러너 실행

## A. 전체 실행

### 명령

```bash
cd C:/Users/장재영/Desktop/dataQ
python "dataQ설계/테스트/selenium/run_all.py"
```

### 진행 표시

각 테스트마다:
```
[RUN] test_xxx.py
  → [PASS] 39s — exit 0
```

### 종료 시 요약

```
======================================================================
[FINAL SUMMARY] ~1500초 총소요
======================================================================
  [PASS] 28

----------------------------------------------------------------------
[GROUP 별 상세]

## API/Login (가벼움)
  ✓ [PASS   ]    65s  test_login.py
  ✓ [PASS   ]     4s  test_phase1_schedule_api.py
  ...
```

### 종료코드

- `0` = 모든 PASS
- `1` = 1건 이상 FAIL/TIMEOUT/ERROR
