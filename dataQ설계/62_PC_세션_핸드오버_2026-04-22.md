```bash
cd <프로젝트>
git status           # modified: DSDatamodelStatusTable.vue, DSDatamodelStatusColumn.vue 등 뜨는지
git log --oneline -5 # 로컬에 push 안 된 커밋 있는지 (ahead of origin)
```

- `git status` 가 clean + `ahead of 0 commits` → **미푸시 작업 없음**이 확정. 56번 문서는 "백엔드 스펙 기반 설계 의도" 로 재분류하고 60번 §8 에 기록. 이후 **프론트를 신규 구현**으로 진행
- 미푸시 커밋 또는 수정 파일이 있음 → 즉시 push 또는 stash pop 후 review. PC1 의 `ca8858d` 와의 머지 이슈 먼저 해소
