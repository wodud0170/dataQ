# 데이터 관리 SW 설치 지원 - 요구사항 충족 현황

**작성일**: 2026-04-20
**대상 시스템**: Narae DataQ

## 1. 메타데이터 수집·관리 SW

### 요구사항
> 스키마, 테이블, 컬럼, 인덱스, 제약조건 등 DB 구조 정보를 자동으로 수집하고 변경 이력을 관리하는 기능

### 충족 현황

| 항목 | 충족 여부 | 구현 내용 |
|------|----------|----------|
| 스키마 수집 | ✅ | TB_DATA_MODEL_SCHEMA 기반 멀티 스키마 수집, 스키마 필터 지원 |
| 테이블 수집 | ✅ | TB_DATA_MODEL_OBJ — 테이블명, 논리명, 소유자, 컬럼수, 생성일, 수정일 |
| 컬럼 수집 | ✅ | TB_DATA_MODEL_ATTR — 컬럼명, 논리명, 타입, 길이, Nullable, PK/FK, 기본값, 순서 |
| 인덱스 수집 | ✅ | TB_DATA_MODEL_INDEX — 인덱스명, 타입, 유니크, 구성컬럼, 순서, 정렬방향 |
| 제약조건 수집 | ✅ | TB_DATA_MODEL_CONSTRAINT — PK/FK/UK/CHECK, 구성컬럼, 참조테이블/컬럼, 삭제규칙, 조건식 |
| 자동 수집 | ✅ | DBMS 카탈로그 직접 접속 수집 (Oracle, MariaDB, Cubrid), WebSocket 진행상황 알림 |
| 변경 이력 관리 | ✅ | 구조 변경 진단 — 수집 스냅샷 vs 현재 DB 비교, 컬럼/인덱스/제약조건 ADDED/MODIFIED/DELETED 감지 |
| 변경 이력 저장 | ✅ | TB_STRUCT_DIAG_HISTORY (진단 이력), TB_STRUCT_DIAG_DETAIL/INDEX_DETAIL/CONSTRAINT_DETAIL (변경 상세) |
| 이력 조회/다운로드 | ✅ | 진단 결과 화면 (3탭: 컬럼/인덱스/제약조건), 탭별 엑셀(xlsx) 다운로드 |

### 지원 DBMS

| DBMS | 테이블/컬럼 | 인덱스/제약조건 | 비고 |
|------|-----------|-------------|------|
| Oracle | ✅ | ✅ | ALL_* 뷰 사용 (멀티 스키마) |
| MariaDB | ✅ | ❌ (Named Query 미구현) | 테이블/컬럼만 수집 |
| Cubrid | ✅ | ❌ (Named Query 미구현) | 테이블/컬럼만 수집 |
| PostgreSQL | ❌ | ❌ | Named Query 미구현 (내부 DB로만 사용 중) |

## 2. 데이터베이스모델링 관리 SW

### 요구사항
> 시스템의 데이터 모델이 원활히 편집·시각화되는지 확인하고 충분한 성능이 발휘될 수 있도록 설치 지원

### 충족 현황

| 항목 | 충족 여부 | 구현 내용 |
|------|----------|----------|
| 데이터 모델 등록/관리 | ✅ | 데이터 모델 CRUD, 데이터소스 연결, 수집 이력 관리 |
| 논리/물리 모델 구분 | ✅ | MODEL_TYPE (PHYSICAL/LOGICAL/BOTH), 논리명(NM_KR)과 DB 코멘트(COMMENT) 분리 |
| 논리 모델 생성 (데이터소스 없이) | ✅ | 데이터소스 미지정 상태에서 모델 생성 → 테이블/컬럼 수동 추가 가능 |
| 테이블 추가/수정 | ✅ | 데이터 모델 > 테이블 메뉴 — 테이블 추가/수정 다이얼로그 |
| 컬럼 추가/수정 | ✅ | 데이터 모델 > 컬럼 메뉴 — 컬럼 추가/수정 다이얼로그 (표준사전 드롭다운) |
| 인덱스/제약조건 조회 | ✅ | 데이터 모델 > 인덱스/제약조건 메뉴 — 수집된 메타 조회 |
| DDL 생성/다운로드 | ✅ | CREATE TABLE + 제약조건 + 코멘트 SQL 자동 생성 (Oracle/PostgreSQL Dialect) |
| ERwin 모델 임포트 | ✅ | ERwin XML 파일 파싱하여 테이블/컬럼 일괄 수집 |
| 모델 현황 대시보드 | ✅ | 테이블수, 컬럼수, 표준 준수율, 구조 일치율, 진단 추이 차트 |
| 논리→물리 자동 변환 | ❌ | 미구현 — 논리명(한글) 입력 시 표준 용어 매칭 → 영문컬럼명 + 타입/길이 자동 생성 기능 필요 |

**참고**: 시각적 모델링(ER 다이어그램, 관계선 편집)은 ERwin/DA# 등 전문 도구 영역. 본 시스템은 모델링 결과를 임포트 또는 수동 등록 → 표준 검증 → DDL 생성하는 역할.

**목표 흐름**:
```
논리 모델 입력 (ERwin 임포트 or 행 단위 등록)
    ↓
표준 사전 기반 물리 자동 변환 (논리명 → 표준용어 → 영문약어 + 도메인 타입/길이)  ← 미구현
    ↓
DDL 생성 (CREATE TABLE SQL 다운로드)  ← 구현 완료
```

## 3. 메타시스템 연계 모듈

### 요구사항
> 데이터 모델 정보와 메타데이터 관리시스템 간의 연동 지원
> 데이터 모델의 메타데이터를 표준 포맷으로 추출·변환·적재할 수 있는 연계 처리 기능

### 충족 현황

| 항목 | 충족 여부 | 구현 내용 |
|------|----------|----------|
| DBMS 카탈로그 연동 | ✅ | DataSourceUtils + DBHandler로 대상 DBMS 직접 접속, Named Query 기반 메타 수집 |
| 데이터소스 관리 | ✅ | 다중 데이터소스 등록/수정/삭제, 연결 테스트, SID/Service Name 지원 |
| 표준 포맷 추출 (Excel) | ✅ | 테이블/컬럼/인덱스/제약조건/단어/용어/도메인 전체 Excel(xlsx) 다운로드 |
| 표준 포맷 추출 (DDL) | ✅ | 데이터 모델 기반 CREATE TABLE SQL 생성 (Oracle/PostgreSQL) |
| 표준 포맷 적재 (Excel) | ✅ | 단어/용어/도메인/코드 Excel 일괄 업로드 |
| ERwin XML 연동 | ✅ | ERwin XML 파일 임포트하여 논리/물리 모델 적재 |
| 표준화 진단 연계 | ✅ | 수집된 컬럼 vs 표준 용어/도메인 자동 비교, 준수율 산출 |
| 구조 변경 진단 연계 | ✅ | 수집 스냅샷 vs 현재 DB 자동 비교, 변경 감지 |
| API 기반 연동 | ✅ | REST API 전체 공개 (Swagger 문서 제공) |
| ETL 연계 | ❌ | 별도 ETL 도구 연동 미구현 (API 기반 수동 연계만 가능) |
| 실시간 동기화 | ❌ | 수동 수집 방식 (진단 스케줄러 설계 완료, 구현 예정) |

### 미충족 항목 및 대응 방안

| # | 미충족 항목 | 영향도 | 대응 방안 | 비고 |
